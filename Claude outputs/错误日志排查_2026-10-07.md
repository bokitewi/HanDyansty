## 第一档：刷屏，或导致核心功能失效（建议最先修）

### 1. 五胡内附：族群 flag 读不出来【今日】，约 65,000 条
- **位置**
  - `common/scripted_effects/zz_hd_wuhu_liao_common_effects.txt:241`：`save_scope_value_as = { name = hd_wuhu_tribe value = var:hd_wuhu_settled }`
  - `events/zz_hd_wuhu_events.txt:104`：同样的写法，读的是 `var:hd_wuhu_tribe`
- **根因（已验证）**
  - 这两个变量里存的是 flag（`flag:xiongnu` 等）。
  - `save_scope_value_as` 的 `value = var:...` 只接受数值，日志报 "Value of wrong type ... Got value of type 'flag'"。
  - 结果 `scope:hd_wuhu_tribe` 变成了一个数值，下游所有 `$TRIBE$ = flag:xxx` 的比较全部失败。
- **影响**
  - 每年对每位内附胡首、每个县都要跑一遍，报错因此刷屏，也拖慢运行。
  - 渐进胡化（`hd_wuhu_convertible_county_trigger`）**永远不会成立**。
  - 2099 封地时"优先本族安置区"的加分失效：`hd_wuhu_frontier_grant_score` 第 135 行。
  - `hd_wuhu_save_tribe_culture_rite_effect` 第 41 行起的分支全部判假，族群的文化和信仰 scope 存不下来。
  - `hd_wuhu_tribe_is_nomadic_trigger` 判假，**匈奴、鲜卑、乌桓都被设成了部族制**：common_effects:122/139，其中 4 次报 "illegal government"。
- **修复**
  - 两处都改成 if 链：逐个比较 `var:X = flag:xiongnu`，再字面写 `save_scope_value_as = { name = hd_wuhu_tribe value = flag:xiongnu }`，6 个族都这样写。
  - 写法照 common_effects:13-33。

    - 减少 CB 种类。
