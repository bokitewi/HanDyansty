# 郡国制：擅兴律与疆界之制（设计稿）

2026-10-31 拟定，boki 逐项拍板；同日已实施，未进游戏测试（实施记录见 §9）。

## 1. 背景

- 原版「行省发动战争」（province_war_law）与「行省边界政策」（province_border_law）两组法律只给行政制：法律组要求政体旗标 `government_uses_imperial_bureaucracy`，各档保有条件 `realm_law_use_imperial_bureaucracy` 又明确排除天朝制。郡国制即原版天朝制（celestial_government），原版天朝也没有这两组。
- 结果：郡国制君主没有任何法律能管郡国制封臣**对外宣战**（皇权法律的 `vassal_internal_wars_banned` / `vassal_all_wars_banned(_permanent)` 只约束非郡国制封臣；郡国制封臣互攻原本就一律禁止）。郡国制封臣也可以随意对同僚发起「边界争端」「吞并辖区」计谋。
- 只给郡国制加 `government_uses_imperial_bureaucracy` 不可行：会同时打开拜占庭「帝国官僚」皇权法律组；各档保有条件排除郡国制；解锁看 `authority_level_1/2/3`（郡国制皇权法律不带）；中间档只认边疆/水师军区。

## 2. 拍板结果

| 项 | 决定 |
|---|---|
| 范围 | 宣战、边界两组都开 |
| 实现 | 复用原版两组法律，放宽条件；宣战判定、许可互动、AI、冷却全沿用原版；行政制原样不变 |
| 宣战档位 | 四档；中间两档看武官编制 |
| 解锁 | 挂钩皇权法律（见 §3） |
| 军阀 | 军阀契约（拥兵自重）封臣完全不受擅兴律约束 |
| 名称 | 宣战组改「擅兴律」，边界组改「疆界之制」（两种政体共用名称） |
| 乱世 | 照常生效，与王朝循环阶段无关 |
| 花费/冷却/AI | 全部沿用原版：改一次冷却 5 年、花行政法律威望；AI 好战者倾向限制、建设型倾向批准、虔诚建设型倾向禁止 |
| 冷却 | 保留与军队法律、致仕法律等共用的 `admin_law_cooldown`（行政改革 5 年内只能动一项） |
| 许可互动 | 沿用原版「请求宣战许可」：双倍巨量影响力（仅玩家）或把柄，对同一主君 10 年冷却 |
| 史实线/导演层 | 脚本安排的出兵一律豁免（见 §5） |
| 适用面 | 沿用原版：只管郡国制封臣对外宣战；非郡国制封臣仍由皇权法律管；攻打本国非郡国制封臣不受限 |
| 开局档 | 按皇权档位预设各组允许的最严档，只在开局套一次（见 §4） |

## 3. 档位表

### 擅兴律（province_war_law，累进）

| 档 | 名称 | 效果 | 郡国制解锁 | 行政制解锁（原版） |
|---|---|---|---|---|
| 0 | 听其专征 | 总督可以对外宣战 | — | — |
| 1 | 武臣专征 | 只有边疆/水师军区（行政制）或武官编制（郡国制：军制、都护府、司隶）的总督可以对外宣战 | 皇权 ≥ 有限行政 | authority_level_1 |
| 2 | 奏请出师 | 同上，且须先向主君请求宣战许可 | 皇权 ≥ 省部集权 | authority_level_2 |
| 3 | 擅兴之禁 | 总督**不能**对外宣战 | 皇权 = 天命在我 | authority_level_3 |

军阀（主头衔变量 `hd_warlord`）、持旄节（假节/持节/使持节）或假黄钺者在任何档位都可以对外宣战（旄节、假黄钺为实施时追加，见 §9）。

### 疆界之制（province_border_law，不累进）

| 档 | 名称 | 效果（原版） | 郡国制解锁 | 行政制解锁（原版） |
|---|---|---|---|---|
| 0 | 听其争界 | 总督可随意使用边界争端、吞并辖区计谋 | — | — |
| 1 | 豪右方得 | 只有强势家族或显赫家族的总督才能使用这两种计谋 | 皇权 ≥ 省部集权 | authority_level_2 |
| 2 | 封疆有定 | 总督**不能**使用这两种计谋 | 皇权 = 天命在我 | authority_level_3 |

皇权降级时，原版保有条件失效，法律自动退档（引擎行为，与行政制相同）。封臣跟随最高主君的档位（原版 `should_synchronize_liege_law` 机制，封臣不能自行更改）。

## 4. 开局预设

在 `common/on_action/zz_hd_celestial_authority_startup.txt` 抽完皇权（20/50/20/10）之后，按结果为郡国制独立君主套用：

| 抽中皇权 | 擅兴律 | 疆界之制 |
|---|---|---|
| 地方自治（_0） | 听其专征 | 听其争界 |
| 有限行政（_1） | 武臣专征 | 听其争界 |
| 省部集权（_2） | 奏请出师 | 豪右方得 |
| 天命在我（_3） | 擅兴之禁 | 封疆有定 |

其郡国制封臣同步到同一档。只在开局执行一次；之后新改行郡国制或新独立的君主从「听其专征」「听其争界」开始。

## 5. 豁免说明

原版封臣禁战只写在「宣战」互动的判定 `allows_declaring_war_against_target_trigger` 里（00_war.txt:38 调用），宣战理由组与 `can_declare_war` / `start_war` 都不经过它。因此导演层（hd_strategic_ai 等用 `can_declare_war` + `start_war`）、史实线、剧本脚本直接开的战争**自动豁免**，无需逐个加例外。实施时要复核这一点：确认新增限制只进了该判定，没有进宣战理由组。

## 8. 测试清单

- **首要**：确认脚本 `can_declare_war`（导演层、曹操奉迎判定等）不会连带检查宣战互动的禁令——在擅兴之禁下看导演层战争是否照常开打。
- 253 开局：姜维（使持节）在蜀汉任何擅兴律档位下都能用「北伐中原」宣战。
- 郡国制独立君主的领国窗口「行省法律」栏出现擅兴律、疆界之制；皇权不足时对应档灰掉并显示所需皇权。
- 开局各郡国制君主的档位与抽中的皇权对应；封臣同档。
- 武臣专征：文官封臣无法对外宣战，武官可以；军阀在擅兴之禁下仍可宣战。
- 奏请出师：武官封臣出现「请求宣战许可」互动，获准后可宣战一次。
- 疆界之制：封疆有定下郡国制封臣无法发起边界争端、吞并辖区。
- 行政制（拜占庭式）法律行为与原版一致。
- 史实剧本（184 讨黄巾、190 讨董等）与导演层战争照常开战。
- error.log 无新报错。

## 9. 实施记录（2026-10-31）

实施中追加拍板（boki）：
- 同步容错：封臣只在直属主君也能持有这两组法律时才须同档（行政制一并适用）。原写法下，氏族等主君手下的郡国制/行政制封臣任何一档都保不住。
- 去掉 7 档上的旧旗标 `uses_imperial_bureaucracy`（mod 是旧版副本，1.20 原版已无；全 mod 无脚本读取）。
- 疆界之制第 1/2 档对郡国制封臣同扣好感 -5/-10（`celestial_government_vassal_opinion`），与行政制对等。
- 英、日、韩名称沿用原版，只改中间两档与禁止档的效果文字。
- mod 旧补丁 dm_tiger 里边界政策 `_effects` 三条文字与实际效果相反，四种语言都改为引用原版 `_effects_not_in_prev`。

- 豁免扩大：除军阀外，持旄节（假节、持节、使持节，三节一律）或假黄钺的封臣也完全不受擅兴律约束（新触发器 `hd_province_war_law_exempt_trigger`）。起因是 253「姜维北伐中原」`hd253_beifa_cb` 要由蜀汉郡国制封臣自行宣战；姜维开局为使持节、军制编制，253 代码注释原本就预留「使持节有宣战权」。
- 「征伐委任」互动（大将军、大司马等重臣可派郡守对外出征，脚本开战）不受擅兴律限制，boki 拍板不处理。

豁免清点（2026-10-31，对 §5 的更正）：
- 脚本开战（`start_war`，含 `hd_wct_start_war_effect`、`hd_anti_regent_try_stage_war_effect` 等包装）不受影响：讨董联军、汉中之战、襄樊、白衣渡江、89 北伐、253/263 史实战争、五胡、衣冠南渡、黄巾、历史入侵等。
- 需要自行宣战、且发起者可能是郡国制封臣的 mod 宣战理由：`hd253_beifa_cb`（已由旄节豁免解决）；`zgrc_county_rangyi_cb`、`zgrc_duchy_rangyi_cb`、`zgrc_dafuchou_cb`（攘夷/大复仇，属正常对外战争，按设计受擅兴律约束）。其余 mod 宣战理由或限独立君主、或为内战/派系战，不受影响。
- 能用脚本开战、绕过禁令的互动/决议：「征伐委任」（见上，不处理）；其余为史实决议（曹操奉迎、346 李玄）或原版内战类（囚禁、驱逐冒险者），不涉及郡国制封臣对外宣战。
- 请求宣战许可获准会触发王朝循环催化项 `catalyst_hegemon_influenced_by_interaction`（原版行为，已有定义）。
