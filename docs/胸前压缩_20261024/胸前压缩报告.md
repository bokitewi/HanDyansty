# 甲胄胸前回收（2026-10-24）

触发：玩家截图——弩兵鳞甲（`hd_frontier_crossbow_scale`）+ 抱臂姿势，前臂和手整段埋进胸甲。用户判断「所有建模都有这个问题，胸前突起过多」。
范围：HanJIn_Clothes `gfx/models/portraits/m_clothes/` 下 22 件甲胄，男女版都改（将军精甲只有男版）。只改 `.mesh` 顶点位置/法线/切线/包围盒，`.asset`、贴图、UV、三角形、蒙皮都不动。

## 一、量化（为什么是甲胄而不是全部）

指标：躯干中线 |x|<12、胸腹高度内，每 2×2 格取衣服最外层到「身体前表面」的距离，取 90 分位（`compress_front.garment_emax`）。

| 组 | 数值 |
|---|---|
| 原版全部男装 170 件 | 中位 4.7，75% 6.0，90% 7.0 |
| 原版战甲（war_nob 等 36 件） | 多在 3.6~7，中位约 5 |
| mod 常服/袍服、东汉铠甲一号、张角、汉代袍 | 3.8~6.4，在原版范围内 |
| 10-22 修过的匈奴重甲 | 5.7 |
| **mod 甲胄 22 件** | **7.1~11.7**，其中 16 件 ≥ 9.5 |

**根因**：这批甲（多来自全战三国转换）整套衣服离身体悬空。局部统计：最内层衣服的外表面距身体约 5~9，整叠衣服本身只有 1~3 厚。也就是说，多出来的凸出大部分是「衣服与身体之间的空隙」，不是衣服本身厚。原版姿势动画是按原版衣服厚度摆手臂的，所以抱臂、按胸、叉腰时前臂会陷进去。

## 二、做法

脚本 `tools/compress_front.py`（局部叠层曲线，`HD_CF_MODE=local`）。每个顶点只沿 z（前后）移动：

1. **身体前表面高度场 H(|x|, y)**：原版男/女身体去掉四肢的朝前面片取最前 z，并与全部非四肢面片取最前（防止肩前三角肌处估计偏后），左右侧每单位最多后收 0.8、上下每单位最多后收 0.4（模拟衣服从胸口垂下），两次 3×3 平滑。
2. **每个顶点的深度** e = H − z（在身体前方多远）。
3. **局部叠层曲线**（每 2×2 格，参数网格再平滑）：e_lo = 最内层衣服外表面深度，e_hi = 最外层（先取 3×3 局部最大再平滑，避免局部凸点超标）。先压「身体到最内层」的空隙（斜率 kg，下限 0.15）；若空隙压完仍超目标，再压叠层（斜率 kl，下限 0.2）。已经不超目标的格子不动。曲线在每条前后射线上单调 → 层次顺序在顶点处严格保持。
4. **空间权重**：竖直范围男 y 60→95 渐入、128→152 渐出（女 56→89、120→143），横向男 |x| 17→23 渐出（女 15→21）；再乘「手臂遮罩」——按该位置所有衣服顶点的手臂骨蒙皮比例（0.3→0.7 渐出，平滑两次），袖子不动。所有权重都只依赖 (x, y)，同一位置的各层用同一映射。
5. **法线/切线**：按形变雅可比矩阵变换（保留原作者的平滑法线），不是重算。
6. **体型文件**：每个 `_bs_*` 加同样位移，体型差值按新位置用原版身体混合形状重新对齐（沿用 10-22 的 `apply_fit.process_bs`；对齐误差 >1 的部件保留原差值，见第五节）。

### 为什么不用「整体等比例压」

先试过线性等比（e' = a + k(e − a)）。胸前同样能收回，但层间距只剩 25~40%，女装渲染里内衬（橙色）在胸部两侧从胸甲透出（`图/02_女装_原版-等比压-去空隙对比.png` 中间列）。改成局部叠层曲线后层间距保留约 70~90%，不再透出（右列）。

## 五、自拟项（实施中自行决定的数值，用户未逐项确认）

- 贴身余量 a：男 1.5、女 1.3（身体前表面外这一段不动）。
- 高度场侧向后收坡度 0.8/单位，上下 0.4/单位；3×3 平滑两次。
- 竖直渐变带：男 60→95 渐入、128→152 渐出；女 56→89、120→143。最初用 78→90/136→148，裙甲长三角形（跨 9~12 单位）在陡渐变里线性插值会互穿，加长后翻转从上千降到个位数。
- 横向渐出：男 |x| 17→23，女 15→21（覆盖甲片两侧，不让侧边前翘）。
- 手臂遮罩：手臂骨蒙皮比例 0.3→0.7 渐出，2×2 格、平滑两次。
- 空隙压缩斜率下限 0.15，叠层压缩斜率下限 0.2。
- 体型差值对齐误差 >1 时保留原差值：东汉铠甲二号饰件（男 dwarf/fat）。

## 六、未验证 / 已知残留

- **没进游戏**。离线渲染为纯色、无贴图，用的是未缩小的基础身体。
- 全部 22 件只渲染了抱臂、贪婪两个姿势；议事、勇敢、狠辣、威吓、正直只在弩兵鳞甲等少数件上看过；胖/壮/老体型的姿势渲染没做。
- 女装东汉铠甲三号、关羽甲、吕布甲：抱臂时胸甲上沿仍略压到前臂上沿（比原来整段埋入好得多）。
- 腰带、腰结、束带随胸腹一起回收，会比原来薄（将军精甲腰结最明显）。
- 匈奴贵族甲、南蛮肩甲的毛皮/外层布只随整体回收，没有重做造型。
