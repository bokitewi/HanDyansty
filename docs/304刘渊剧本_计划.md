- **默认 304.11.20**，即晋永安元年（304）十月、汉元熙元年。这个月刘渊在左国城即汉王位，同月李雄在成都称成都王。

### 5.3 领土连通性检查（只按 provinces.png 与 adjacencies.csv 实算）
方法与 346 相同，脚本是 `conn.py`，运行时 `RIVER=0`：
- 逐像素算省份相邻，排除海、河、湖和不可通行地块；
- 加上 adjacencies.csv 的渡口；
- 每个势力和每个顶层势力分别算连通块。

当前草案 `conn304.txt` 的结论：
- 所有独立势力都各自连通。
- 晋顶层与王浚剩下的飞地都有理由：

| 势力 | 飞地 | 理由 |
|---|---|---|
| 晋 | 平州辽东、玄菟、乐浪、两带方 26 县 | 史实：晋平州与中原之间隔着段部、慕容、宇文，东夷校尉靠海路与朝廷联系 |

| 晋 | 广陵东部 7 县（海陵等） | 与 346 相同：同郡内隔河无渡口 |
| 晋 | 珠崖 4 县 | 海南岛，无渡口 |
| 晋 | 巴郡南平 + 涪陵枳 | 与 346 相同：地图上的孤立块 |
| 王浚 | 范阳、涿、广阳、渔阳泉州 20 县 | 与 346 后赵相同：与幽州北部隔河无渡口 |

- 封臣子领地内部的飞地（陈敏的广陵东部、段部令支海阳经右北平才相连）按 346 的先例列为已知项。

### 5.4 法理
- 一行不改：304 的头衔文件里不写任何 de_jure_liege。
- 南北朝的 `zz_hd_nbc_dejure.txt` 是 280.1.1 生效，304 开局已经生效。所以开局就有江州、秦州、河州、雍州、洛州、司州、平州、湘州、郢州、朔州这套"晋代州制"。其中河州（345 年置）、湘州（307 年置）、郢州、朔州在 304 年史实上还没有，这是已知结果，与 346/404 一致。
