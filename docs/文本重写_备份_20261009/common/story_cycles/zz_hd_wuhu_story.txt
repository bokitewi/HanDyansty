# 五胡内附·第二层：边疆收留链（移植原版 FP3 turkic_tribe_story，见 docs/五胡内附_僚人入蜀_设计草案.md 4.2）。
# 与原版的区别：收留者死亡时故事传给主继承人；结局事件为 hd_wuhu.2099（索封）。

story_hd_wuhu_frontier = {

	on_setup = {
		save_scope_as = hd_wuhu_frontier_story
		set_variable = {
			name = turkic_leader
			value = story_owner.var:turkic_leader
		}
		if = {
			limit = { story_owner = { has_variable = upset_vassal } }
			set_variable = {
				name = upset_vassal
				value = story_owner.var:upset_vassal
			}
		}
		set_variable = {
			name = nomads_county
			value = story_owner.var:nomads_county
		}
		set_variable = {
			name = nomads_new_county
			value = story_owner.var:nomads_new_county
		}
		set_variable = {
			name = hd_wuhu_tribe
			value = story_owner.var:hd_wuhu_frontier_tribe
		}
		story_owner = {
			remove_variable = turkic_leader
			remove_variable = upset_vassal
			remove_variable = nomads_county
			remove_variable = nomads_new_county
			remove_variable = hd_wuhu_frontier_tribe
		}
	}

	on_end = {}

	on_owner_death = {
		if = {
			limit = {
				exists = story_owner.primary_heir
				story_owner.primary_heir = {
					is_alive = yes
					is_landed = yes
				}
			}
			make_story_owner = story_owner.primary_heir
		}
		else = {
			end_story = yes
		}
	}

	# 胡首死亡或不再是故事主的廷臣/封臣：结束
	effect_group = {
		days = 200
		trigger = {
			trigger_if = {
				limit = { exists = var:turkic_leader }
				var:turkic_leader = {
					OR = {
						is_alive = no
						NOR = {
							is_courtier_of = scope:story.story_owner
							is_vassal_of = scope:story.story_owner
						}
					}
				}
			}
			trigger_else = { always = yes }
		}
		triggered_effect = {
			trigger = { always = yes }
			effect = { end_story = yes }
		}
	}

	# 中间事件
	effect_group = {
		days = { 200 350 }
		chance = 50
		triggered_effect = {
			trigger = { always = yes }
			effect = {
				story_owner = {
					trigger_event = {
						on_action = hd_wuhu_frontier_ongoing
					}
				}
			}
		}
	}

	# 索封
	effect_group = {
		years = { 5 10 }
		chance = 100
		trigger = {
			story_owner = { is_available = yes }
		}
		triggered_effect = {
			trigger = { always = yes }
			effect = {
				story_owner = {
					trigger_event = {
						on_action = hd_wuhu_frontier_end
					}
				}
			}
		}
	}

	# 收留者变成无地：结束
	effect_group = {
		days = 1
		trigger = {
			story_owner = { is_landed = no }
		}
		triggered_effect = {
			trigger = { always = yes }
			effect = { end_story = yes }
		}
	}
}
