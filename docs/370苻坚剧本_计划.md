## 目标
1. 新增一个 370 年开局的书签，主角苻坚，开局时前秦伐前燕之战已经在打，可以直接开新档。
2. 领土、人物、头衔都建在本 mod 的地图和人物库上。史实尽量准确，飞地逐个列出原因。
3. 184、218、253、304、346、404、531 七个已有开局完全不受影响。郡及以下的法理一行不改。
4. 只做中文本地化，只考虑新存档，不启动游戏验证。

**370 与 531 的根本区别**：370 夹在 346 和 404 之间。370 的头衔条目会漏进 404、531，新人物会漏进 346、404。所以要照 304 的写法加撤销文件（第 5.5 节），人物生卒也要按规则定（第 3.4 节）。

## 1. 开局日期
- **默认 370.2.13**，即晋太和五年、秦建元六年、燕建熙十一年正月朔（丁丑）。
  - 换算：儒略历，Meeus 朔望公式算到洛阳地方时，月序按中气定（含雨水者为正月）。
  - 对照已知日子，推算一致：
    - 袁真卒于太和五年二月癸酉 = 370.4.10；
    - 简文帝崩于咸安二年七月己未 = 372.9.12，与库中 `si_ma_yu_2` 卒年相同；
    - 桓温卒于宁康元年七月己亥 = 373.8.18。
  - 369 年有闰月（闰四月），370 年无闰，372 年闰三月。
- 开局时的形势：
  - 369 年十二月，王猛率梁成、邓羌，步骑三万攻洛阳，开局时正在围城。
  - 370 年正月，燕乐安王慕容臧率兵救洛阳，在石门、荥阳一带与秦军相持；洛州刺史慕容筑随后以金墉降秦（《资治通鉴》卷一〇二，只记"正月"，没有日子）。
  - 开局取正月朔，洛阳仍属燕，所以战争开局就在打。
- 两个备选，都不推荐：
  - 370.8.8（七月朔）：王猛攻壶关、杨安攻晋阳的时候。洛阳已经归秦，开局少了洛阳一仗。
  - 370.11.5（十月朔）：潞川之战前，燕已经只剩邺城一线，形势接近一边倒。
