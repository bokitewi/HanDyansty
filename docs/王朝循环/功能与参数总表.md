# 功能与参数总表

当前源码核对日期：2026-09-13。路径均相对 mod 根目录；完整逐文件定位见 [源码文件索引](源码文件索引.csv)。状态含义：**已接入**表示有实际脚本链；**有限接入**表示明确限定了入口范围；**关闭/缺失**表示不可当作可玩功能。所有游戏内表现仍待验证。

## W/H 与时代判定

| 项目 | 数值/规则 | 权威位置与维护约束 |
|---|---|---|
| W | 原始 0～2000，显示 0～100 | `situation:dynastic_cycle.var:hd_dc_pressure_raw` |
| H | 原始 0～2000，显示 0～100 | `situation:dynastic_cycle.var:hd_dc_prosperity_raw`；不与 W 互为补数 |
| 档位 | W <20、20～<40、40～<60、60～<80、80～100，内部档号 1～5 | `hd_dc_pressure_band_value`；20/40/60/80 恰好进入高档 |
| 增量写入 | `hd_dc_change_points_effect` 的 W/H 参数为原始点 | 唯一增量写入接口，记录来源、请求、实际增量、日期与序号 |
| 节点收据 | `hd_dc_commit_point_receipt_effect` 的 W/H 参数为显示点 | 内部乘 20；需要真实持久收据；不要把原始值再传入造成放大 |
| 普通事件年度净额 | W ±120 原始点，即显示 ±6 | `hd_dc_ordinary_annual_w_limit`；净额而非每次绝对值累计，不限 H |
| 原生时代进度 | 继续独立存在 | 催化剂保留原生结果；W/H 不直接镜像阶段进度 |
| 无霸权 | 连续 12 个月 | `hd_dc_absent_wait_months` |
| 低控制 | 真实控制率 <50% 连续 24 个月 | `hd_dc_enter_percent`、`hd_dc_low_control_wait_months` |
| 恢复 | 真实控制率达到 65%，连续 60 个月 | `hd_dc_restore_percent`、`hd_dc_restore_wait_months` |
| 夺取天命决议 | 决议原 80%条件与交接奖励保留；退出交给判定器 | 决议条件计入朝贡与时代真实领地口径不可混为一项 |

集中参数：`common/script_values/hd_dc_parameters.txt`。档位及郡存量：`hd_dc_pressure_values.txt`。政治快照、计时与阶段路由：`common/scripted_effects/hd_dc_era_effects.txt`。不要只改中文显示或调试按钮数值而遗漏正式 script value。

郡存量周期并非永久不重启：在适用观察中恢复第一档并连续满足60个月恢复等待后，清除旧周期基准/处理账，下一危世周期重新取基准；不返还已损失的控制/发展。回到高档会打断恢复等待，离区或观察区间无法证明连续性时不能借机结清旧周期。对应 `hd_dc_county_recovery_wait`、`hd_dc_highest_loss_band`、`hd_dc_pressure_interval_unproven`。

F 的人物倍率函数在群雄割据时另乘 1.5，合计上限 3；只在调用该函数且满足区域条件时应用，不能把它当成所有数值的通用乘数。概率采用 `100 × (1 − (1 − p0/100)^m)`，p0 单位为百分数。函数 `hd_dc_hazard_probability_value` 自身不抽随机数。不要在入口、适配器、结果三层重复乘倍率。
