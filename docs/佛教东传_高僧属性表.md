## 0. 通用规则

改下面任何一条，全表跟着改，不用逐行动手。

### 0.1 分档

数值参照：蔡邕 `cai_yong` 史书基础学识 20。

| 档 | 谁 | 基础学识 | 教育 | 神学家特质 `theologian` |
|---|---|---|---|---|
| 甲 | 宗师、译经巨匠（7 人） | 16–18 | `education_learning_5`（学识 +10） | 都给（学识 +3） |
| 乙 | 重要译经者、学派先驱（20 人） | 14–16 | `education_learning_4`（+5） | 只给开学派的：道生、慧思、吉藏 |
| 丙 | 一般译经僧、行者（18 人 + 备选） | 11–13 | `education_learning_3`（+3） | 不给 |

### 0.2 其余特质的给法

- **天赋**：史载早慧、过目成诵的给 `intellect_good_1/2/3`（全属性 +1/+3/+5）。
- **神异**：以咒术、预言、神迹著称的给 `lifestyle_mystic`（学识 +1）。
- **远行**：西行或遍游诸国的给 `lifestyle_traveler`。
- **个人特征**：医方给 `lifestyle_physician`；造像给 `architect`；相貌突出给 `beauty_good_1` 或 `beauty_bad_1`。
- **身份**：每人都给 `historical_character`。`devoted`（原版僧侣特质）本身没有属性加成。

### 0.3 其他属性和性格

- **其他属性**：外交 6–12（弘法、交游、劝谏的偏高）；管理 3–12（组织僧团、主持寺务的偏高）；谋略 2–10（神异、预言的偏高）；军事 0–6；武艺 2–6。
- **性格**：每人正好 3 个，按传记取，已检查没有对立组合。`eccentric` 与 `stubborn` 互斥，没有同时给。`reclusive` 不属于性格类，不用。

### 0.4 怎么读这张表

- **学识合计** = 基础学识 + 教育 + 天赋 + 神学家 / 神秘主义者 / 医者。性格带来的加成不算在内。
- **属性**列按 外交 / 军事 / 管理 / 谋略 / 学识 / 武艺 的顺序写。
- **年份**：「史载」表示有明文；「拟」表示史料没有，按前后事件推估，最需要审。

### 0.5 文化

- 中土僧人：按出生地取本 mod 的州别文化。
- 西来僧人：安息 → `persian`；月氏 → `tocharian`；康居 → `kangju`；龟兹 → `kucha`；天竺 → `hindustani`，北天竺拟 `kashmiri`。
- `han` 文化键在本 mod 的文化文件里没找到定义，但人物里用了 6,128 次，实际能用，实施时再核实。
