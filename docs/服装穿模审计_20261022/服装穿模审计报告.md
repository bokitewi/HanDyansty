# 服装穿模审计报告（2026-10-22）

触发：玩家截图——秦天子苻坚，匈奴重甲（`hd_frontier_xiongnu_heavy_dark`）+ 黑色尖顶盔，用户指认「手臂/手穿进胸甲」，并推测 mod 内所有服装都有此问题。
范围：HanJIn_Clothes 里全部男装上衣 33 件（`m_clothes`），对照原版男装 179 件。未启动游戏，全部为离线运算。

## 一、结论（先说）

1. **没有发现「全体服装系统性穿模、明显比原版差」的证据。** 静态内陷率、躯干体量、姿势穿插三项指标，mod 服装都落在原版分布范围内，只是整体略偏鼓（见第三节）。
2. **匈奴重甲本身有两处明显的结构缺陷**，在渲染图里肉眼可见：宽圆筒/穹顶形的胸甲，以及一片片漂浮的平面毛皮肩甲（与胸甲互相穿插，绿色碎片戳出胸甲边缘）。「夫妻/贪婪」类姿势下，一侧前臂会陷进胸甲边缘。
3. **未能复现截图里的「严重」程度。** 离线渲染用的是未变形的基础身体（没有胖/壮/老等体型），而截图人物看起来偏胖；这一条没有验证。

## 二、原版机制核对（排除项）

- 原版服装靠 accessory 里的 `set_tags = "shrink_arms,shrink_chest,shrink_belly..."` 触发 `gene_shrink_body`（`common/genes/10_genes_special_misc.txt`），把衣服下的身体缩小，避免皮肤顶出衣服。
- mod 的 `HanJIn_Clothes/gfx/portraits/accessories/*.txt` 里，上衣/腿装都已带 shrink 标签（匈奴重甲：`shrink_arms,shrink_chest,shrink_belly,short_skirt`）。**这一项不是原因。**
- 混合形状（`_bs_fat/gaunt/musc/old/dwarf`）：mod 服装每件都有，且顶点数与基础网格一致。生成方式是「取最近的身体三角形，按重心坐标搬运原版身体混合形状的位移」（`tools/hd_tw3k_portrait_build.py:657-702`），对紧身的衣服没问题，对宽松/漂浮的部件（毛皮肩甲、披风）只是近似。

## 三、量化结果

### 3.1 静态内陷率（服装顶点落进身体表面以内超过 1 单位的比例；身体已套用 shrink 与体型变形，服装套用自己的 bs）

| 体型 | 原版中位 / 75% / 90% / 最大 | mod 中位 / 75% / 90% / 最大 |
|---|---|---|
| 基础 | 4.3% / 5.7% / 8.0% / 58.7% | 5.5% / 6.9% / 8.7% / 21.3% |
| 胖 | 3.4% / 4.4% / 6.3% / 62.5% | 4.7% / 5.3% / 8.2% / 20.0% |
| 瘦 | 10.6% / 13.8% / 16.5% / 61.7% | 11.5% / 12.9% / 13.8% / 26.8% |
| 壮 | 4.0% / 5.1% / 7.2% / 57.2% | 4.6% / 5.5% / 6.7% / 15.4% |
| 老 | 4.8% / 6.1% / 8.0% / 57.6% | 6.3% / 7.7% / 9.8% / 23.1% |
| 矮 | 4.1% / 5.0% / 7.1% / 55.7% | 5.0% / 6.3% / 7.7% / 14.6% |

mod 比原版整体高约 1 个百分点，没有跳出范围。离群件：`hd_historic_sabre_infantry_01`（基础体型 21% 顶点在身体内，紧身衣）。领口/护颈类部件因身体颈口是开口网格，数值不可靠，未当作问题。

### 3.2 躯干体量（躯干高度带内，服装顶点到缩小后身体表面的距离）

- 原版各件中位数：10% / 50% / 90% 分位 = 7.2 / 8.4 / 10.3 单位；mod：8.1 / 9.2 / 10.2。
- 90% 分位：原版 9.4 / 11.5 / 15.1；mod 11.7 / 13.5 / 15.0。
- mod 平均偏鼓约 0.8 个单位，匈奴重甲中位 10.3、p90 15.0，处于 mod 偏高端但未越界。

### 3.3 姿势穿插（`tools/hd_tw3k_posetest.py` 原有脚本，9 个原版动画，身体未收缩=偏保守）

以 idle_1 为例：原版 war_nob_01 穿插顶点 97、war_02 176；匈奴重甲 胸甲 38 + 袖 84 + 领 5 = 127。量级相当。

### 3.4 姿势渲染（本次新增）

`图/sheet_cmp.png`：原版 war_nob_01 / war_02 与匈奴重甲在 bold、greedy、cynical、honorable 四个姿势下的正面对照。原版衣服的袖子与躯干贴着身体做，手臂始终在甲外；匈奴重甲的胸甲是宽圆筒，肩甲毛皮是漂浮碎片。
`图/sheet_mod1_greedy.png`、`图/sheet_mod2_greedy.png`：mod 33 件上衣在 greedy 姿势下的总览。其余件肉眼看没有明显的手臂陷入，较差的是匈奴重甲、匈奴贵族甲（毛皮碎片）、南蛮肩甲（边缘锯齿）。

## 四、未覆盖 / 未验证

- 胖/壮/老等体型下的姿势渲染没做：Blender 导入后顶点顺序与原文件不同，无法直接把混合形状套到导入的身体上（可用最近点映射解决，尚未做）。静态内陷率里已含体型变形，结果见上表。
- 头盔 / 头饰 / 腿装 / 女装没审计；10-19 的帻外扩已处理过 6 件头饰。
- 游戏内实际用哪个待机动画，没有读到；渲染用的是 `male_body_AI_*_asia` 四个。
- 没有启动游戏，全部为离线结果，运行时表现未知。

## 五、可选修法（尚未动任何 mod 文件）

A. 只修匈奴重甲：把胸甲向身体收拢到原版体量（中位 ≈ 9）、重做毛皮肩甲（贴肩弧面，不再漂浮），再对前臂留出间隙。
B. 先补做胖/壮体型姿势渲染，再决定要不要全体收窄。
C. 让用户在游戏里确认「哪个姿势、什么体型、什么角色」复现，再据此修。
