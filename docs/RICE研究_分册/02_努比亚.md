### 努比亚（Nubia / nubia）

## 0. 一页速览

- **包的身份**：`common/on_action/RICE_game_start.txt:123` 写着 `RICE_setup_nubia_flavor_pack_effect = yes # Heirs of Kush 09/30/25`，是 RICE 较新的大包之一（2025-09-30 发布）。
- **两个"局势"（situation）是骨架**：
  - `RICE_nile_river_situation`：尼罗河水情，6 个阶段（正常/高/很高/泛滥/低/很低），每年换一次，1 个子区域，按政体分 2 个参与组。
  - `RICE_nubia_baqt_situation`：巴克特条约（Baqt，7 世纪阿拉伯–努比亚和约），2 个阶段（和睦 accord / 失和 discord），2 个子区域（埃及、努比亚），按文化分 2 个参与组，催化剂 42 个。
- **人物故事靠 RICE 跨包的"历史志向"（historical aspiration）框架**：本包给 7 位历史人物各配一套"开场事件 → 年度达成检查 → 完成事件"，还有 Niuty 叛乱（双视角）、Eldad ha-Dani 讲故事、Marianos 追逃奴信件链等专门事件链。
- **目标任务的载体**：局势阶段、志向（important_action 提醒 + 修正说明）、两步式决议（`decision_option_list_controller` 小部件）、一次性大决议（尼罗河帝国、苏丹文化、重建 Banganarti 教堂）。
- **接入本体**：全部是在原版钩子上追加（on_game_start、yearly/three/five_year_playable_pulse、on_title_gain、on_war_started、on_travel_plan_start/movement），没有覆盖原版文件；地图上的改动（授地、改信仰、放特殊建筑、改文化传统）全在开局效果里运行时完成。

## 1. 主题与史实背景

**地区**：中世纪努比亚（今苏丹北部至中部）及其周边：

| 政治体 | RICE 里的对应 | 说明 |
|---|---|---|
| 马库里亚 Makuria（首都栋古拉） | `k_nubia`，本地化改名为 "Makuria"（`localization/replace/english/RICE_nubia_replace_l_english.yml:4`） | 主角国 |
| 诺巴迪亚 Nobadia / Nobatia（北部边区） | `d_nobatia`，总督称 Eparch，即"山之主"（Lord of the Mountain） | 与埃及接壤的边境长官 |
| 阿洛迪亚 Alodia（首都索巴） | `k_alodia`，挂在新建的 `e_nubia` 下（`common/landed_titles/00_RICE_nubia_titles.txt:26-64`，注释说改编自 Ibn Battuta's Legacy） | 南方王国 |
| 阿斯旺（埃及一侧） | `c_aswan`，其持有者是"阿斯旺总督" | 巴克特在埃及一侧的执行者 |
| 达尔富尔的 Daju / Tora、科尔多凡的 Nuba、南方尼罗特人（Dinka/Luo 等）、贝贾人 | 改县文化、宗教、新传统 | 周边族群 |

**年代与开局**：RICE 自己的三个书签都有努比亚人物可选：
- 867：马库里亚国王 Georgios，附带可选的 Merki、Niuty（`common/bookmarks/bookmarks/RICE_867_bookmarks.txt:438-475`）。
- 1066：诺巴迪亚总督 Marianos，附带王子兼大主教 Georgios、副总督 Mena（`common/bookmarks/bookmarks/RICE_1066_bookmarks.txt:578-622`）；同书签还有 Daju 首领 Kusbur。
- 1178：Moses Georgios，附带总督 Adam（`common/bookmarks/bookmarks/RICE_1178_bookmarks.txt:295-310`）。

代码用 `current_date` 区间判断书签（850–900、1000–1100、`game_start_date = 1178.10.1`），所以任何落在区间里的自定义开局也会触发。`current_date < 700.1.1` 时会设 `RICE_game_started_on_TFE_start_date`（`common/on_action/RICE_game_start.txt:40-47`），用来在 The Fallen Eagle 的古代开局里关掉一部分内容（例如 `common/decisions/RICE_nubia_decisions.txt` 里多个 `is_shown` 开头的 `NOT = { has_global_variable = RICE_game_started_on_TFE_start_date }`）。

**史实依据**（作者在注释和"Historical Context"文本里写得很明白）：
- 巴克特条约、马库里亚与埃及的长期和平贸易；Georgios 年轻时去巴格达重议巴克特、后来侄子 Niuty 与沙漠军阀 al-Umari 勾结叛乱（`nubia.0060.info`，`localization/english/rice_nubia_l_english.yml` 中 `nubia.0060.info`）。
- 卡斯尔伊卜里姆（Qasr Ibrim）出土的努比亚官方文书：总督与阿斯旺总督之间的往来信件、逃奴追捕、土地买卖见证——RICE 直接把这些文书节选改写成事件文本（见第 5.4、9.8 节）。
- 1066 年前后法蒂玛王朝"大饥荒"内战（土耳其军团 vs 非洲军团、太后 Rasad、Nasir al-Dawla、Badr al-Jamali），由 `nubia.0012` 做开局简报。
- 1170 年代萨拉丁兄弟攻努比亚后的休战（Moses Georgios 开场事件 `nubia.0124` 把萨拉丁放在下角立绘）。
- 1220 年后努比亚衰落：开局日期 ≥1220 时巴克特直接切到"失和"（`common/scripted_effects/RICE_nubia_effects.txt:3186-3196`）。
- 人物考据极细：例如 `history/characters/RICE_nubia.txt:52-60` 的注释说明 Eionñoka 是卡斯尔伊卜里姆文书中社会网络很广的女性，于是以她为中心重建了整个家族。

### 3.4 年度脉冲：随机风味事件

本包的 35 个"通用风味事件"（0260–0294，连续编号）不自己挂钩子，而是写进 RICE 总的随机池：

| 池 | 挂载 | 本包事件 |
|---|---|---|
| `RICE_events_yearly_pulse` | `yearly_playable_pulse`（`common/on_action/RICE_events_on_actions.txt:907-921`） | 0261、0262、0264、0266、0270、0271、0278、0279、0283–0285、0288–0290、0294（`:1433-1448`） |
| `RICE_events_tri_yearly_pulse` | `three_year_playable_pulse`（`:924-929`） | 0260、0263、0265、0269、0274–0276、0280、0281、0287、0291（`:1737-1748`） |
| `RICE_events_five_yearly_pulse` | `five_year_playable_pulse`（`:931-938`） | 0273、0277、0292、0293（`:1960-1964`） |
| `RICE_events_courtier_yearly_pulse` | 同上 | 0080 尼罗特人廷臣（`:2076-2077`） |
| `RICE_travel_events_common` / `_uncommon` | `on_travel_plan_movement` → `RICE_travel_random_event_tombola`（`common/on_action/RICE_travel_on_actions.txt:2-7, 433-439`） | 0267、0268、0272、0286（`:499-503`）；0282（`:559-560`） |

每个池的写法相同：`chance_of_no_event` 按游戏规则调整，加一个超大权重的空项（例如 `20000 = 0`，`RICE_events_on_actions.txt:1212`），再列上百个各包事件，每个 100 权重。由于空项权重极大，具体某个事件很少出现；能不能出现由事件自己的 `trigger` 决定（例如 `nubia.0261` 要求努比亚文化、同语言、有掌玺大臣，`events/RICE_nubia_events.txt:13829-13846`）。

## 6. 目标任务

### 6.1 局势阶段 = 区域长期目标

巴克特没有"胜利条件"，玩家的目标是让自己所在子区域保持在想要的阶段：努比亚玩家通常想要和睦（发展、少被袭），想扩张的埃及玩家可以刻意制造失和（AI 更好战、索贡更容易被接受）。因为换相需要 1000 分、日常行为只有 1–10 分，实际上很难改变（见第 10 节），更像是"历史背景温度计"。

### 6.2 志向 = 个人全局目标

见 5.1。它的界面链路是：

```
人物修正（RICE_aspiration_icon 图标，无数值）
  └─ 修正说明 = 剧情 + 目标清单（本地化 $EFFECT_LIST_BULLET$）
important_action（右侧提醒栏）
  └─ 标题/正文 = custom_loc 按 var:RICE_historical_aspiration 路由
yearly_global_pulse 检查
  └─ 完成事件：移除变量 & 修正，主奖励 + 若干"额外目标"奖励
```

注意：额外目标（bonus objectives）不出现在检查条件里，只在完成事件里 `if` 判断后追加奖励（例如 Merki 与国王的关系，`events/RICE_nubia_events.txt:4233-4267`）。

### 6.3 两步式决议：小部件选项 → 事件链 → 技能对决 → 催化剂/经验

本包有 3 个两步决议：边境管理（6 选项）、努比亚农业（5 选项）、基督徒供养人画像（3 选项）。共同结构：

```
decision.widget = {
	gui = "decision_view_widget_RICE_..."          ← 照抄原版 petition_liege 小部件改名
	controller = decision_option_list_controller   ← 原版控制器
	item = { value = X  is_valid = {...}  icon = ... }   ← 选中后 effect 里 scope:X = yes
}
effect = {
	if = { limit = { is_ai = yes }  random_list = {...} }   ← AI 不会选，作者手动随机
	else_if = { limit = { scope:X = yes }  random_list(show_chance=no 只显示成败说明)  trigger_event = ... }
}
```

边境管理决议的选项和事件：

| 选项 | is_valid | 事件链 | 技能 |
|---|---|---|---|
| 与对岸同僚通信 | 自己只持有总督或阿斯旺之一、另一方存在（`common/decisions/RICE_nubia_decisions.txt:856-879`） | 0160 写信（可附礼）→ 0161 对方读信（好/中/坏三种语气，对方回礼或回斥）→ 0162/0163 结果 | — |

成本是 `RICE_baqt_frontier_decision_cost`（失和时 ×1.25，`common/script_values/RICE_nubia_values.txt:607-622`），冷却 5 年。

### 9.1 同一个事件发给双方，只在一方执行

```
# events/RICE_nubia_events.txt:1524-1543 （nubia.0041 巴克特交换生效）

				root = scope:actor
			}

				save_scope_as = other
			}
			RICE_nubia_baqt_exchange_effect = yes
		}
		else_if = {
			limit = {
				root = scope:recipient
			}

				save_scope_as = other
			}
			show_as_tooltip = {				
				RICE_nubia_baqt_exchange_effect = yes
			}
		}
```

`RICE_baqt_frontier_officials_xp_gain_effect`（`common/scripted_effects/RICE_nubia_effects.txt:6304-6366`）：任何两位统治者完成巴克特交换，诺巴迪亚总督和阿斯旺总督（不论是谁）都会拿到小额特质经验，并收到一条 `send_interface_message`（左右图标是交换双方）。总督同时兼任阿斯旺时合并成一条消息。巧处：职位持有者能感觉到"国家大事经过我的手"。

### 9.12 兼容桩：用文件名排序覆盖

```
# common/scripted_triggers/00000000_compatibility_triggers.txt:12-22
roa_is_active = {
	always = no
}
paganism_plus_is_loaded = {
	always = no
}
ibl_is_loaded = {
	always = no
}
```

文件名前缀 8 个 0，保证最先加载；别的 mod 用同名触发器写 `always = yes` 就能"告诉"RICE 自己在场。本包大量用 `ibl_is_loaded`（`RICE_nubia_effects.txt:103, 1882, 1909`），地理区域文件头也说明 IBL 有一份同名后缀版本专门在 RICE 之后加载覆盖（`map_data/geographical_regions/RICE_nubia_geographical_region.txt:14-15`）。BAP 则用全局变量 `bap_is_loaded`（见末节）。

## 10. 问题与局限

按把握程度排序，前 4 条是读代码可以确认的。

1. **湖神谕"派神职人员"会发两次旅行**：选项 c 在 `scope:clergy` 块里先无条件 `start_travel_plan`（`events/RICE_nubia_events.txt:936-940`），下面的 `if/else` 又在 else 分支再发一次（`:955-959`）；首都恰好就是神谕所在省时，还会同时触发延迟事件。可能导致 `nubia.0026` 触发两次或旅行冲突。"派廷臣"选项（`:863-905`）没有这个问题。
2. **追逃奴链视角错位**：`nubia.0148` 是 Mena 的事件，选项 a 成功分支发 `nubia.0151`（`:5338-5341`），但 0151 是 Marianos 视角（"我写给 Mena 的信还没到……"，`localization/english/rice_nubia_l_english.yml` 中 `nubia.0151.desc`），收件人却是 Mena。另一处调用 `nubia.0150` 是在 `scope:marianos` 里发 0151（`:5550-5557`），印证 0151 本是 Marianos 视角事件。选项 b 成功发的是 0152（抓到逃奴，正确）。很可能 a 也应发 0152。
3. **贿赂门槛与扣款不一致**：`nubia.0062`、`nubia.0063` 的大额贿赂选项，AI 门槛是 `short_term_gold >= 100`，实际扣 200（`:2196-2200`、`:2283-2287`）。
4. **跨包复制粘贴残留**：Moses Georgios / Adam 完成志向时生成的军队名为 `RICE_sicily_norman_muslim_event_troops`，兵种是西西里穆斯林的 `mubarizun/abudrar/mulaththamun`（`:4636-4647`、`:4771-4782`）；4 个完成事件的发展度奖励借用红海包的 `RICE_red_sea_al_umari_aspiration_dev_bonus`（`:2865, 2977, 4554, 4740`）。苏丹文化的家人转换效果里还留着 Volga-Finnic（莫尔多瓦包）的注释（`RICE_nubia_effects.txt:4945` 起）。
5. **局势参数形同虚设**：两个局势的参数全部不被读取（第 4.1、4.2 节），真正效果用 `situation_current_phase` 判断。巴克特有两个子区域，各自阶段可能不同，`situation:RICE_nubia_baqt_situation ?= { situation_current_phase = ... }` 读到的是整体/哪个子区域，代码里没有区分——埃及子区域失和时努比亚人的互动价格会不会也涨，我没有在游戏里验证。
6. **巴克特几乎不动**：换相要 1000 分，没有 `max_duration`，日常行为 1–10 分，一次交换才 10 分，只有两条"重大史事"（250）能明显推动。开局 ≥1220 直接切失和是唯一的大幅变化。玩家可感知的反馈很弱。
7. **"不可靠预报"可能并不不可靠**：每年新阶段开始时 6 个"预期"催化剂各 +1，只有被抽中的那一个再加 1/4/7；全脚本没有其他地方加尼罗河催化剂。若引擎在换相时清空未来阶段积分，被预报的阶段永远得分最高，预报必然应验，"不可靠/可信"只是文字；若不清空，旧年余分才会让弱预报落空。哪种成立需要实测。
8. **六个水情阶段各写一遍**：每个阶段约 330 行，`on_start` 里的预报抽签完全一样（`RICE_nile_river_situation.txt:95-306` 与 `:426-637` 等），改一个数要改六处。
9. **硬编码人物 ID**：志向检查与开局效果大量写死 `character:dongola0010`、`character:1228761`、`character:226000`（萨拉丁）等。开局效果里很多地方没用 `?=`（例如 `RICE_nubia_effects.txt:151, 193, 224`），在别的 mod 改了人物库或用户自建开局时会报错。
10. **传奇种子未判 DLC**：`create_legend_seed` 在 `nubia.0106`、`nubia.0221` 中直接调用（`:4072, 12642-12872`），没有判断是否有传奇（Legends of the Dead）功能。
11. **AI 不会用两步决议的选项**：作者自己承认，只能手动随机。小部件选项的 `ai_chance` 实际没被用到。
12. **名字生成器会留下死人**：每次"处理申诉"都造 4 个立即死亡的角色（`RICE_nubia_effects.txt:5465-5587`），长期游戏会增加存档里的死人数量。
13. **小问题**：`RICE_setup_nubia_flavor_pack_after_game_start_effect` 里有一个 limit 写好但内容为空的 `if`（`:3294-3306`），不影响结果；本地化 466 行 `"xxxxx"` 占位；1066 法蒂玛军阀的 5 个志向只写了文本没启用；圣凯瑟琳"灵感"事件的正文用 `[GetPlayer.Custom('RICE_saint_catherine_monastery_inspiration_loc')]`（`localization/english/rice_nubia_l_english.yml:2333`）读的是"本机玩家"而不是事件主角，多人游戏或旁观时可能显示别人的结果，写成 `ROOT.Char` 更稳。
14. **头衔历史与原版同键**：`history/titles/RICE_BAP_nubia_shared.txt` 第 1 块是 `k_nubia`，原版 `原版:history/titles/k_nubia.txt:1-5` 也有 `k_nubia`（只有 3 行发展度）。RICE 版先抄了同样的 3 行发展度，再加历代持有者。这不是 common 数据库，不违背"顶层键零重名"的总述；推测作者是有意让"合并"或"覆盖"两种加载结果都正确，但具体合并规则我没有实测。

## 本包可迁移的设计模式

以下每条都附一句怎么用到《汉晋春秋》，仅供参考，不代表已经决定要做。

1. **历史志向五件套**（挂牌修正 + 变量 flag → 开场事件 → important_action 提醒 → custom_loc 路由文案 → 年度检查 + 完成事件）。适合给 184/190 开局的曹操、刘备、孙坚、董卓等配"个人目标"，任务清单写在修正说明里，进度由普通决议顺手记账（`has_character_modifier` 判断后才计数）。
2. **双子区域的对立局势**：一个局势两个子区域、两种阶段、各方行为按"谁做的"记到自己子区域。可用于汉–匈奴/鲜卑"和亲 vs 寇边"、汉–羌"抚 vs 剿"。分值记住要比 1000 分低得多，或者加 `max_duration`，否则不会动。
3. **环境年度相位 + 一年预报**：用局势表现黄河水情、蝗旱、疫病；用 1 天全局变量把"今年抽到什么"传给通知事件；地方修正（如"修过的水利"）减灾。正好和本 mod 已有的灾异/天命周期对接。
4. **两步式决议**：照抄原版 `decision_view_widget_petition_liege.gui` 改名，`decision_option_list_controller` + `item` + `scope:<value> = yes`。适合屯田、水利、察举、边郡事务这类"选一种做法"的决议；记得给 AI 写随机分支。
5. **官职绑定特质 + 经验轨道**：`on_title_gain` 系列挂隐藏事件交接特质，`track` 分级。可用于西域都护、护羌校尉、度辽将军、护乌桓校尉等边官，前任保留特质当履历。
6. **信件和使者走真实旅行**：`start_travel_plan` + `on_arrival_event` + 到达时复核阵营；收信人用 `letter_event`。适合诏书、檄文、密信、求援信。
7. **史料原文进随机文书**：把居延汉简、悬泉汉简、尹湾汉简等文书节选改写成本地化，人名、上级、神名用占位符，术语用 `[Glossary(...)]` 注释，再用游戏规则开关"史实背景"。
8. **一事件多视角**：同一事件发给多方，`root = scope:actor` 时执行、否则 `show_as_tooltip`；或者同一事件用 `first_valid` 按"你是谁"给不同说明（像 `nubia.0012` 的群雄简报）。适合讨董联军、官渡前夕的局势通报。
9. **占位无地头衔承载世系，开局再授地**：不改原版（或本 mod 已有）县级历史，就能让一串历史人物以"在任者"身份存在；大厅结束后销毁占位头衔。注意这类做法与本 mod 的开局人口清理、议会预填闸门之间的先后顺序。
10. **一次性大决议 + 名字/传说选择**：用原版 `unavailable_unique_decisions` 防重复，事件里 `set_title_name` 选国号、`create_legend_seed` 选正统传说。可对应本 mod 已有的国号偏好（汉/魏/吴）与称帝流程。

## BAP 是什么

**结论**：BAP 指另一个 CK3 模组 **Africa Plus**（非洲扩展）。RICE 的注释多次写作 "BAP/Africa Plus"，例如 `common/religion/religion_types/00_dinka.txt:1` 的 `# TAKEN FROM BAP/AFRICA PLUS`、`common/scripted_effects/RICE_niger_delta_effects.txt:70` 的 `If Africa Plus/BAP is loaded`。作者信息：`history/characters/RICE_BAP_nubian_shared.txt:5-6` 写"ORIGINAL CODE FROM AFRICA PLUS / Adapted with permission from iFrunx, current maintainer of BAP as of me writing this (6/25)"；关切人宗教的注释提到"BlackEmperor's original Guanche faith in BAP"（`common/scripted_effects/RICE_guanche_effects.txt:72`）；贝贾异教的注释写"borrowed from Africa Plus by BlackEmperor/B7E7"。所以 Africa Plus 的原作者是 BlackEmperor（B7E7），2025 年中的维护者是 iFrunx。

缩写 "BAP" 的全称在 RICE 文件里没有展开。我推测可能取自作者名首字母加 Africa Plus，但没有证据；另有一批 `wap_` 前缀的键（`localization/english/wap_dynasty_names_l_english.yml`、`common/buildings/wap_duchy_buildings.txt`、注释里的 `wap_tenet_grand_pilgrimages`，`common/on_action/RICE_game_start.txt:197`），可能是该模组更早的名字留下的前缀，同样未证实。

**它与 RICE 的关系**：

1. **内容借用（经许可）**：努比亚包的马库里亚历代国王与诺巴迪亚君主（`history/characters/RICE_BAP_nubian_shared.txt`，121 个）、Nuba 人物（`history/characters/nuba_BAP.txt`）、Nuba 王朝（`common/dynasties/RICE_BAP_nubia_dynasties.txt:189` "Nuba - adapted from BAP"）、马库里亚王朝纹章（`common/coat_of_arms/coat_of_arms/00_RICE_nubia_coat_of_arms.txt:108`）、头衔历史（`history/titles/RICE_BAP_nubia_shared.txt`）都是从 Africa Plus 改编的，作者还做了修订（例如注释"Africa Plus 这里是 Stephanos，我改成 Zacharias V"）。其他非洲包也借了 Dinka/Idoism/Odinala 宗教、圣地、名单、柏柏尔文化、头饰肖像修正（`gfx/portraits/portrait_modifiers/BAP_headgear_scripted_characters.txt:1-3` 致谢 xangelo7 与 BlackEmperor，块名 `bap_headgear_scripted_characters`）、青铜铸造科技（`common/culture/innovations/bap_bronze_casting_innovation.txt`）、关切语言支柱等。
2. **运行时检测**：RICE 用 `has_global_variable = bap_is_loaded` 判断 Africa Plus 是否同时加载（推测该变量由 Africa Plus 自己在开局设置）。努比亚开局效果里，装了 BAP 就**不再**给马库里亚/阿洛迪亚/诺巴迪亚补县，只保存 scope（`common/scripted_effects/RICE_nubia_effects.txt:35-129`）；科尔多凡的朝贡安排也只在没装 BAP 时做（`:435, 1069, 1649`）。全局开局里装了 BAP 会给两个南亚异教补"适应"教义（`common/on_action/RICE_game_start.txt:191-217`）。
3. **"BAP 共享"文件的组织方式**：凡是和 Africa Plus 重叠的内容，RICE 都放进带 `BAP` 字样或注释"为与 BAP 兼容而单独成文件"的文件里，例如 `common/on_action/RICE_BAP_shared_title_on_actions.txt:1`（"kept separate to maintain compatibility with BAP"）、`common/event_themes/RICE_guanche_event_themes.txt:4`（"Separated from others for compatibility with BAP"）、`events/RICE_misc_events.txt:325`（"Formerly tuareg.0012 but moved here for compatibility with BAP"）。共享文件包括：5 个 `common/on_action/RICE_BAP_shared_*.txt`、`events/RICE_BAP_shared_misc_events.txt`（`RICEmisc.0010`，被努比亚牛祭活动使用）、`common/important_actions/RICE_BAP_shared_actions.txt`、`common/travel/travel_options/zzz_RICE_BAP_shared_travel_options.txt`、`map_data/geographical_regions/RICE_BAP_shared_region.txt`、4 个 `localization/english/RICE_BAP_shared_*`（Darfur、Omotic、Sidamic 宗教文本等）。我推测目的是：两个模组同时加载时，同名或同键内容只保留一份，避免重复定义；但我手头没有 Africa Plus 的文件，无法确认它是否用了完全相同的文件名。
4. **BAP 共享内容大多不属于努比亚**：`RICE_BAP_shared_events_on_actions.txt` 的随机事件池里是关切、尼日尔三角洲、博佐、图阿雷格、南埃塞俄比亚的事件（`:137-331`）；标题、死亡、宗教、旅行钩子服务的是尼日尔三角洲的 Ooni、马德拉木材、加纳葬礼、跨撒哈拉商人等。与努比亚直接相关的只有：人物/王朝/头衔历史三份 `RICE_BAP_nubia*` 文件、`nuba_BAP.txt`，以及活动取消事件 `RICEmisc.0010`。
