## 0. 一页速览

- **一句话概括**：北大西洋包用一套**原版“斗争”（Struggle，FP2 机制）+ 三条全局变量资源条 + 7 个故事循环 + 24 个决议**，模拟一个**不在地图上的殖民地（格陵兰）和更远的文兰**的兴衰。玩家不能直接统治格陵兰，只能从挪威、冰岛、苏格兰等“母邦”出钱、出人、出船去支援、狩猎、远征，最终把斗争带向三种结局之一，或者坐视它自然崩溃。
- **最值得学的三件事**：
  1. **地图外的地方怎么做**。CK3 地图上没有格陵兰和美洲，RICE 用全局变量（`RICE_greenland_resilience` / `RICE_greenland_networks` / `RICE_vinland_viability`）充当“看不见的领地”，斗争区域则锚定在母邦（挪威、苏格兰、冰岛等）。汉晋春秋做西域、南海、辽东海外、林邑这类“地图外/边缘”内容可以直接照搬。
  2. **故事循环 + 决议选项列表 + 进度条 GUI 三件套**。决议弹出多选项卡片（原版 `decision_option_list_controller`），卡片上方嵌进度条。选完后决议把参数写进变量，再创建故事循环；故事循环按节奏抛事件，最后一次性结算。这是 RICE 做“目标任务”的核心骨架。
  3. **“角色槽位”和“文化指针”**。历史上的红发埃里克/莱夫·埃里克松放进全局列表；如果玩家在 867 开局自己发现格陵兰，就把玩家的领队塞进同一个列表，后续文本里的“埃里克”自动换成玩家的人。新文化是动态生成的，没法用键名引用，于是 RICE 让一个死去的假人“持有”新文化，当作指针。

| 项目 | 内容 |

		RICE_north_atlantic_maintenance_yearly_global_pulse

- **融合**：→生计（:292-325）；→边缘化（:326-378）
- **生计**：→融合（:520-548）；→边缘化（:549+）
- **边缘化**：→生计（:731-759）；→**边缘化自己**（:760+）

催化剂权重：原版 `minimal/minor/medium/major/massive` = 1/3/5/10/25（原版:`common/script_values/00_struggle_values.txt:9-13`）。RICE 另外补了两档：`RICE_very_major_struggle_catalyst_gain = 15`、`RICE_historically_significant_struggle_catalyst_gain = 100`（`common/script_values/RICE_misc_values.txt:3-7`）。“历史大事”一档直接给 100，因纽特人抵达、气候变化、发现美洲这类事件因此几乎能单独推动换阶段。

**设计要点：时间漂移只出现在通向衰落的箭头上。**

- `passing_of_time_1~4` 只列在 拓殖→生计（:154-157）、融合→生计（:320-323）、生计→边缘化（:596-599）、边缘化→边缘化（:808-811）这几条路径下。
- 融合→边缘化下的时间漂移被注释掉了（:373-376）。
- 结论：**什么都不做，殖民地会慢慢滑向衰落；玩家只能靠正面行动往回顶**。两种压力出现之后，0005 每年激活更高档的漂移（`events/RICE_north_atlantic_events.txt:263-293`），衰落会加速。这个结构很适合用来写汉末“王朝周期”。

**另一个设计亮点：“成功也有代价”。** 远征文兰成功、援助文兰、建成文兰前哨，在各阶段里都被列为**推向衰落一侧**的催化剂（例如 :111-119、:136）。年度结算还会按前哨数扣格陵兰两项资源（`RICE_north_atlantic_effects.txt:845-858`）。这对应史实：文兰冒险会抽干格陵兰本来就有限的人力物力。

## 5. 人物个人故事

这一节对应用户最关心的问题：RICE 怎样把剧情落在具体人物身上。北大西洋包给出了 **8 种**写法。

### 5.1 角色槽位：“埃里克 / 莱夫等价人”全局列表

做法分三步：

1. **开局写入史实人物**。`RICE_north_atlantic_effects.txt:519-524`：

```
character:RICE_north_atlantic_001 = {
	make_unprunable = yes
	add_to_global_variable_list = {
		name = RICE_north_atlantic_erik_the_red
		target = this
	}
}
```

2. **玩家改写历史时写入玩家的人**。0161 把大远征的领队放进**同一个列表**（`events/RICE_north_atlantic_events.txt:16633-16636`）；0166 对莱夫做同样的事（:17390-17393）。领队如果在途中死亡，就 `make_unprunable`，保证存档里这个人一直可引用（:16638-16644）。

3. **剧情文本统一从槽位取人**。0001、0008、0009、0094 等事件开头都有：

```
ordered_in_global_list = {
	variable = RICE_north_atlantic_erik_the_red
	save_scope_as = erik
}
```

（events:100-103, 385-388, 414-417, 13167-13170）

本地化里写 `[erik.GetFirstNameNicknamedPossessive] voyage paved the way…`（`localization/english/RICE_north_atlantic_l_english.yml:993`）。史实开局显示“红发埃里克”，867 开局显示玩家自己派出的那个人。

> 用在汉晋春秋：可以给“首倡义兵者”“首个称帝者”“开辟西域者”建槽位。史实人物先占位，玩家或 AI 改写历史时替换成实际完成者，后续事件统一读槽位。这和本 mod 已经在做的“ID 引用改指针”是同一个思路。
> 存疑：`ordered_in_global_list` 没写 `order_by`，列表里有多人时具体取哪一个，没有实测。

### 5.2 史实人物写在 history 里，再用开局效果精修

- 21 个人物里，19 个是史实/传说人物：埃里克一家五代（含莱夫的兄弟姐妹，弗蕾迪丝带着“野心/欺诈/勇敢”特质）、伊斯莱夫主教的妻儿、西峡湾的奥顿、海泽比的伍尔夫斯坦、巴塞洛缪·莱斯利、迈克尔·司各特（`history/characters/RICE_north_atlantic.txt:44-455`）。
- 原版已有的人物不改 history，而是开局用效果**改性格和教育以贴合史料**。伊斯莱夫（原版 ID 20579）就是这样处理的：删掉原有性格特质，换成学识 4，加上勤勉/狂热/合群/公正，每个特质后面注释史料依据；挂上志向修正，设置志向变量，`set_father` 接上 RICE 新加的父亲吉苏尔（`RICE_north_atlantic_effects.txt:365-401`）。商人奥泰尔被改为管理 3 教育，并加 `do_not_generate_starting_family`，防止系统给他自动生成家人（:337-350）。

### 5.3 开局定向事件：`character:X = { trigger_event = ... }`

`RICE__game_start_effects.txt` 按书签分块，每块直接给具体人物发开场事件：

```
character:20579 = { # Isleifur
	trigger_event = north_atlantic.0270
}
```

（:194-196）

开场事件的写法（以 0270 为例，events:20047-20094）：

- 左右两个肖像分别是“老师”（不来梅的阿达尔伯特）和本人，配 `happy_teacher`、`personality_bold` 动画。
- `immediate` 里用 `show_as_tooltip` 预告志向修正，让玩家知道接下来的目标，但效果不在这里真正执行。
- 规则 `RICE_historical_context_on` 打开时，追加一段 `custom_description_no_bullet` 史实注释（`north_atlantic.0270.info`）。

0272（巴塞洛缪·莱斯利，“匈牙利出身的苏格兰人”）给了一个**身份抉择**：选项 a 保持苏格兰身份；选项 b（仅玩家可选）`set_culture = culture:hungarian` 并移除修正（events:20203-20225）。这是“扮演某人”的入口：玩家刚上手这个角色，就要决定他的文化归属。

### 5.4 史实志向：五步最小框架

这是 RICE 跨包共用的系统，北大西洋包用它给伊斯莱夫做了一条个人目标线。

| 步骤 | 做法 | 位置 |
|---|---|---|
| ① 授予 | 开局 `set_variable RICE_historical_aspiration = flag:isleifur`，并挂角色修正 `RICE_north_atlantic_aspiration_cultivate_icelands_church` | `RICE_north_atlantic_effects.txt:373-379` |
| ② 提醒 | 重要提醒 `action_RICE_historical_aspiration`：只要角色身上有这个变量，就弹出提醒，点击打开角色界面 | `common/important_actions/RICE__misc_actions.txt:2-23` |
| ③ 文本分派 | 3 个 customizable_localization（标题/行动描述/修正描述）按 `var:RICE_historical_aspiration ?= flag:xxx` 分派到各包的本地化键 | `common/customizable_localization/RICE_aspirations_custom_loc.txt:3, 128-133, 287, 414-419, 582, 709-714` |
| ④ 检测 | 年度脉冲按书签分块，逐人检查条件。伊斯莱夫：存活、在任、持有并完全控制冰岛公国、信基督教、已办斯卡尔霍特学校（旗标）、虔诚等级 ≥3 | `common/on_action/RICE_aspirations_on_actions.txt:529-548` |
| ⑤ 完成 | 0271：播放 `mx_cue_epic_sacral_moment`，`RICE_historical_aspiration_fulfilled_effect` 清掉变量（`RICE__misc_effects.txt:1608-1614`）；主奖励是虔诚、威望和冰岛各郡开发度；有附加目标旗标时再加威望 | `events/RICE_north_atlantic_events.txt:20098-20161` |

**附加目标的“监听”写法很巧。** “建大教堂/大修道院”这类效果写在诺曼底包的共用效果里。效果末尾检查角色身上有没有伊斯莱夫的志向修正，有就补一个旗标（`common/scripted_effects/RICE_normandy_effects.txt:835-840, 874-879`）。志向修正在这里同时充当“监听标签”，不用在每个调用点单独判断是不是伊斯莱夫。

主目标里“办学校”的旗标，由冰岛决议「建立斯卡尔霍特学校」的事件 0027 设置（events:1663）。这一步同时通知冰岛的其他玩家（:1672-1690），通知用一个临时旗标防止重复（:1668, :1691-1697）。

### 5.5 LAAMP 史实冒险者（无地冒险者 + 书签）

链路如下：

1. **定义冒险者头衔**：`d_laamp_RICE_*`，`landless = yes`、`destroy_if_invalid_heir = yes`、`dlc_feature = roads_to_power`，`ai_primary_priority` 加 -1000，防止 AI 把它当主头衔（`common/landed_titles/00_RICE_north_atlantic_titles.txt:1-78`）。
2. **history 里授予**：`history/titles/RICE_laamp_titles_1066.txt:25-33`（莱斯利）、`:311-319`（奥顿）、`RICE_laamp_titles_1178.txt:3-11`（司各特）、`RICE_laamp_titles_867.txt:112-138`（奥泰尔、伍尔夫斯坦）。都调用原版 `create_landless_adventurer_title_history_effect`，并设置 `adventurer_creation_reason = flag:historical`。
3. **开局设定营地宗旨**：奥顿是探险者营，司各特是学者营（`RICE__game_start_effects.txt:1650-1658, 1703-1711`）。
4. **AI 控制时销毁头衔**：例如 `character:RICE_north_atlantic_016 ?= { if = { limit = { is_ai = yes } destroy_title = ... } }`（:1085-1092）。这样这些冒险者**只在玩家扮演时存在**，不会给 AI 世界添乱。
5. **书签条目**：`common/bookmarks/bookmarks/RICE_1178_bookmarks.txt:681-691`（司各特，头衔就是 laamp 头衔）。1066 书签里伊斯莱夫带两个儿子作备选（`RICE_1066_bookmarks.txt:8-52`），其中次子吉苏尔的 `history_id = RICE_north_atlantic_011` 引用的是 RICE 新加的人物。

### 5.6 远征领队：从普通廷臣到“探险家”

这是本包最有“个人故事感”的部分。

- **候选人挑选**（0030，events:1840-2110）：遍历廷臣，条件是原版 `is_available_healthy_ai_adult`、年龄 ≤55、不在议会、继承顺位 ≥3（“近期不会继承什么”），放进列表。按特质加权随机选出至多 3 人：已有探险家 +20，野心/勇敢/勤勉 +5，满足/懦弱/懒惰 -5。权重还考虑**文化的性别从军规则**：用 `has_cultural_parameter = martial_custom_male_only_combatant / has_access_to_shieldmaidens` 给异性候选人减 15 或 30。三人用 `lower_left/center/right_portrait` 同屏展示。
- **玩家也可以先不选**：选项 d（仅玩家）先不指定领队。之后可以对廷臣用互动「任命远征领队」：互动的 `is_shown` 要求 actor 有进行中的远征、而故事里还没有领队（`common/character_interactions/RICE_north_atlantic_interactions.txt:11-27`）。接受后**直接往故事里写变量**（:48-58）。被 0030 列为候选人的廷臣 120 天内自动接受（:297-309）。也可以花钱（`pay_to_lead_expedition` 选项）或用把柄。
- **出航时兜底**：故事第 90 天触发 0033。如果故事里仍没有领队，就用模板 `RICE_expedition_crew_member_template` 现场生成一个（events:2293-2311）。
- **状态标记**：出航后领队获得临时特质 `RICE_exploring_western_seas`（不能结婚、不能生育、每月 +1 威望，`common/traits/RICE_north_atlantic_traits.txt:195-216`）。同时借用原版旗标 `blocked_from_leaving`（防止廷臣离开）和 `planning_an_activity`（防止被别的活动征用）。
- **成长**：归来时调用 `RICE_north_atlantic_explorer_trait_or_experience_effect`。没有探险家特质的先获得特质，已有的随机往“发现者”或“使节”轨道加 25 经验，上限 100（`RICE_north_atlantic_effects.txt:3478-3531`）。特质名用 `has_trait_xp` 三档分派成“探险家 / 老练探险家 / 多产探险家”（`RICE_north_atlantic_traits.txt:87-135`）。这个写法明显照抄了原版 EP2 旅行者特质，连 `#TODO_CD_EP2 standardize MAX` 这条注释都一起抄了过来。
- **继承交接**：故事的 `on_owner_death` 如果发现继承人恰好就是领队本人，就提前结束远征，并给他结算经验（`RICE_story_cycle_north_atlantic_expedition.txt:148-183`）。否则把领队转入继承人的宫廷，并 `make_story_owner = player_heir`（:185-200）。

### 5.7 随机出身故事：廷臣出场事件（0090–0095）

以 0090「奴隶/仆人因才能被注意到」为例（events:10931+）：

- 70% 概率是“奴隶”分支，30% 是“自由人”分支。标题、描述、肖像动画、**服装**全部用 `triggered_desc / triggered_animation / triggered_outfit = { outfit_tags = { beggar_rags } }` 切换（:10959-10976）。
- 来源地按权重随机：盖尔人 70%、欧洲其他地方 5% 等。先 `every_county_in_region` 把符合条件的郡放进列表，`random_in_list` 取一个，再用该郡的文化、信仰、礼仪生成角色（:10998-11058）。

### 6.2 小型远征：故事循环“四件套 + 计数器结算”

**① 决议写参数**（`decisions:3413-3692`）

- 选项列表有 4 项：AI 专用项（`is_shown = { is_ai = yes }`）、赫卢兰、马克兰、文兰。
- 玩家项的 `is_valid` 都带 `is_ai = no`，AI 只能走自己那一项。
- 文兰项在“边缘化”阶段不可选（:3580-3590）。
- effect 用 `scope:RICE_north_atlantic_helluland_option = yes` 判断玩家选了哪一项，写入 owner 变量 `RICE_expedition_destination_pick = flag:helluland`。
- AI 项按权重随机目的地：好结局后、文兰已定居后，马克兰和文兰的权重上调（:3621-3670）。

**② on_setup 转存**（`RICE_story_cycle_north_atlantic_expedition.txt:3-24`）

```
on_setup = {
	set_variable = {
		name = RICE_expedition_destination
		value = story_owner.var:RICE_expedition_destination_pick
	}
	story_owner = {
		remove_variable = RICE_expedition_destination_pick
	}
	if = {
		limit = { exists = story_owner.var:RICE_expedition_leader_choice }
		set_variable = {
			name = RICE_expedition_leader
			value = story_owner.var:RICE_expedition_leader_choice
		}
		story_owner = { remove_variable = RICE_expedition_leader_choice }
	}
	...
```

决议和事件不能直接给“还没创建的故事”传参，所以先写在 owner 身上，`create_story` 之后由 `on_setup` 搬进故事，再把 owner 身上的清掉。之后紧跟着把十几个计数器初始化为 0（:25-94）：成功/失败、神器数、金币/威望/虔诚的得失、三项资源的增减。

**③ effect_group 用变量串成剧集**（:662-759）

```
# First "episode"
effect_group = {
	days = { 30 120 }
	trigger = {
		exists = var:RICE_expedition_set_sail
		exists = var:RICE_expedition_leader
		NOT = { exists = var:RICE_expedition_episode_one }
	}
	first_valid = {
		triggered_effect = {
			effect = {
				set_variable = { name = RICE_expedition_episode_one value = yes }
				var:RICE_expedition_leader = { save_scope_as = leader }
				story_owner = {
					trigger_event = { on_action = RICE_ongoing_north_atlantic_expedition_events }
				}
			}
		}
	}
}
```

- 每一集都要求前一集的旗标已存在、本集旗标还不存在，因此三集严格按顺序发生。
- `days` 是“检查间隔”，不是“绝对时刻”，所以实际时间有随机抖动。
- 每集都从 on_action 事件池里抽一个随机事件（`common/on_action/RICE_north_atlantic_story_cycle_on_actions.txt:3-30`，23 个事件，马克兰伐木类权重 75，其余 50）。

**④ 事件池按目的地过滤，并受修正影响**

以 0068（马克兰好木材）为例，events:10162-10236：

- `trigger = { scope:story.var:RICE_expedition_destination = flag:markland }`：只有目的地是马克兰才会抽到。
- `weight_multiplier`：援助格陵兰时修过牧场小屋（拥有 `RICE_north_atlantic_built_shielings` 修正）的人，抽到它的概率 ×1.25。
- **奖励先记账，最后统一发放**：选项只显示“预计获得金币/韧性”的 tooltip，`hidden_effect` 里只给故事计数器 +1。

**⑤ 归来时统一结算**（故事 :263-660 → 事件 0034）

- 比较各计数器的增减。例如韧性增加次数 ≥1 且大于减少次数，才判定为“韧性上升”；上升幅度按次数分档（1 次 1–10、2 次 1–20、3 次 1–30，:280-330）。
- 0034 里：失败数大于成功数算远征失败（+50 威望）；否则算成功（+200 威望，领队王朝加声望）。按计数生成神器（北极神器或原住民神器）。按 `RICE_expedition_modifiers` 变量列表挂对应的 10 年修正，例如“原住民联系”“原住民传说”（events:2766-2800）。最后按目的地激活成功或失败催化剂（:2672-2750）。
- 神器在事件窗口里显示：`artifact = { target = scope:native_american_artifact position = lower_center_portrait }`（events:2460-2464）。

**这么写的好处**：中途的随机事件可以有很多个，彼此独立、可以随时增删，但奖励只在终点出现一次，玩家能看到一张清晰的“远征总账”。数值平衡也只需要调整 0034 这一个地方。

### 6.3 诺德塞图尔海象狩猎：预掷结果 + 计时器变量 + 季节门槛

- **季节**：决议 `is_valid` 要求 `current_month <= 4`（decisions:2471-2474）。故事 `on_setup` 用 `trigger_on_next_date = 6.1` 安排在**下一个 6 月 1 日**出发（`RICE_story_cycle_north_atlantic_nordsetur_hunt.txt:12-15`），对应北极夏季狩猎季。
- **预掷结果**：0120 出发时一次性算出成功率（events:14502-14570）。成功率的组成：基础 20，加上韧性×0.05、外交×0.5（上限 15）、管理×1.25（上限 15），再按阶段、规模（大型 +10、超大型 +20）、是否修过狩猎站调整。掷中就给 owner 挂一个 365 天的旗标 `RICE_walrus_hunt_success_guaranteed`。同时给故事设一个 75 天的计时变量 `RICE_walrus_hunt_timer`。
- **两个 effect_group 用计时器分流**：
  - 失败组（20–75 天检查）：要求计时器还在、没有成功旗标 → 失败（0121）（故事 :71-182）。
  - 成功组（80–90 天检查）：要求计时器已消失 → 成功（0122）（:185-508）。
  
  这样结果在出发时就定了，但玩家要等到失败事件“可能出现的窗口”过去，才知道是否成功，悬念得以保留。
- **结果附带随机插曲**：0122 有 50% 概率不出插曲，直接结束故事；否则在 `after` 里从 6 个插曲事件中随机触发一个：友好/敌对原住民、遇难猎队、救援其他猎队、独角鲸牙、北极熊（events:15153-15196）。
- 作者注释写明：0120 的成功率**不能写成 script_value**，只能内联（:14503，“Doesn't work as a scripted value for some frustratingly bizarre reason”）。

### 6.4 援助格陵兰/文兰：8 种援助 + 故事循环

- 决议 `RICE_north_atlantic_support_greenland`（decisions:2725-3164）。冷却时间是 **script_value**：`cooldown = { days = RICE_greenland_support_cooldown_time }`（:2737）。融合阶段 5 年、默认 10 年、边缘化 15 年（`common/script_values/RICE_north_atlantic_values.txt:250-279`）。
- 8 个选项：基础物资、移民、粮食、材料、教士、狩猎站、牧场小屋、教堂，外加 AI 专用项。每个选项对应不同的成功/失败催化剂权重（struggles:87-94 / 123-130）。修建类援助（狩猎站、牧场小屋、教堂）还会挂角色修正，这些修正又反过来提高狩猎和远征事件的权重，例如 0068 的 `weight_multiplier`。
- 故事 `support_greenland`：失败组先掷失败率（基础 25，生计 +5、边缘化 +10），失败扣资源；成功组发放资源（`RICE_story_cycle_north_atlantic_support_greenland.txt:31-182, 185+`）。
- **流放/遣送**是另一条“出人”的通道（互动 4 个，interactions:333-3240）。目的地有东聚落/西聚落/文兰三个 `send_option`：东聚落加联系，西聚落加韧性，文兰加可行性（events:19450-19470）。被送走的人用风味死因离开地图（`death_reason = death_RICE_north_atlantic_greenland_exile`，死因列表见 `common/deathreasons/RICE_north_atlantic_deaths.txt`）。玩家版和 AI 版分成两个互动，作者注释原因是“没法让 AI 在 send_options 之间做选择”（interactions:370, 1100）。AI 版在 `on_accept` 里自己 `random_list` 选目的地（:1164-1200）。

### 6.5 斗争：阶段效果、参数与结局决议

**参与资格**：文化包括 norse/norwegian/icelandic/inuit/dorset，信仰包括天主教、东正教、北欧异教、因纽特异教，`involvement_prerequisite_percentage = 0.4`（struggles:8-33）。格陵兰文化和文兰文化是动态加入的：

- 0161 用 `set_culture_as_involved` / `set_faith_as_involved` 把发现者的文化和信仰、以及新文化拉进斗争（events:16726-16739）。
- 两个“沉浸式”决议让玩家**主动**把自己的文化或信仰拉进斗争。条件：首都在斗争区域、区域内本文化郡 ≥10、完全控制 ≥5 个郡、威望 2 级（decisions:1781-1913）。效果见 `RICE_greenland_new_culture_involvement_effect`（effects:3344-3374）。

> 这解决了原版斗争的一个硬限制：参与文化列表是写死的，不能随剧情变化。

**阶段效果**：每个阶段分 war/faith/culture/other 四组，每组再分共同/参与者/介入者/局外者。例如拓殖阶段，参与者伯爵领税收 +10%、发展 +20%（struggles:255-258）。

**阶段参数**是 RICE 自定义的 `RICE_greenland_*` 参数（例如 :238-248、:461-473、:882-898），但它们**只在斗争界面显示文字**（本地化键 `struggle_parameter_rice_greenland_*`，`RICE_north_atlantic_l_english.yml:343-366`）。真正的效果靠 script_value 里硬编码的 `is_struggle_phase` 实现。全包 grep 不到任何 `has_struggle_phase_parameter = RICE_greenland_*`。见 §10.3。

**原版催化剂白拿**：

- 拓殖→融合列入 `catalyst_new_building_in_city / castle`（:102-103）。
- 拓殖→生计列入 `catalyst_unnatural_death_important_character / broke_truce_against_important_character / win_any_war_within_the_region`（:150-152）。

这些由原版 on_action 在区域内自动激活（原版:`common/struggle/catalysts/catalysts.txt:6, 41, 87, 103`；`common/on_action/war_on_actions.txt`），RICE 一行触发代码都不用写。

**结局决议**：写法照搬原版 FP2 结局决议。`is_invisible = yes`，只在斗争界面里出现；`extra_picture` 是斗争按钮图；`confirm_click_sound` 用 FP2 音效；成就旗标 `ach_ended_struggle`。effect 只做两件事：`show_as_tooltip` 预告，然后 `trigger_event` 到全屏结局事件。

|---|---|---|---|
| 区域融合 | decisions:8-188 | 处在融合阶段；独立；控制斗争区域 ≥50% **或**首都所在法理公国各郡开发度达标；韧性和联系 ≥850（简单 600、困难 950）；威望等级达到 high；完全控制 7 个北大西洋公国中的 ≥2 个（`calc_true_if`） | 0170：文化 / 经济 / 社群（events:17612-17719） |

### 6.7 重要提醒（important_actions）

### 6.8 唯一决议的“可撤销”写法

原版的写法是：唯一决议完成后，把旗标放进全局列表 `unavailable_unique_decisions`，`is_shown` 里检查旗标不在列表中（原版:`common/decisions/00_major_decisions_east_europe.txt:29, 88`）。RICE 冰岛/海象牙作坊决议沿用了这个写法（decisions:1174-1176, 1241-1243）。

**新东西是反向操作**：进入边缘化阶段时，0013 用 `remove_list_global_variable` 把旗标从列表里删掉，同时拆掉作坊修正（events:812-848）。“海象牙贸易中心”因此会随格陵兰衰落而消失，等局势好转后又能重建。

### 6.9 AI 跟着历史走：按日期递增的 ai_will_do

「探索格陵兰」的 `ai_will_do` 基础值 40，非北日耳曼文化 -30。950/975/1000/1025/1050 年之后分别再加 25/50/75/100/100（decisions:528-576）。「定居文兰」同理（:963-985）。867 开局时 AI 不会抢跑，但越接近史实年代越积极，AI 世界因此大致沿史实时间线发展。AI 的威望门槛也比玩家低：AI 1 级，玩家 3 级（decisions:466-479）。

## 10. 问题与局限

### 10.1 实质性 bug（静态推断，未实测）

1. **东聚落宽限计时器单位写错，自然崩溃结局基本无法触发。**
   - `common/on_action/RICE_north_atlantic_greenland_struggle_on_actions.txt:357-386` 的四个分支写的是 `years = 3650 / 5475 / 7300 / 9125`，注释分别是 “10/15/20/25 years”。显然本意是天数（3650 天 = 10 年）。
   - 实际效果：计时器持续几千年。“格陵兰终结”块要求 `NOT = { has_global_variable = RICE_greenland_eastern_settlement_abandoned_timer }`（:431），游戏期内不会满足。
   - 结论：东聚落废弃后，格陵兰只会停在“即将崩溃”状态，0009 不会自动发生，只能靠玩家主动选“放弃”结局。
2. **融合阶段的催化剂列表疑似复制粘贴错误。** 融合→生计（衰落方向）下列的是一整套**正面**催化剂（援助格陵兰、狩猎成功、因纽特人抵达等）加上时间漂移（struggles:292-325），和拓殖→融合的列表（:79-106）几乎相同。按原版斗争的语义，处在融合阶段时援助格陵兰反而会把进度推向“生计”。需要实测确认。
3. **三个结局都用融合决议作为 `end_struggle` 参数**：events:17692（融合，正确）、:17857（原住民，应该是 indigenous）、:17982（放弃，应该是 abandonment）。原版用这个参数记录结局来源，影响范围未核实。
4. **0166 结束了错误的故事**：发现文兰后，`after` 里结束的是小型远征 `RICE_story_cycle_north_atlantic_expedition`（events:17520-17525），而不是大远征 `grand_expedition`。对比 0161 结束的是大远征（:16824-16830）。大远征最终会被 600 天自毁兜底，但在那之前一直挂着。
5. **边缘化阶段把自己列为未来阶段**（struggles:760）。属于疑似无效配置，引擎对“自指阶段”怎么处理（重置进度？触发 on_change_phase？）未核实。
6. **诺德塞图尔故事的自毁组写成 `chance = 330`**（`RICE_story_cycle_north_atlantic_nordsetur_hunt.txt:513-514`）。按百分比理解等同 100，无害，但明显是笔误。
7. **静态和动态格陵兰文化混用**：
   - 867 开局发现格陵兰时，0160 生成**新的**动态格陵兰文化。

   - 后果：在动态文化存档里，这些加成可能落到一个没人使用的静态文化上。
8. **文兰“造物者”没有被清理**：0148 生成的 `vinlandic_creator_deity` 全文件只出现在 :16453-16508，没有 `death`（格陵兰版在 0161 里杀掉了）。每次定居文兰都会留下一个游荡的随机角色。
9. **年度收入只发给斗争区域内的庄园主**：通知列表来自 `every_county_in_region` 的持有者（effects:1714-1726）。但庄园提醒的本地化承诺“家族每位统治者每年都有收入”（`RICE_north_atlantic_l_english.yml:192`）。区域外参与斗争的家族成员，似乎拿不到这笔钱。存疑。

## 本包可迁移的设计模式（对照汉晋春秋）

1. **地图外领地 = 全局变量资源条 + 锚定在母邦的斗争**
   格陵兰不在地图上，RICE 用 2~3 个全局变量表示它的“健康度”，斗争区域设在能影响它的本土地区。汉晋春秋可以用来做：西域都护府（“都护威望/商路联系”）、交州海路、辽东公孙氏的海上联系、五胡内迁的“边郡安定度”。资源条配 §9.5 的进度条，挂在决议和事件里。

2. **时间漂移只指向衰落，玩家行动往回顶**
   把 `passing_of_time` 拆成多档，按“已经发生的史实压力数”每年激活更高档（§4.2、§9.2）。天然适合本 mod 的王朝周期：党锢、黄巾、董卓之乱各算一档压力，越往后衰落越快；玩家靠整顿吏治、赈灾、讨伐往回拉。

3. **故事循环四件套 + 终点统一结算**
   决议写参数 → `on_setup` 转存并清理 → effect_group 用变量串成剧集 → 中途事件只记账、终点一次结算（§6.2）。适合做出使西域（张骞、班超式）、远征南中、北伐、海上求仙这类“出发—若干插曲—归来”的任务，插曲事件池可以独立扩充。

4. **角色槽位：史实人物占位，改写历史时替换**
   全局列表存“某历史角色的等价人”（§5.1）。可以给“第一个称帝者”“讨董盟主”“迎天子者”建槽位，后续剧情读槽位，不写死人物 ID。和本 mod 已有的“ID 引用改指针”是同一思路。

5. **假人锚点当动态对象的指针**
   动态生成的文化或信仰不能用键名引用，就让一个 unprunable 的死人“持有”它（§5.8）。衣冠南渡、五胡内迁里如果要生成“侨姓文化”“杂胡文化”，可以照做。注意不要再用 `han` 当占位文化。

6. **史实志向五步框架 + 修正当监听标签**
   变量授予 → 重要提醒 → custom_loc 分派文本 → 年度脉冲检测 → 完成事件清变量；附加目标在共用效果末尾监听修正（§5.4、§9.8）。很适合给曹操（“挟天子以令诸侯”）、诸葛亮（“兴复汉室”）、孙策（“据江东”）这类人物做个人目标线，比纯事件链更轻，玩家也能一直看到目标。

7. **LAAMP 史实冒险者只给玩家**
   冒险者头衔 + history 授予 + 营地宗旨 + `is_ai = yes` 时 `destroy_title`（§5.5）。适合本 mod 的游侠、名士、隐士（例如 184 年的刘备三兄弟、许劭、管宁）：玩家可以扮演，AI 世界里不会冒出一堆无地营地。

8. **全局互斥锁 + 自毁兜底 + 全服广播**
   “天下只能有一个人先做成”的事情（首次发现、首倡、首个迁都）先上锁，故事自毁时解锁，同时广播给其他统治者（§9.7）。本 mod 的“首倡义兵”“迎奉天子”可以直接套用。注意广播时要加 `is_ai = no`，不要重复 §10.2 的性能问题。

9. **决议选项卡片：玩家多选，AI 专用项**
   原版 `decision_option_list_controller` + 自定义按钮类型 + AI 单独一项，在 effect 里随机（§9.3）。适合做“援助方式”“出使规格”“赈灾方式”这类一个决议、多种投入的玩法。

10. **按年代递增的 AI 意愿 + AI 门槛低于玩家**
    `ai_will_do` 按年份逐档加值（§6.9），让 AI 世界大致沿史实年代推进又不会抢跑。可以和本 mod 已有的历史人物出场、导演层配合，用在“三分天下”“晋灭吴”这类时间节点上。
