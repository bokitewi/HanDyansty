# 一、西西里（Sicily / sicily）

## 1. 主题与史实背景

**主题**：南意大利与西西里岛作为"三个世界交汇的边疆"——拉丁西方、拜占庭希腊、伊斯兰（阿拉伯-柏柏尔）三方在此反复争夺、混居、融合。游戏概念把它命名为"Sicilian Frontier"，说明这是一个"可重复的斗争"，涉事统治者会获得一个代表与三个世界联系的特质，三个世界的影响力用"支配度"衡量（`localization/english/rice_sicily_l_english.yml:178-179`）。

**年代与开局适配**：
- 斗争本体只要开局日期 ≥ 647 年（阿拉伯征服马格里布开始）就在开局时自动启动，并受游戏规则开关控制（`common/scripted_effects/RICE_sicily_effects.txt:1136-1152`，规则定义 `common/game_rules/RICE_game_rules.txt:412-420`）。也就是说 867、1066、1178 三个原版书签全都有斗争。
- 867 书签：巴里埃米尔国萨乌丹（`character:163094`）、塔兰托的乌斯曼、犹太学者阿布·亚伦、阿格拉布王朝增兵（`common/scripted_effects/RICE_sicily_effects.txt:442-559`）。
- 1040–1091 区间：西西里泰法内战，给岛上每个统治者推一条"非可选"开局事件 sicily.0060（`common/scripted_effects/RICE__game_start_effects.txt:443-459`）。
- 1066 书签：罗杰一世征服西西里、罗伯特·吉斯卡尔攻巴里、泰法领主 Benavert 等、君士坦丁·阿非利加努斯、巴里大主教安德烈亚斯（`common/scripted_effects/RICE_sicily_effects.txt:561-870`，`common/scripted_effects/RICE__game_start_effects.txt:415-430`）。
- 1178 书签：两个西西里相关的无地冒险者 Trapelicino、Guglielmo Grasso，以及比萨的圣博娜（`history/titles/RICE_laamp_titles_1178.txt:69`、`:113`、`:442`）。

**史实依据的呈现方式**：大量事件和决议在游戏规则 `RICE_historical_context_on` 打开时附带一段"Historical Context"说明（规则：`common/game_rules/RICE_game_rules.txt:20-34`；例：泰法背景 `localization/english/rice_sicily_l_english.yml` 中 `sicily.0060.tooltip`、萨乌丹背景 `sicily.0064.tooltip`）。历史人物文件里每个特质后都写了注释说明史料依据，君士坦丁条目甚至列了 5 个参考链接（`history/characters/RICE_sicily.txt:44-80`）。

## 3. 触发入口

### 3.1 开局：总入口 → 包设置效果

RICE 只在原版 `on_game_start` 上追加一个 on_action，然后在里面按包顺序调用设置效果（`common/on_action/RICE_game_start.txt:1-5`、`:118`）。西西里的设置效果 `RICE_setup_sicily_flavor_pack_effect`（`common/scripted_effects/RICE_sicily_effects.txt:1`）做了这些事：

1. 给原版文化加/减传统与创新（西西里文化、西库罗-阿拉伯文化、伦巴第等），并 `remove_variable = tradition_cooldown` 清掉冷却（`:19-110`）。
2. 按开局年份改县文化/信仰（`:127-160`）。
3. **给原版变量"打桩"阻止原版机制误伤**：在巴勒莫、阿格里真托等 9 个县设 `had_sicilian_county_conversion`，这是原版"西西里文化自然出现"事件用的变量，设上之后原版事件就不会把这些县变成西西里文化（`:162-215`；原版用法在 原版:`events/global_culture_events.txt`）。
4. 书签专属人物调整（见第 5 节）。
5. 按年份放置历史据点县修正（`:1059-1128`），给那不勒斯加"弗莱格雷火山区"修正（`:1130-1134`）。
6. 启动斗争并手动触发开局事件 on_action（`:1136-1152`）。
7. 预计算一次支配度（`:1165`）。

```
# common/scripted_effects/RICE_sicily_effects.txt:1136-1152
	if = {
		limit = {
			#NOT = { exists = culture:soissons }
			game_start_date >= 647.1.1 # Start of the Arab conquest of Maghreb ...
		}
		if = {
			limit = { has_game_rule = RICE_struggle_sicily_toggle_on }
			start_struggle = {
				struggle_type = RICE_sicily_struggle
				start_phase = struggle_RICE_sicily_phase_borderland
			}
			struggle:RICE_sicily_struggle ?= {
				trigger_event = { on_action = RICE_sicily_struggle_starting_events }
			}
		}
	}
```

注意斗争定义里的 `on_start` 被注释掉，注释写"Not working for some reason, moved to wherever struggle is triggered"（`common/struggle/struggles/RICE_sicily_struggle.txt:63-67`）——作者遇到斗争 `on_start` 不触发事件的问题，改成在每个 `start_struggle` 之后从斗争作用域手动触发 on_action。

### 3.6 互动与宣战理由

- 求援远征：仅在边疆阶段显示，向西西里周边的 AI 独立统治者出钱，请其对目标县开战；接受时激活"远征发起"催化剂（`common/character_interactions/RICE_sicily_character_interactions.txt:9-340`）。这套写法明显从原版 FP3 的求援入侵改来，沿用了 `fp3_request_invasion_troop_value_estimate`、`fp3_incited_conflict`、`fp3_please_dont_give_me_negative_gold` 等原版键。
- 送粮 / 求粮：只有岛内领主能送，冷却 5 年、对同一对象 15 年；送出时激活催化剂，收方得 10 年修正与一个 10 年期钩子 `RICE_sicily_grain_hook`（`common/character_interactions/RICE_sicily_character_interactions.txt:623-760`；`common/scripted_effects/RICE_sicily_effects.txt:2029-2070`；钩子 `common/hook_types/RICE_hook_types.txt:17-19`）。后续回复走 5 个信件事件 sicily.0051–0055。
- 远征 CB 胜利时按攻守双方所属世界概率生成据点（`common/casus_belli_types/RICE_sicily_struggle_wars.txt:106`、`:132`、`:156`），胜/败分别激活催化剂（`:254`、`:295`、`:338`）。

## 4. 机制循环

### 4.1 阶段结构：两个常驻阶段来回摆动，两个终结阶段"攒满即结算"

```
                【整合类催化剂】                        【整合类催化剂】
   ┌───────────────────────────────┐        ┌──────────────────────────────┐
   │                               ▼        │                              ▼
Borderlands 边疆（开局）          Colonization 殖民                 Imperiality 帝国化（终结）
   │   ▲                               │                                 on_start：按支配度写"统治阶层"县修正
   │   └─────【冲突类催化剂】───────────┘                                 → 10 年计时 → end_struggle
   │
   └──【冲突类催化剂】──► Periphery 边缘（终结）
                          on_start：按支配度写"底层"县修正 → 10 年计时 → end_struggle

临时结局后 10 年：外部统治者"占领边疆"/岛内统治者"振兴边疆"决议 → 重启斗争（占领从殖民阶段起步，振兴从边疆阶段起步）
任意常驻阶段：满足条件即可走永久结局决议 Dominion / Crossroads（斗争从此不能再开）
```

依据：
- 阶段定义与互通关系：边疆 `common/struggle/struggles/RICE_sicily_struggle.txt:106-339`（future_phases `:109-205`），殖民 `:341-562`（future_phases `:344-440`），边缘 `:565-615`，帝国化 `:618-671`。
- 两个终结阶段都写了 `save_progress = yes`（`:566`、`:619`）。按原版说明，这表示"朝该阶段积累的进度在阶段切换时保留"（原版:`common/struggle/struggles/_struggles.info:95-96`）。作者在注释里解释了用意：这些进度要跨阶段累计，所以数值故意给得低，目标是"大约 100–120 年攒满"（`:162`、`:347`）。
- 阶段未设 `duration`（`#duration = { points = 500 }` 被注释，`:107`、`:342`），按原版默认 1000 点（原版:`common/defines/00_defines.txt:1648`）。原版催化剂档位 minimal=1 / minor=3 / medium=5 / major=10 / massive=25（原版:`common/script_values/00_struggle_values.txt:9-14`），RICE 另加了 15 / 35 / 50 / 75 / 100 五档"历史性"档位（`common/script_values/RICE_misc_values.txt:3-7`）。

### 4.2 催化剂分两类，同一张清单在两个方向上复用

边疆→殖民 与 殖民→帝国化 用的是几乎同一张"整合"清单（贸易、学语言、赐地给本地贵族、释放重要俘虏、送粮、治理议程、萨莱诺、远征胜利……）；边疆→边缘 与 殖民→边疆 用的是几乎同一张"冲突"清单（结仇、揭露秘密、背弃停战、据点出现、边境劫掠、远征失败……）。

细节上有三处"方向反转"：
- `catalyst_RICE_sicily_historical_event_new_rulers` 在边疆阶段推向殖民（`:127`），在殖民阶段却推回边疆（`:412`）。
- 送粮/求粮/提拔官员在边疆阶段推向殖民（`:131-133`），在殖民阶段被移到了"推回边疆"的清单（`:414-416`）。
- 远征发起在边疆是冲突（推向边缘，`:182`），在殖民是整合（推向帝国化，`:366`）。

代码里没有注释解释这些反转，可能是"殖民期依赖外援反而不稳"的刻意设计，也可能是复制时的疏漏。

另有两处**跨包复用**：西西里斗争直接引用诺曼底包定义的 `catalyst_RICE_normandy_activity_travel`、`catalyst_RICE_normandy_hunt`、`catalyst_RICE_normandy_war_attacker/defender`（`:129`、`:177`、`:180-181`）。催化剂本身只是一个空名字（`common/struggle/catalysts/RICE_normandy_catalysts.txt:39-43`），所以可以当成全 mod 共享的"行为标签"用。

### 4.3 自动催化剂：斗争作用域的年度自续事件

sicily.0007 写在斗争作用域（`scope = struggle`），每年扫一遍涉事统治者：技能高（外交/管理/学识 ≥ decent）→ 整合类；技能高（军事/谋略/武力）→ 冲突类；公爵以上独立 → 冲突类，非独立 → 整合类；最后 `trigger_event = { id = sicily.0007 years = 1 }` 给自己续期（`events/RICE_sicily_events.txt:443-512`，续期在 `:507`）。玩家不做事，斗争也会按"这一带统治者是什么样的人"慢慢漂移。

### 5.5 角色模板：批量造"有地方味"的人

`common/scripted_character_templates/RICE_sicily_character_templates.txt` 的 22 个模板都遵循同一套写法：

## 6. 目标任务

### 6.1 斗争阶段与参与条件

- 涉事文化 21 个（拉丁 5、希腊 1、阿拉伯 5、柏柏尔 3、诺曼 1、犹太 3 等），涉事信仰 7 个（`common/struggle/struggles/RICE_sicily_struggle.txt:8-55`）；文化或信仰有 15% 的县在区域内即为涉事（`:60-61`）。
- 各阶段效果（摘要）：
  - 边疆：雇佣兵 -15%、AI 战争倾向大增、区内战争便宜、停战缩短；异信仰/异文化好感 +5、学语言给威望、杂交文化更容易；全区发展 +0.1/+20%、旅行危险 +25；城堡建造便宜（`:207-333`）。
  - 殖民：区内冲突只限单县、解锁强制附庸 CB；涉事县征召兵/驻军 +20%；改宗改文化加快并给虔诚；全区税收 +10%、发展衰退减少；城市建造便宜（`:442-556`）。
- 自定义阶段参数（如 `rice_sicily_cheaper_frontier_admin_decision`）只是**显示文本**：本地化键是 `struggle_parameter_<参数名小写>`（`localization/english/rice_sicily_l_english.yml:302-308`），真正的效果在脚本值里直接判断当前阶段，例如治理决议在殖民阶段便宜 25%（`common/script_values/RICE_sicily_values.txt:2190-2240`）、招兵选项在边疆阶段经验门槛降到 25（`common/decisions/RICE_sicily_decisions.txt:2114-2140`）。全 mod 搜不到对这些自定义参数的 `has_struggle_phase_parameter` 查询。

## 9. 写法亮点

### 9.1 绕过"斗争只能从起始阶段开始"

```
# events/RICE_sicily_events.txt:726-736（sicily.0012）
		start_struggle = {
			struggle_type = RICE_sicily_struggle
			start_phase = struggle_RICE_sicily_phase_borderland
		}
		# Won't start on any other phase but the predefined starting phase
		struggle:RICE_sicily_struggle ?= {
			change_struggle_phase = struggle_RICE_sicily_phase_colony
		}
		struggle:RICE_sicily_struggle ?= {
			trigger_event = { on_action = RICE_sicily_struggle_starting_events }
		}
```

**巧在**：作者发现 `start_phase` 写别的阶段不生效，就先按起始阶段开、立刻 `change_struggle_phase`。外部"占领"重启从殖民阶段起步，岛内"振兴"重启从边疆起步，两条重启路径用同一个斗争定义做出不同开局。

## 10. 问题与局限

1. **萨莱诺参数与实际相反**：边疆阶段参数说"资助萨莱诺更贵"（`common/struggle/struggles/RICE_sicily_struggle.txt:301`；`localization/english/rice_sicily_l_english.yml:306`），脚本值却在边疆阶段 ×0.75（`common/script_values/RICE_sicily_values.txt:2308-2318`）。"参数只是说明文字"的写法容易出这种说一套做一套。
2. **拉丁轨小额经验的 `if` 是空的**：`RICE_sicily_signore_latin_track_minor_gain` 的 `if` 块里什么都没写，`add_trait_xp` 放在了外面，没有特质的人也会执行加经验（`common/scripted_effects/RICE_sicily_effects.txt:2447-2459`）；希腊、阿拉伯两版是正确的（`:2461-2472`）。
3. **年份比较写成日期**：难民事件里 `current_year >= 950.1.1`（`events/RICE_sicily_events.txt:11845`），`current_year` 是整数，这样写要么报错要么不如预期。
4. **事件里重复写 `scope`**：sicily.0007 同时写了 `scope = none` 和 `scope = struggle`（`events/RICE_sicily_events.txt:445-446`），诺曼底的 0002/0003 同样如此。
5. **每年给所有西西里县主推消息**：`RICE_notify_sicily_dominance_effect` 放在 `if` 外面，斗争不存在时也执行，而且对 AI 也触发隐藏事件（`common/on_action/RICE_sicily_struggle_on_actions.txt:16`；`common/scripted_effects/RICE_sicily_effects.txt:2072-2084`；`events/RICE_sicily_events.txt:115-131`）。
6. **催化剂清单有三处方向反转无注释**（见 4.2），设计意图不明。另外 `catalyst_RICE_sicily_recruit_sicilian_soldiers` 在两个阶段里都挂了（`common/struggle/struggles/RICE_sicily_struggle.txt:184`、`:418`），但全 mod 没有任何地方激活它——招兵决议的效果（`common/scripted_effects/RICE_sicily_effects.txt:2825-2889`）漏了这一步，等于一个死催化剂。
7. **大量死代码**：派系文件 1711 行、起义 CB 503 行全注释（`common/factions/RICE_sicily_factions.txt`、`common/casus_belli_types/RICE_sicily_uprising_wars.txt`）；斗争文件里 400 多行"为抑制报错"保留的伊比利亚阶段占位也被注释（`common/struggle/struggles/RICE_sicily_struggle.txt:674-1108`）；历史战争文件整段注释。
8. **斗争 `on_start` / `on_change_phase` 为空**：没有阶段切换通知事件，玩家只能看斗争界面得知阶段变了（`:63-75`）。
9. **硬编码原版人物 ID**：`character:163094`、`character:1132`、`character:1128` 等大量出现，原版或其他人物 mod 改 ID 就会失效。
10. **依赖模板的 `after_creation`**：大量随机点缀写在模板的 `after_creation` 里。你自己的项目记录里提到过"模板 after_creation 不执行"的现象，若要借鉴请先在 1.20 下实测再用，或改为在 `create_character` 之后由调用方补效果。
11. **跨模组兼容靠占位触发器**：`is_tip_trigger`、`ME_is_loaded` 等在 `common/scripted_triggers/00000000_compatibility_triggers.txt:1-30` 里默认 `always = no`，由其他 mod 覆盖为 yes；文件名前缀 8 个 0 保证最先加载、最容易被覆盖。设计思路好，但只适用于双方约定好的 mod。

## 西西里包：可迁移的设计模式

1. **"可重启的循环斗争"**：两个常驻阶段来回摆动 + 两个终结阶段 `save_progress` 慢慢攒，攒满就在 `on_start` 里自动结算并 `end_struggle`，10 年后用决议重开。适合"治乱循环""朝代兴替"这类反复出现的地区局势。
2. **三方势力用一个三轨特质承载**：身份、进度条、称号升级合一，经验从决议/事件发放，作为结局与选项门槛。汉晋可用于"胡汉/士庶/南北"之类三方或多方张力。
3. **昂贵的统计年度缓存成全局变量**，UI 与结局判定都读缓存。
4. **历史志向框架**：人物修正（玩家可读）+ 变量（脚本可查）+ 重要行动（提示栏）+ 年度检查 + 完成事件，并要求"用过本地区的某个决议"。适合给三国/两晋名人定"人生目标"。
5. **"由玩家决定有争议的史实"**：萨乌丹出身六选一、改文化连带外貌。适合出身有争议的人物（如刘备宗室身份、孙坚家世）。
6. **人物按局势条件化登场 + 优先玩家**：伊本·哈姆迪斯只在西西里落入非穆斯林之手后才逃来。适合"避乱南渡的名士""投奔某方的谋士"。
7. **阶段驱动的人口流动**：乱世阶段把难民（带技能、带地域修正）推给外部统治者，治世阶段把移民推给区内统治者。
8. **决议 + 二级小部件 + 事件链**：七选一议程、三选一招兵、四选一结局都用原版 `decision_option_list_controller`，选项 `is_valid` 写门槛，AI 用相同条件随机抽。
9. **借原版变量阻止原版机制误伤**，而不是覆盖原版文件。
10. **一次性地标决议统一登记到原版 `unavailable_unique_decisions` 列表**，开局按年份预先登记已发生的史实。

## 4. 机制循环

### 4.1 三角形阶段：每个阶段都能去另外两个

```
           ┌────────── 同化类催化剂 ──────────┐
           ▼                                   │
   Acculturation 同化  ◄──同化类──  Adventure 冒险（开局）
      │      ▲                         │   ▲
 对抗类│      │同化类             对抗类│   │冒险类
      ▼      │                         ▼   │
   Confrontation 对抗  ─────冒险类────►（回到冒险）

三个阶段都挂同样三个结局决议：诺曼征服 / 完全同化 / 外人之轭
结局门槛 = 当前阶段正确，或"冒险和同化阶段都至少经历过一次"
```

依据：对抗 `common/struggle/struggles/RICE_normandy_struggles.txt:98-357`、同化 `:361-591`、冒险 `:595-836`；起始阶段冒险（`:93`）；每个阶段的 `ending_decisions` 都是同样三个（`:352-356`、`:586-590`、`:831-835`）。

**阶段访问标记**：`on_change_phase` 里第一次进入冒险或同化阶段时写全局变量 `RICE_normandy_adventure_phase_once` / `_acculturation_phase_once`（`:43-73`）。结局决议用"当前阶段正确 OR 两个阶段都经历过"作门槛（`common/decisions/RICE_normandy_decisions.txt:36-52`），开局 ≥1000 年时直接视为都经历过（`common/scripted_effects/RICE_normandy_effects.txt:126-138`）。这是一种"让玩家不必卡在某个阶段等"的放宽设计。

### 4.2 催化剂：同一个行为在不同阶段指向不同方向

诺曼底最有意思的设计是**同一个催化剂的含义依当前阶段而变**。以"邀请北欧人"系列为例：

|---|---|---|---|

7 人：Beorhtric 父子及其妻（玛蒂尔达事件的对象）、杰弗里·布雷尔（平民十字军指挥官）、朝圣者伯纳德及其两名同伴（`history/characters/RICE_normandy.txt:1-148`）。伯纳德是 867 年的无地冒险者，头衔首都设在福贾，注释写"他先到罗马，然后去了加尔加诺山"（`common/landed_titles/00_RICE_normandy_titles.txt:29-42`；`history/titles/RICE_laamp_titles_867.txt:458`）——一个人物连接了诺曼底的圣米歇尔山和西西里包的加尔加诺山两个圣米迦勒圣地。同伴的历史条目用 `employer` 和 `effect = { set_employer = ... }` 双保险绑到伯纳德身边（`history/characters/RICE_normandy.txt:110-114`）。

### 5.6 人物模板

17 个模板都很朴素：年龄区间 + 信仰主导性别比例 + `random_traits = yes` + 某项技能高（`common/scripted_character_templates/RICE_character_templates.txt:685-882`）。文化信仰来自调用方作用域（`scope:norse_faith` / `scope:norse_culture`），或在 `create_character` 时直接覆盖——奴隶模板本身不写文化信仰，由罗洛事件传入（`:878-882`；`events/RICE_normandy_events.txt:8505-8512`）。

## 6. 目标任务

### 6.1 末日审判书：故事循环做"多年工程"

- 决议只在"诺曼征服结局已发生"后显示，要求诺曼系文化或罗洛王朝修正，并完全控制征服结局对应的那个区域（英格兰/法兰克/大诺曼底）（`common/decisions/RICE_normandy_decisions.txt:609-772`）。
- normandy.0015：按区域和"是否有管家"分支描述，在 `after` 里 `create_story`（`events/RICE_normandy_events.txt:1485-1552`，`create_story` 在 `:1545`）。
- 故事循环：365–550 天后完成（登记一次性列表、推 normandy.0016）；600 天强制自毁；主人死亡则交给玩家继承人并补标记，否则结束；`on_end` 里若中途失败就悄悄重新开放决议（`common/story_cycles/RICE_story_cycle_normandy_domesday_book.txt:1-86`）。
- normandy.0016：生成不会衰减的文物《末日审判书》（描述按区域三选一），事件窗口用 `artifact = {}` 直接展示文物；正文按"是否原发起人"分支（继承人收尾时措辞不同）（`events/RICE_normandy_events.txt:1553-1700`）。
- 效果：征服区域全部县控制度 +15、50 年县修正（`common/scripted_effects/RICE_normandy_effects.txt:927-985`）。

### 6.2 圣奥贝尔圣物链

1. 年度脉冲：圣物尚未失踪时，每年 5% 起、随年代递增的概率失踪，给西法兰克有地的玩家推 normandy.0066（`common/on_action/RICE_events_on_actions.txt:337-384`）。
2. 决议"寻找圣奥贝尔遗失的圣物"：持有阿夫朗什、基督徒、虔诚 ≥2；AI 意愿随年代递增（`common/decisions/RICE_normandy_decisions.txt:1220-1352`）。
3. normandy.0065：按概率找到/找不到，两个选项用 `trigger` 互斥显示；找到 → 虔诚、"圣物发现者"修正、同化类催化剂、全区玩家收到 0067；找不到 → 少量虔诚 + 冒险/对抗类催化剂（`events/RICE_normandy_events.txt:7531-7647`）。
4. 找到后解锁"圣奥贝尔游行"活动、扩大圣米歇尔山朝圣的可发起距离（`localization/english/rice_normandy_l_english.yml` 中 `normandy.0065.tooltip`）。

### 6.3 邀请冒险者：五选一的"移民政策"

两个决议（北欧人/诺曼人）结构相同：二级界面五选一——廷臣、殖民者、战士、商人、统治者（统治者项要求至少有 2 个县，"不要把唯一的县送出去"）（`common/decisions/RICE_normandy_decisions.txt:1530-1848`、`:1850-2270`）。选择被写进人物变量 `RICE_norse_adventurer_type = flag:xxx`，再触发"抽签"隐藏事件 0020/0030。北欧人决议在盛期中世纪后消失，冷却由脚本值决定；在对抗阶段涉事者邀请北欧人便宜 25%（`common/script_values/RICE_normandy_values.txt:94-152`、`:208`）。每种类型对应一个催化剂（见 4.2 的矩阵）。

**代表性事件链完整走读：邀请北欧冒险者**

```
决议 RICE_normandy_recruit_norse_adventurers（二级界面五选一）
```

## 9. 写法亮点

### 9.1 接住原版决议，补上自己的系统

```

on_character_culture_change = {
	on_actions = { on_culture_change_RICE }
}
on_culture_change_RICE = {
	effect = {
		# Trigger Normandy stuff if done through the vanilla decision
		if = {
			limit = {
				completely_controls = title:d_normandy
				root = { culture = culture:norman }
				NOT = { is_target_in_global_variable_list = { name = unavailable_unique_decisions target = flag:flag_formed_normandy_decision } }
				NOT = { has_global_variable = RICE_normandy_struggle_started }
			}
			add_to_global_variable_list = { name = unavailable_unique_decisions target = flag:flag_formed_normandy_decision }
			if = {
				limit = { has_game_rule = RICE_struggle_normandy_toggle_on }
				set_global_variable = { name = RICE_normandy_struggle_started value = yes }
```

```
			trigger_event = { id = normandy.0002 years = 1 }
```

**巧在**：不占用任何全局脉冲，斗争结束后 `trigger` 失败自然停止；把"婚姻、联盟、技能、封臣好感"这些持续状态转成每年一次的催化剂，让斗争对玩家的日常经营做出反应。

## 10. 问题与局限

1. **两个结局事件用错了 `end_struggle` 的结局键**：外人之轭（normandy.0007）和完全同化（normandy.0008）都写成 `end_struggle = RICE_normandy_struggle_ending_conquest_decision`（`events/RICE_normandy_events.txt:792`、`:832`）。原版 FP2 用这个参数记录"以哪个结局结束"（原版:`events/dlc/fp2/fp2_struggle_events.txt:665`、`:873`、`:1033`），所以这里很可能把结局记成了"征服"。具体影响（斗争历史记录、成就判定等）未实测，属高度疑似。
2. **玛蒂尔达事件的触发条件写错**：检查 `character:367 = { is_spouse_of = character:367 }`（自己是自己的配偶，永远为假），还引用了未定义的 `scope:william`（`common/on_action/RICE_events_on_actions.txt:299-306`）。按代码看这条事件通过该路径几乎不会触发。
3. **《诺曼史》最长计时等于最短计时**：两个全局变量都是 `days = 1095`，注释却说最长 10 年（`events/RICE_normandy_events.txt:10345-10357`）。于是年度脉冲里"在两个计时之间每年 25% 成书"的分支永远不会进入，总是在三年后直接成书（`common/on_action/RICE_events_on_actions.txt:395-428`）。
4. **斗争描述是占位文字**：`RICE_normandy_struggle_desc` 是一句无关的占位句子重复两遍（`localization/english/rice_normandy_l_english.yml:143`）。
5. **冒险者来源的兜底分支引用了未保存的作用域**：`scope:norwegian`、`scope:norse` 等在该事件里没有 `save_scope_as`（`events/RICE_normandy_events.txt:1876-1899`），只有"地图上找不到任何北欧系县"时才会走到，但走到就会报错。另外，作者在同一事件开头的注释里承认"冒险者类型变量一直报未设置，补设了也不管用，原因不明"（`:1726-1728`），说明这条"决议写变量 → 隐藏事件读变量"的链路在 AI 侧并不稳。
6. **人物记忆定义了但没有创建**（见 5.7）。同类问题：`catalyst_RICE_normandy_invited_norse_rulers` 在三个阶段里都以 massive 档挂着（`common/struggle/struggles/RICE_normandy_struggles.txt:168`、`:424`、`:671`），但邀请北欧"统治者"的效果分支里没有激活它（其余 9 个邀请类催化剂都在 `common/scripted_effects/RICE_normandy_effects.txt:1071-1743` 里激活了），是个死催化剂。
7. **外人之轭结局没有写传奇种子**，另两个结局都有（`common/decisions/RICE_normandy_decisions.txt:166-172`、`:360-366` 对比 `:530-535`）。
8. **大量死代码**：两个 CB 文件 2000 多行全注释；斗争文件末尾 400 多行占位阶段注释（`common/struggle/struggles/RICE_normandy_struggles.txt:838-1275`）；建筑文件开头还留着旧版单级建筑的注释（`common/buildings/RICE_normandy_buildings.txt:8-49`）。
9. **区域只有一个公国**：诺曼底 7 县，`involvement_prerequisite_percentage = 0.2`（`common/struggle/struggles/RICE_normandy_struggles.txt:35`），任何文化只要有 2 个县在这里就够门槛的 20%——对小文化来说门槛很低，对大文化来说几乎不可能涉事，实际涉事者往往只有本地几家。
10. **硬编码人物 ID**：`character:242`（罗洛）、`character:140`（威廉）、`character:367`（玛蒂尔达）、`character:90111`（糊涂查理）等。

## 诺曼底包：可迁移的设计模式

1. **"扮演某人"事件链**：开局段连发 + 年度条件触发段 + 以系统性事件（斗争开始）作高潮；每段都有干净的退出选项；配角带标记、后续优先找回同一人。汉晋可做"刘备织席贩履→桃园→三顾"或"司马懿隐忍"式的个人线。
2. **选项 = 史料说法**：把史学争议做成玩家选择并附历史说明（罗洛出身、萨乌丹出身两例）。
3. **历史角色"替身"**：玩家改变历史后，用全局列表记住"本局的罗洛/查理/杜多是谁"，后续事件用 `ordered_in_global_list` 取回，叙事仍能连贯。
4. **同一行为在不同阶段含义不同**：催化剂矩阵让"招北欧殖民者"在乱世安定、在太平搅局，比单向进度条更有张力。
5. **阶段访问标记放宽结局门槛**：经历过关键阶段一次就够，不必卡在当前阶段。
6. **剧情驱动的文化传统升级路径**：同名同描述的多个版本传统，按事件结果替换，玩家感知为"传统被强化"。
7. **接住原版决议的后果**而不是覆盖原版决议（`on_character_culture_change`）。
8. **故事循环做多年工程**：完工计时 + 继承交接 + 自毁兜底 + 失败重开。适合汉晋"修《东观汉记》""开凿运河""编户齐民"之类。
9. **AI 限制保护玩家剧情 + 随年代递增的 AI 意愿**，让 AI 世界按史实节奏但不抢玩家戏份。
10. **带背教检查的延时完工**：投资类决议的结果在完工时重新检查身份，处理"中途身份变了"的情况。

# 三、两个斗争的对比

| 维度 | 西西里 `RICE_sicily_struggle` | 诺曼底 `RICE_normandy_struggle` |
|---|---|---|
| 阶段拓扑 | 两常驻阶段线性摆动（边疆↔殖民）+ 两侧各一个终结阶段（边缘、帝国化） | 三阶段完全图（任意两阶段互通），无终结阶段 |
| 进度保存 | 终结阶段 `save_progress = yes`，跨阶段累计，目标约百年 | 未用 `save_progress`；靠"阶段访问标记"记录历史 |
| 起始方式 | 开局自动（≥647）；临时结局后用两个决议重启（一个从殖民起步） | 开局 911–1075 自动；否则四条路径之一触发一次 |
| 是否可重复 | 可重复（临时结局 → 10 年冷却 → 重启）；永久结局后不可再开 | 一次性 |
| 结局形态 | 自动临时结局 2 个 + 决议永久结局 2 个（统治结局内含四选一） | 决议结局 3 个，各附文化风气四选一 |
| 结局门槛的"长期资源" | 王朝传承第 5 天赋 + 三轨特质经验 + 发展度 + 控制区域 | 《诺曼史》成书 + 发展度 + 控制区域 + 时代 |
| 结局决议可见性 | `is_invisible = yes`（同原版） | 在决议列表中可见（`is_shown`） |
| 自动催化剂 | 年度自续事件：技能高低、是否独立 | 年度自续事件：配偶、盟友、技能、封臣好感 |
| 催化剂复用 | 两张清单（整合/冲突）在两个方向复用，三处反转 | 3×2 矩阵，同一催化剂依当前阶段指向不同 |
| 平行量表 | 三世界支配度（年度缓存）、三轨特质、据点县修正 | 无数值量表，靠全局标记（史书、圣物、征服区域） |
| 阶段参数 | 自定义参数仅作显示，实效写在脚本值里（有一处说反） | 同样做法（参数说明 + 脚本值按阶段打折） |
| 结局后续 | 底层/统治阶层/统治/十字路口县修正持续影响重启后的决议成本与加成；难民/移民随结局方向流动 | 传统升级、末日审判书、诺曼冒险 CB 解锁、诺曼学者邀请 |
| 传奇/编年史 | 自建两部编年史和种子效果 | 直接用原版 `legend_seed_struggle_ending_effect` |
| 个人故事接入 | 历史志向要求使用本地区决议；人物（萨乌丹、君士坦丁）的进度与斗争系统共享特质轨 | 罗洛线以斗争开始为高潮；罗洛修正直接改写授予/谈判的规则 |
| 设计气质 | "地区像一台慢慢摆动的钟摆"，强调多方长期共存与周期性 | "一个民族的成长三部曲"，强调一次性的历史叙事与选择 |

**对汉晋春秋的启示（简要）**：
- 如果要表现"治乱循环、反复出现"的地区局势（例如河西走廊、交州、辽东、巴蜀），西西里式的"可重启斗争 + 终结阶段自动结算 + 冷却后决议重启"更合适；配一个"多方影响力"的年度缓存量表，可以让结局取决于这些年谁在这里扎根。
- 如果要表现"一次性的民族/政权形成史"（例如五胡内迁后的某个胡族政权汉化、衣冠南渡后的侨姓与吴姓融合），诺曼底式的三角阶段 + 同一行为依阶段变义 + 剧情驱动的传统升级更合适。
- 两者共同的底层手法都值得直接搬：斗争作用域的年度自续催化剂事件、"结束者执行/其他人看提示"的结局事件、用原版 `unavailable_unique_decisions` 登记一次性决议、用全局变量配天数做冷却、把历史人物的目标做成"人物修正 + 变量 + 重要行动 + 年度检查"。
