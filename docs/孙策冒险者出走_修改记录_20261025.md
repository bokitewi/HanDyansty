## 2026-10-28 补丁：交地后又拿回县、仍算出走

### 现象（190 局存档 205.7.1）
- 孙坚未走辞袁事件，191.6.2 自己拿下汝南四县并独立；`hds_sj_departed_line` 未设，故不算孙坚自立线。
- 191.10.10 孙策继承；191.10.24 出走，走「无上级」分支，四县分给新首领、汝南郡销毁。
- 同一天五防县（c_uuii_p_1661，旧首府）以 revoked 回到孙策手上；立营段要求无地被跳过，庄园未拆、政体仍天朝、无 `hds_sc_camped`。
- 收尾判定只看「独立 + 孙家庄园」，照样打上 `hds_sc_departed`，以有地身份打丹阳。西平县是 200 年征服所得，属正常战果。
- 收回来源未确证，疑为原版 yearly_playable_pulse「无地君主有有地封臣则收回一县（优先首府）」。

### boki 拍板
孙坚经其他途径自立时，孙策照样交地立营（不原样继承）；修漏洞。

### 改动
- `zzzzzzzzzz_hds_20260919_sun_ce.txt`
  - `hds_sun_camp_departure_effect`：交地后仍有地就再交一次；计数 `hds_diag_dep_regained`（交完仍有地）、`hds_diag_dep_still_landed`（交两次仍有地）。
  - `hds_sun_return_land_effect` 无上级分支：转县与独立放进同一个 independency 变更（照原版 MPO 游牧分立 mpo_decisions.txt 写法），不再出现「出走者已无地、新首领仍是有地封臣」的中间态；销毁郡以上头衔前再把仍挂名下的有地封臣放独立。
  - `hds_sc_depart_effect`：交地立营线必须有 `hds_sc_camped` 才打 `hds_sc_departed`；第一次走立营即打 `hds_sc_depart_chosen`。
  - `hds_sc_tick_effect`：有 `hds_sc_depart_chosen` 的直接重试出走，不再弹 hds.4001；计数 `hds_sc_depart_tries`，含事件那次共最多 3 次。
