# 天朝循环 · 朋党系统 设计草案

> 依据：`天朝循环局势大修.doc`（设计原稿）、`docs/天朝循环大修_维护文档.md`，以及 2026-10-06 设计问答 Q1–Q77 的全部结论。
> 状态：**已实现（2026-10-06），尚未游戏内实测**。实现阶段的确认与变更见下方"实现变更记录"，与正文冲突时以变更记录为准。

### 实现变更记录（E1–E7、F1–F6、G1）
- **G1 存储**：所有朝廷（含天子）的朋党数据统一存放在君主本人身上（`var:hd_party_<组>_*`）；天子朝廷的领袖/势力/青睐同步写回原版全局组。第 1.1、11.3、11.4 节中"天子存全局组""终结/进入乱世时迁移"不再需要：新天子直接沿用自己的数据，其余诸侯成为臣属后在下次年度结算时清空。
- **F1**：四夷组照抄诸侯组的政府参数；旧四夷人物 modifier 已停用（定义保留，仅用于清理旧存档）。
- **F2**：原版 `pro_hegemon_interaction_boost` 无任何代码读取，已从外戚组移除，尊王立场不另实现"互动加成"。
- **F3**：青睐时君主获得的是该身份本时代**数值类**组效果的复制件（`hd_party_favor_<组>_<时代>_modifier`，由 `docs/tools/gen_party_effects.py` 从局势文件生成），政府参数无法复制。
- **F4**：合作朋党成员请愿时，天子的请愿接受度 +20（"联名请愿"）；"影响力花费减半"未实现（原版请愿的花费分散在请愿事件链中）。诽谤阴谋维持 mod 原有的禁用状态。
- **F5**：184 年开局给十常侍（在世者）补阉人特质并入宫；领袖强制为 张让 / 何进 / 袁隗 / 卢植 / 皇甫嵩；约 75 天后事件解除党锢。
- **F6**：群雄逐鹿时，外戚/武勋/寒门/世族免除原版"成为冒险者"的文化/信仰门槛。
- **E2–E7**：尊王武官 = 持军衔或军事人员；对抗 ×1.5 后兵士团数取 −2；非行政政体按威望结算；党际好感 −15 / +10；"投身乱世"带 2 名随从、300 + 军事×25（≤800）义从；事件文案为半文言。
- 原版"选择朋党"决议与"劝说换党"互动已禁用（身份只能通过"转换身份"决议改变）。
- **2026-10-06 测试后修改**：朝廷门槛由王国级改为**帝国级**（乱世中只有帝国级诸侯有朋党，帝国级以下看不到"政治派别"页）；所有朋党数字（势力、领袖、前三名、成员名册、组按钮数字、门生加成）只计本国，界面不再显示全局数据。
> 约定沿用维护文档：前缀 `hd_party_*`；简体中文本地化；只追加 on_action 子项；覆盖原版文件处标注"天朝循环大修·朋党"。

## 0. 术语

| 术语 | 含义 |
|---|---|
| 身份 / 参与者组 | 局势 `dynastic_cycle` 的全局参与者组，决定角色吃哪一份**时代组效果** |
| 朋党 | 某个"朝廷"（天子或乱世王国级以上诸侯）内、同一身份成员构成的**政治组织**，有领袖、立场、势力、满意度、对君主态度、君主政策 |
| 朝廷 | 拥有朋党玩法的政权：治世为天子政权；乱世为首都在 h_china 法理内、王国级以上、非四夷的独立统治者政权 |
| 君主 | 朝廷的最高统治者（治世即天子，乱世即该诸侯，UI 称"主上"） |
| 立场 | 尊王 / 开拓 / 进取 / 守旧 / 中立，朋党的属性（不再是分组依据） |
| 态度 | 朋党对君主：拥护 / 中立 / 对抗 |
| 政策 | 君主对朋党的政治运作：查禁 / 限制 / 中立 / 促进 |

## 1. 总览与架构

### 1.1 双层结构（Q2）
- **第一层·身份（全局）**：局势参与者组，全天下共用，只负责"你是谁"与时代组效果。
- **第二层·朋党（按朝廷）**：
  - 天子朝廷：直接用全局参与者组作载体，复用原版组变量（`var:movement_leader`、`var:movement_power`、`var:movement_favored`），新增数据也存在组上。
  - 乱世诸侯朝廷：数据存在**该诸侯本人**的变量上，每个身份一套（见 11.3）。
- 王国级以下政权、四夷政权：只有身份与时代效果，没有朋党玩法，UI 不显示"政治派别"页（Q11、Q66）。

### 1.2 参与者组 key 映射（Q9、Q11、Q38、Q45）
保留原版 key（兼容原版与 mod 中大量按 key 判定的代码），改成员判定与本地化；新增第 8 组四夷。**文件中组的排列顺序 = 归属优先级**（引擎取第一个满足的组）。

| 顺序 | key | 显示名 | 类别 | 组图标（Q71/Q77） |
|---|---|---|---|---|
| 1 | `hegemon_ruler` | 天子 | 统治者 | `dynastic_cycle_group_emperor.dds` |
| 2 | `hd_siyi_movement`（新增） | 四夷 | 特殊 | `dynastic_cycle_group_independent.dds` |
| 3 | `other_rulers` | 诸侯 | 统治者 | `dynastic_cycle_group_emperor.dds` |
| 4 | `undecided_movement` | 宦官 | 朋党 | `dynastic_cycle_group_pro.dds` |
| 5 | `pro_hegemon_movement` | 外戚 | 朋党 | `dynastic_cycle_group_unaligned.dds` |
| 6 | `expansion_movement` | 武勋 | 朋党 | `dynastic_cycle_group_expand.dds` |
| 7 | `conservative_movement` | 世族 | 朋党 | `dynastic_cycle_group_anti.dds` |
| 8 | `advancement_movement` | 寒门 | 朋党（兜底） | `dynastic_cycle_group_advance.dds` |

- 原版组短名"尊王派/攘夷派/进取派/守旧派/中立"全部替换为上表显示名；原版游戏概念"朋党、朋党势力、朋党领袖、个人朋党力量"保留原义。
- 原版组的 `on_join`/`on_leave`（设 `movement_member`、重算势力与领袖、给玩家发入组事件 tgp_dynastic_cycle.0052–0056）保留，入组事件文本改写为身份语义。

### 1.3 与原版 movement 内容的拆分（Q18）
原版 movement 的五类内容重新分配：

| 原版内容 | 新归属 |
|---|---|
| 各时代组效果（modifier_sets） | **身份**（第 8 节重做） |
| 请愿决议 `movement_petition_decision` 的选项 | **立场**：开拓←攘夷派、进取←进取派、守旧←守旧派、尊王←尊王派；中立无 |
| AI 改法偏好 `ai_movement_petition_change_laws_decision` | **立场**（同上映射） |
| 当权朋党推动时代的年度诱因（`dynastic_cycle_on_actions.txt:69-108`） | 改为按**被青睐朋党的立场**判定 |
| vassal stance +250 分（`00_vassal_stances.txt`：courtly/glory_hound/parochial/belligerent） | **立场**：尊王→courtly、守旧→glory_hound、进取→parochial、开拓→belligerent |

### 1.4 与现有 PAR 党争危机（Q9、Q23、Q43）
- PAR（`hd_dc_par_*`）保留，作为"立场对立 → 党争爆发"的落点。
- 候选党：由四个 movement 改为五个身份朋党（宦官、外戚、武勋、世族、寒门）。
- 敌对判定（`hd_dc_party_triggers.txt:113`）：改为 **立场对立 OR 领袖互为对手/仇敌 OR 双方领袖互相好感 ≤ −30**。
- 仍只在天子朝廷触发；乱世诸侯国的党争只靠辩论与拥护/对抗体现。

## 2. 身份组

### 2.1 参与者范围（Q12、Q37）
- **地理**：
  - 治世：天子政权内的人（含原版"带 `celestial_investiture_politics` 的朝贡国"规则，仅治世生效）。
  - 乱世：首都在 h_china 法理内的任意独立统治者政权内的人（不论等级）。
- **谁是参与者**：
  - 有地统治者：自动（`auto_add_rulers`）。
  - 无地角色：满足任一条件时 `add_manual_participant`，条件失效时 `remove_manual_participant`：
    持有世族（`noble_family`）头衔 / 持有宫廷职位 / 是议政成员 / 是摄政或辅政 / 持有 WJ 官职（`WJ_has_official_position_trigger`）/ 持有武官军衔（`WJ_mr_has_rank`）。
  - 游荡者、池中角色、无上述条件的普通廷臣不是参与者。
- 手动加入/移除的触发时机 **【待定】**：建议挂在获得/失去宫廷职位、议政任免、头衔获得/失去、军衔授予的既有 on_action 上，外加局势年度脉冲兜底；实现阶段列出具体 on_action 再确认。

### 2.2 各组判定（Q11、Q13、Q38）
"君主"：治世为天子，乱世为该政权最高统治者。

| 组 | 判定（满足任一即可，除注明外） |
|---|---|
| 天子 | `has_title = title:h_china`（外族入主亦为天子） |
| 四夷 | 非汉文化传承（h_china 法理范围内的封臣与独立统治者都算） |
| 诸侯 | 独立统治者，且不是带天朝授封标记的朝贡国 |
| 宦官 | `is_eunuch_trigger = yes` |
| 外戚 | 成年，且所属**宗族（dynasty）**为：君主母亲、正妻或任一嫔妃的宗族；或君主子女配偶的宗族。（不限男性；参考现有 `WJ_waiqi_member`，需另写一个按宗族判定的版本） |
| 武勋 | 持武官军衔 `WJ_mr_has_rank`；或 `WJ_mt_military_person`（含大司马）；或军事教育特质 ≥3 级 |
| 世族 | 家族为豪族/主导家族（`is_powerful_family` / `is_dominant_family`）；或本人/家族持有 `noble_family` 头衔；或宗族威望等级 ≥7（闻名于世及以上） |
| 寒门 | 以上皆不满足的所有人（兜底，含无宗族者；不要求"无庄园"） |

- **门生**（原版 elder/disciple）：沿用原版"门生强制跟随举主入组"，但跟随的优先级排在宦官、外戚之后（举主为武勋、门生为阉人 → 归宦官）。
- 四夷政权（四夷出身的王国级以上独立王）没有朋党。

### 2.3 身份粘性与自动重归（Q14）
- 沿用原版粘性变量 `var:movement_member`，防止在组之间来回跳。
- **外戚、宦官**失去资格时（如新君登基，前朝后族不再是外戚），在下次年度检查中自动按优先级重新归组，不收转换代价。
- 其他身份保持粘性，直到本人走转换决议或死亡。

### 2.4 身份转换决议（文档 1.0101，Q3、Q26）
- 条件：满足目标身份的判定；不在冷却中。
- 代价：
  - 威望 −500
  - 正统 −30（有正统者）
  - 影响力扣至下一等级门槛（有影响力的政体）
- 冷却 10 年。
- 结算：设置 `movement_member` 后 `recalculate_participant_group = situation:dynastic_cycle`。
- AI 使用条件：目标身份是被青睐的朋党，或目标朋党满意度比原朋党高 30 以上。

| 主头衔等级 | ×5 |
| 内阁型辅政 / 其他辅政 / 议政 | +100 / +50 / +20 |
| 朝贡国皇恩 | +皇恩值 |
| 庄园书房建筑 | 原版档位 |
| 门生 | 门生势力的 25% 计入举主 |

| 新增项 | 值 |
|---|---|
| 直辖伯爵领数 | ×2 |
| 首都县发展度 | ×0.5 |
| 持 WJ 实职官位（`WJ_has_substantive_office_trigger`） | +20 |
| 持任一宫廷职位 | +10 |
| 威望等级 | ×5 |
| 持有世族头衔 | +25 |

不逐县求和，避免性能开销。

### 3.2 朋党势力
- **天子朝廷**：原版 `movement_power_value` = 成员势力和 + 青睐（`var:movement_favored`）+350 + 时代偏好 +150 + 阴谋/请愿临时衰减变量；新增"辩论失败""青睐事件链"等临时变量，沿用原版 `update_modified_movement_power_effect` 的年度衰减写法。
- **诸侯朝廷**：同一公式，只累加本政权成员，存为 `var:hd_party_<组>_power`。
- **势力占比** = 本党势力 ÷ 本朝廷五党势力之和（百分比，Q22）。
- **势力衰微**：占比 <10% 时，不施加拥护/对抗效果，也不能发起辩论；成员个人的时代效果照常生效（Q22、Q32）。

### 3.3 领袖（Q4）
- 领袖 = 本朝廷该朋党内个人势力第一名（天子朝廷沿用原版 `update_movement_leader_effect`）。
- 只在三种时机更替：领袖死亡、离开本政权、更换身份。不做定期轮换。
- "前三名"缓存列表（辩论发起资格与 UI 用）：在年度脉冲和领袖变更时刷新。
- 天子、诸侯、四夷三组没有领袖。

## 4. 政治立场

### 4.1 立场存储与持续（Q5）
- 天子朝廷存在组上：`var:hd_party_stance`。诸侯朝廷存在诸侯身上：`var:hd_party_<组>_stance`。
- 立场属于朋党：新领袖继承原立场，想改只能通过辩论。
- 例外：被"要求效忠"强制改成的尊王，在领袖更替或君主更替时解锁；解锁后新领袖可以按性格免辩论重选一次（仅一次）。

### 4.2 立场效果

**尊王**（文档 1.021 + Q35）

| 效果 | 实现方式 |
|---|---|
| 不加入敌对派系 | 加进 `character_has_faction_disabling_modifier_trigger`（`00_faction_triggers.txt:23`，mod 未覆盖），玩家和 AI 都无法加入 |
| 不进攻自己的领主 | 封臣对领主宣战的 CB 加限制 |
| 对领主好感 +15 | `opinion_of_liege` |
| 更少对领主发动阴谋 | 在 mod 已覆盖的计谋互动 `ai_will_do` 中，对"目标是领主"的情况 ×0.1 |
| 领主逮捕成功率更高 | 逮捕接受度 +15，钩子位于 mod 覆盖的监狱互动 `ai_accept` |
| 尊王派武官主动参战 | 领主召唤参战时自动接受，钩子位于 mod 的 `zzzz_WJ_district_acceptance_00_alliance.txt` |
| 尊王派文官总督效率 +10% | 接入 `zz_hd_special_governor_efficiency.txt`；文官 = `WJ_has_substantive_office_trigger` 且不持武官军衔 |
| 继承原版尊王派的内容 | 请愿、AI 偏好、courtly +250，以及参数 `pro_hegemon_interaction_boost` 的效果（见 8.1） |

"尊王派武官"的判定 **【待定】**：建议与武勋身份的武官条件一致，即持军衔或 `WJ_mt_military_person`。

**开拓**：继承原版攘夷派（expansion）的请愿选项、AI 改法偏好（扩军、军事/保护国省份、削减官僚）、belligerent +250。

**进取**：继承原版进取派（advancement）的请愿选项（含举行科举）、AI 偏好（扩官僚、减军队、都会/产业省份、加俸）、parochial +250。

**守旧**：继承原版守旧派（conservative）的请愿选项（致仕法、部门预算、候选分法）、AI 偏好（阻止科举）、glory_hound +250。

**中立**：无任何机制和效果。

**被青睐朋党的立场推动时代**：原版"当权朋党"年度诱因改为看被青睐朋党的立场。

| 被青睐朋党的立场 | 推动方向 |
|---|---|
| 守旧 | → 局势紧张（大） |
| 开拓 | → 稳定（大） |
| 进取 | → 局势紧张（大） |
| 尊王 + 进取时代 | 极大 |

### 4.3 立场选择权重（文档 1.023，Q29）
用于领袖初次选择、新朝廷初始化、解锁后重选、AI 辩论意图。各项加总后**加权随机**。

**性格权重**

| 立场 | 特质与权重 |
|---|---|
| 开拓 | 勇敢 `brave` 30、暴怒 `wrathful` 10、野心勃勃 `ambitious` 30、狂热 `zealous` 10、冷酷 `callous` 15 |
| 守旧 | 合群 `gregarious` 10、狂热 30、节制 `temperate` 15、固执 `stubborn` 10 |
| 中立 | 怯懦 `craven` 30、安于现状 `content` 30、懒惰 `lazy` 20 |
| 尊王 | 节制 10、安于现状 10、狂热 10、忠信 `loyal` 50、忠贞 `chaste` 10、怯懦 10 |
| 进取 | 愤世嫉俗 `cynical` 30、公正 `just` 20、勤勉 `diligent` 20 |

**vassal stance 倾向**：只对有 stance 的有地领袖生效（`has_vassal_stance`），对下表每个倾向立场各 +30。

| stance | 倾向立场 |
|---|---|
| Belligerent | 开拓 |
| Minor Landholder | 守旧、中立 |
| Parochial | 中立 |
| Zealot | 进取、守旧、尊王 |
| Glory Hound | 开拓、进取 |
| Courtly | 守旧、尊王 |
| Minority | 开拓、中立 |

**好感倾向**：尊王 + 领袖对君主好感 ×0.3（好感 +100 时 +30，−100 时 −30）。

### 4.4 立场辩论活动（文档 1.022，Q19、Q30、Q60、Q77）

**基本设定**
- key：`activity_hd_party_debate`（原版 `activity_debate` 已占用该名，不复用）。
- 发起人：本党领袖或前三名。发起人的意图 = 当前立场以外的四种立场之一。
- 嘉宾意图：拥护 / 中立 / 反对。
- 邀请范围：本党成员，加上其他朋党的领袖。君主默认受邀，但出席不是必须的。

**发起条件**
- 发起人不在 10 年冷却中。
- 本党同时只能有一场辩论。
- 本党未被"要求效忠"锁定。
- 本党势力占比 ≥10%。
- 花费：威望 200 + 金钱 50。

**阵营**：`guest_subsets = { hd_debate_support hd_debate_neutral hd_debate_oppose }`。在准备阶段的 `on_phase_active` 中按 `has_activity_intent` 分入，写法参考加冕礼（`coronation.txt:1741-2072`）。

**阶段与事件**

| 阶段 | 时长 | 内容 |
|---|---|---|
| 准备 | 30 天 | 发起人三选一：<br>• 联络同党：花 50 金钱，进度 +5，中立嘉宾有 30% 转为拥护<br>• 拉拢中立：外交判定，成功则一名中立嘉宾转为拥护<br>• 散布流言：谋略判定，成功则一名反对者转为中立，失败则威望 −100 |
| 辩论初期 | 15 天 | 从 6 个事件的池中随机抽 2 个：<br>• 引经据典：发起人与反对方领头人比学识，±10<br>• 清议声援：拥护方中寒门越多，加成越高<br>• 酒宴拉拢<br>• 当廷驳斥：反对方领头人发难，±10<br>• 援引祖制：守旧立场的反对者加成<br>• 群情汹汹：随机一名嘉宾倒戈 |
| 辩论后期 | 15 天 | 从 4 个事件的池中随机抽 2 个：<br>• 决胜之辩：学识 + 外交对抗，±15<br>• 请圣裁<br>• 临阵倒戈<br>• 拂袖而去：反对者离场，反对方势力修正减半 |
| 结局 | — | 结算，成功或失败各一个结局事件 |

- **嘉宾小事件**：拥护者与反对者每个阶段各一个，可以花钱或威望给己方阵营的进度 ±3。
- **请圣裁**：君主不论是否出席都会收到。可以支持一方，让进度 ±20，代价是被支持方的对立方满意度 −10；也可以不表态。

**判定（Q19 方案 C）**
- 进度变量 `var:activity_special_type_progression` 从 0 开始，范围 −100 到 +100。
- 结局时加上势力修正：（拥护方势力合计 − 反对方势力合计）÷ 双方合计 × 30。
- 修正后 ≥ +30 算成功。

**成功**
- 立场改为发起人的意图。
- 发起人威望 +200。
- 若发起人不是领袖，直接取代原领袖。
- 拥护者获得威望 +50，对发起人好感 +10。

**失败**
