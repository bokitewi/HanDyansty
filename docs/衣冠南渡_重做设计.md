# 衣冠南渡 重做设计（仿伊比利亚斗争）

2026-10-26 起与作者逐轮问答。旧版设计见 `docs/衣冠南渡_设计草案.md`（仿自然灾害，按年限切阶段）。本文是重做的唯一设计依据，实施中凡偏离或未写明之处，列入末节交作者确认。

---

## 0. 调研结论（实施前提）

- 原版"斗争"只能按文化+信仰把人分成参与者 / 介入者 / 无关者三档，区域固定，原版启动前都查 FP2 DLC。做不出按脚本条件分的多个参与者组。
- "局势"能做任意参与者组（`participant_groups` + `is_character_valid`，按顺序取第一个满足者），也能像斗争一样用催化剂积分推动阶段（`takeover_type = points`，天朝循环就是这样做的）。
- 通用局势窗口 `window_situation` 显示阶段进度、催化剂、参与者组，但不显示决议；要显示决议须自做窗口（天朝循环、基督教会都是自做窗口）。

## 3. 第 7 轮提案（已确认）

### 3.1 伊比利亚斗争的做法（调研）
- 四阶段：机遇（开局）、敌对、妥协、和解。每阶段两个以内去向，各去向列一组催化剂，累计满 1000 点切换，过渡 3 个月；换阶段后累计清零。
- 催化剂点数 1/3/5/10/25/50 六档；每年"时间流逝"+1。实际主要靠催化剂推动。
- 阶段效果分战争/文化/信仰/其他四类，每类有参数（解锁 CB、互动、决议）和修正。
- 结局决议在斗争窗口里显示，每个结局限定阶段和条件，决议触发结局事件，事件里 `end_struggle`。

## 6. 自拟项（作者授权按推荐拟定，实施后逐条报告）

**结构**
1. 只设一个静态分区（北方八州 + 荆扬），阶段全局统一；沦陷状态用县变量和县修正表达，不再动态改分区。

3. 组和阶段的开放用组参数（北伐、讨胡、发起汉化/胡化）和阶段参数（起兵北还），窗口里能直接显示"可北伐"等字样。
