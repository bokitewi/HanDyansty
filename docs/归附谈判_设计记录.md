# 归附谈判 设计记录（2026-10-25）

状态：设计已定，实施中。把「劝其归附」「请求归附」与郡国制军阀契约接起来：归附的诸侯会开条件，受附者答应、还价或拒绝。

## 1. 用户拍板

| 项 | 决定 |
|---|---|
| 范围 | 劝其归附、请求归附两条路都加谈判，共用一套条件和结算 |
| 形式 | 两者兼有：玩家发起劝其归附时可在互动窗口预先让步；仍不够时对方回信索价 |
| AI 之间 | 也谈判，按同一规则自动结算，不弹窗 |
| 肯降者要价 | 部分会：贪婪/野心/傲慢者本来肯降也趁机开价 |
| 条件 | 赐金、赐威望、让影响力、许为军阀 |
| 组合 | 主条件 + 加价：窗口里让步一次只选一项；对方回信可再要一项（合计至多两项）；原版封建义务三选一保留 |
| 赐金基准 | 按归附者家底：半年 / 1 年 / 2 年收入 |
| 威望/影响力 | 受附者扣多少，归附者加多少 |
| 档位与接受度 | 赐金 半年/1年/2年 = +10/+20/+40；威望 150/350 = +12/+25；影响力 100/250 = +12/+25；军阀 +60 |
| 基础接受度 | 劝其归附被劝方 -50 → -100；请求归附接纳方 +50 不变 |
| 索价上限 | 差 60 以内才回信索价，超过直接拒绝 |
| 要价偏好 | 看性格、军力、好感（野心、多疑、贪婪也倾向军阀），权重见 §2 |
| 趁机要价 | 必开中档（1 年收入 / 350 威望 / 250 影响力），野心者要军阀（不够格则影响力）；发起者已预开价则不再要；不答应就不降 |
| AI 强者招降 | 差 60 以内先招降并预开价（推测对方想要的），付不起或差太多照旧开战 |
| AI 受附者付价 | 金/威望/影响力付完不为负就答应；许为军阀须自身军力 ≥ 对方 3 倍，多疑或对其好感 ≤ -30 不许 |
| 军阀承诺 | 10 年：AI 主君不发起收回权力；玩家提前收回算背约：威望 -350，全体封臣好感 -15（五年衰减） |
| 玩家被劝 | AI 劝玩家归附改为事件：无条件归附 / 索赐金 / 索威望 / 索影响力 / 索军阀 / 拒绝；各项取对方付得起的最高档；AI 按付价规则答复，不答应即谈崩 |
| 请求归附开价 | 有贪婪/野心/傲慢/多疑，或军力 ≥ 对方 1/4 的开一项中档条件（偏好同索价）；其余无条件 |
| 野心/傲慢投靠 | 放开否决，但必须开价：野心者要军阀（不够格则影响力），傲慢者要威望；不答应就不投 |
| 玩家收到附条件的投靠 | 事件：答应条件 / 只许无条件 / 拒绝 |
| 还价 | 降一档掷骰：成功率 = 40 + 对你好感 × 0.5，贪婪/傲慢 -20，知足/谦逊 +20；失败即谈崩 |
| 只许无条件 | 套用还价掷骰；必须开价的野心/傲慢者一律不投 |
| 付款 | 归附当天付；余额不足整笔作废、不归附，视作谈崩 |
| 谈崩冷却 | 沿用现有 2 年（劝其归附同一对 2 年；请求归附 2 年不投同一人、1 年不投任何人） |

## 2. 要价规则

偏好权重（归附者视角）：
- 军阀：野心 +40、多疑 +30、贪婪 +20；军力 ≥ 受附者一半 +30、≥ 1/4 +15；对受附者好感 < 0 +20、≤ -30 再 +20、≥ 50 -30
- 赐金：基础 20，贪婪 +40
- 威望：基础 10，傲慢 +40
- 影响力：基础 10，野心 +15

缺口结算：
1. 可用条件 = 受附者付得起（AI 受附者还须愿意）且合资格的条件。
2. 主条件 = 可用条件里权重最高的；取能补上缺口的最低档，补不上取最高可付档。
3. 仍有缺口：在其余可用条件里取权重最高的作加价，取补得上余缺的最低档；补不上则谈不拢，按拒绝处理。
4. 玩家已预开一项时，该项算主条件，对方只能再加一项。

## 3. 自拟项（实施时按此执行，待确认）

1. 赐金数额下限 10 / 20 / 40，防止收入为 0 或负时白给。
2. 军力口径：归附者用最大兵力（max_military_strength），受附者用当前兵力（current_military_strength），与现有兵力比一致。
3. 权重相同时的先后：军阀 > 赐金 > 威望 > 影响力。
4. 趁机要价时受附者一项中档都付不起：照常无条件归附。
5. 请求归附里非必须开价者（贪婪/多疑/军力）对某个受附者一项都付不起：照常无条件投靠；必须开价者则跳过该受附者。
6. 还价降的是对方最后要的那一项；军阀降为影响力高档，没有影响力则降为大额赐金，再不行则改为无条件。
7. 许为军阀的资格：双方郡国制、归附者主头衔县级以上且非世家头衔、归附者不在被收回权力的 5 年冷却中。
8. 背约只认「收回权力」互动（同意或拒绝都算）；原版剥夺头衔不算。
9. 军阀承诺记在军阀本人身上，10 年或本人去世即止。
10. AI 劝玩家归附的事件当场出结果（不再等 5~10 天）。
11. 玩家对玩家（联机）的劝其归附：只有窗口预开价，没有回信索价。
12. 影响力条件只在双方政体都有影响力时出现。

## 4. 实现要点

- 条件记在归附者身上：`hd_neg_liege`（对手）与 `hd_neg_gold` / `hd_neg_prestige` / `hd_neg_influence`（数额）、`*_tier`（档位）、`hd_neg_warlord`、`hd_neg_last`（最后要的一项）。归附者同一时间只会有一场谈判（现有收件/发件锁保证）。
- 脚本发出的互动带不了窗口选项，所以 AI 的预开价写成变量；接受度的条件项同时认窗口选项和变量（liege 须匹配，二者不叠加）。
- 回信索价要知道缺口：`hd_neg_base_accept_value` 照抄劝其归附的 ai_accept（不含条件项），需要 scope:actor / scope:recipient。
- 许为军阀写法照 `hd190_warlord_one_effect`：归附结算后直接 `hd_warlord_establish_effect`（不扣主君好感），加 `hd_warlord_revoke_ai_grace` 10 年与承诺变量。

实施中的补充（未单独问）：
- 回信索价的事件路径成交不走原版契约选项，窗口里选的封建低/高义务在这条路上不生效（封建制默认普通义务）。中国境内的郡国制归附者不受影响。
- 追加加价时不与预开价重复同一项（例如预开小额赐金后不会要求「改为中额」）。
- 正在请求归附别人的诸侯不能被劝其归附（两边条件存在同一组变量上）。
- 谈判得来的军阀归附 3 天后再跑一次军阀身份自检，防止归附当日引擎补契约时没写上第 6 档。
- 战略 AI 对玩家目标的招降门槛：原来看「对方是否可能接受」，基础改 -100 后会少招很多；改为与 AI 目标一致的「接受度差 60 以内就先招降」（AI 无从预开价，由玩家在事件里开价）。
- 赐金走私库金钱（`gold`），不走国库：郡国制把建筑、常备军等开销都改由国库支付，私库主要用于个人花销，AI 主君一般不缺。若要改成国库或「国库优先」，可换成原版的 `treasury_or_gold` / `pay_treasury_or_gold`。
- AI 招降、战略 AI 借用了 `scope:actor` / `scope:recipient` 来复算接受度，用完即清，宣战前也先清，不带进宣战回调。
- 各分支写了 `HD_NEG …` 诊断日志（game.log），见测试清单。
