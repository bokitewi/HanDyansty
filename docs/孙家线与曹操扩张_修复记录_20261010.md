# 孙家线与曹操扩张 修复记录（2026-10-10）

依据：2026-10-10 18:56 开的 184 观察局（存档快照 217.1.1，logs 同批）。全部改动未进游戏实测。

## 一、诊断结论

### 孙家线
1. 孙坚 history 里 `192.7.1 death` 开局后不执行（未来日期的人物历史不生效），孙坚活到 200 年，靠 hds.5000（土地饥渴）→ 玉玺密谋才死（本局 200.5.2 被刘表谋杀）。整条线晚 8 年；许贡 192–195 已吞吴郡/毗陵/会稽/丹阳。
2. 孙策继承营地后 hds.4000–4003 都触发了，但存档战争名表里没有任何丹阳之战（`hds_wu_invasion_cb`）。具体哪一项拦住无法确认：debug.log 在 19:03（约 195–200 年）后不再写 [D] 行，`HDS_SC_WAR` 诊断全丢。最可疑：无地营地身份用自定义 CB 宣战。
3. 玉玺交易用 `owner = character:yuan_shu` 判断神器归属（应为 `artifact_owner`），交易永不确认 → 5000 甲士从未发放。同类错误还在 `hds_sun_succession_effect`、`hds_sun_force_inherit_effect`。
4. 孙策 204 病死后线断：孙权不在任何 hds 触发里，继承营地后流浪到 253。

### 曹操
1. 只要有扩张剧情就被战略 AI 视为"托管"（`hd_strat_historical_managed_trigger`），吞并战全图 581 场，曹操 0 场。
2. 扩张 CB 每场都以整个州（k_uuii_yanzhou）为目标，推测同一头衔只能有一场战争 → 一次只能打一场；204–216 两场战争拖 12 年未得一县。（推测，未在游戏里验证）
3. 地区完成要求 100% 法理县，兖州 107 县只控制 29 县，换方向菜单从未出现。
4. 214 年持有兖州+荆州两个王国 → 天意青睐退休。

## 四、自拟项（请确认或改）

1. 岘山凶手：黄祖在世用黄祖，否则记为刘表。死因 `death_battle`。
2. 岘山窗口内的落点按"当前日期分 8 档"给延迟区间，近似均匀分布到 192 年底；191.1.1 前不排期。
3. 岘山触发时孙坚或刘表被囚：撤销排期，下次 60 天检查重排；刘表已死：永久取消，交给 200 年兜底。
4. 孙坚 200 年兜底那条路（无玉玺时直接打丹阳）也改用共用发起器：营地身份直接强制开战。
5. 立足成功后销毁孙氏家族庄园（与原"出走即毁庄园"一致）并清空孙坚庄园缓存变量；营地头衔销毁、政体改 `celestial_government`。
6. 孙策若已有封地（不靠立足县），直接视为立足完成，不再拿袁术的地。
7. 强制开战仍尊重停战、结盟、已在交战（`hds_candidate_enemy_trigger`）；优先打持有丹阳郡头衔的那一方。
8. "连续 3 次失败"按每次 60 天检查计，第 4 次检查起强制；成功开战后计数清零。
9. 孙权补兵：孙策领过保底兵（3000 轻步）的，孙权一次补 3000 轻步。若孙权本就是原生继承人，可能与兄长遗下的部队重复。
10. 孙权本人已有封地时，不接孙策的营地/庄园类无地头衔。
11. 旧的 debug_log 诊断（`zz_hd_sun_ce_war_diag_effects.txt`）已无调用点，文件保留未删（死代码）；改用存档全局变量计数。
12. 曹操空转计数：只在"本地区没有任何扩张战在打、且这次也没开出新战"时 +1，任何扩张战存在即清零；结束原因记为 `flag:hd_cao_expansion_stalled`。
13. 曹操按郡搜索时按法理层级的固定顺序逐郡找（先相邻势力、再全地区），不随机。
14. 每场扩张战胜利只拿守方在该郡内的县（原来是在整个州内的县）。
15. 丹阳开战（合法与强制）都不以持有 h_china 的天子为对手，避免孙家在汉室未分裂时对整个帝国宣战。

## 四之二、风险（测试后再定）

- **立足县可能落在南阳。** 本局袁术 184 年持有扶风、188 年起持有南阳；历阳（c_uuii_p_1984）184–200 年在 4220 手里，不属袁术。孙坚 191–192 年死、孙策"继承后立即"出走时，"袁术境内离丹阳最近的县"大概率在南阳一带，离丹阳几百里，而且是从袁术核心领地里切出来的。可选调整：等袁术拿到淮南/扬州的地再渡江；或者允许在扬州境内立足。
