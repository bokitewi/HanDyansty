## 0. 开局日期与设定
- **开局日 253.3.1**（蜀汉延熙十六年正月十四前后，魏嘉平五年，吴建兴二年）。

## 4. 方案

### 4.1 总体原则
- **只写一个日期**：只考虑新开存档。所有新内容只写 253.3.1 这一个日期的条目；所有开局脚本都带 `game_start_date = 253.3.1`、`current_date` 闸门和一次性全局变量（写法照 218）。
- **新文件优先**：书签、头衔历史、开局脚本、宣战理由、修正、本地化都放新文件。共用文件只改 4.13 列出的几行闸门。
- **不污染其他开局**：253 的头衔条目在 346/404 也会生效，因为日期更早。
  - 动工后用脚本算出 346.12.10、404.3.24 两个日期每个头衔的实际持有者，与改动前逐一比对。
  - 凡因 253 条目而变化的，在 253 文件里同头衔加一条 `346.12.10 = { holder = 0 }` 复原。只针对两个南北朝文件没写到、原本就无人持有的头衔。
  - 184、218 早于 253，不受影响。
- **不在 history 里新建虚构人物**：253 年需要的大量郡守、边地首领，一律在开局 on_game_start 里用 218 的写法运行时生成（`create_character` + 授郡）。history 里只引用已有人物。

### 4.3 领土连通性检查（只按 provinces.png 与 adjacencies.csv 实算）

2. 排除 `default.map` 里的海、大河、湖、不可通行地块，再提升为县相邻。
3. 加上 `adjacencies.csv` 的 50 条渡口。
4. 每个顶层势力和每个直属势力分别算连通块。
