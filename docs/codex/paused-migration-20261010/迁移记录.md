## 如何测试

1. 草稿分支不等于main；先下载**本分支或指定提交**的完整ZIP，而不是仍下载main旧内容。GitHub：选分支→Code→Download ZIP，也可按提交下载。[官方说明](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)。
2. ZIP解压后是完整主MOD，不是增量补丁。放入独立本地测试主MOD目录，用启动器的本地MOD描述注册该目录；保留仓库descriptor的replace_path及美术／纹章等原配套。不要直接覆盖工坊目录，也不需要再开启旧活动MOD。
3. 同一播放集不要同时启用工坊主包和这个完整本地主包。用户手动停旧活动包；也需选择测试主包而非工坊主包。此记录不替用户切换。
4. 重新启动游戏并开184新局，先测封公名称：直接“X国”、兼持朝臣仍为“X国”、人物X公／X王不变、死亡授谥名干不带“国国”。扩郡／晋王及谥号按实际步骤另验。
5. 中国进位当前只允许作为初版查错，不能按完成品验收。三辞三让与宫廷分层没有运行代码，不列可测。
6. 可先运行 `node tests/real_fief_x_country.cjs`作离线回归。游戏截图／当前日志与离线结果分开记录。
