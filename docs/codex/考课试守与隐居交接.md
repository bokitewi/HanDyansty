### 2. 五年试守：署名、续守、退职

仍选地方官；最好兼持两个地方官职并有士族头衔。先用下行撤下三种入仕资格、设为试守（只用于测试）：

```text
effect { remove_character_modifier = WJ_bizhao_modifier remove_character_modifier = WJ_xiaolian_modifier remove_character_modifier = WJ_maocai_modifier WJ_temp_official_apply_effect = yes }
```

然后执行第1节命令，分别替换公务分：

- `30`：80分良，举孝廉，署名取本朝郡级实职官员。
- `50`：100分优，举茂才，署名取本朝州级及以上实职官员／朝臣。
- `0`：50分平，仍试守，保留全部官职。
- `-10`：40分差；`-30`：20分劣。应卸下全部地方官职，交现任命继任者，保留士族与爵位，不加隐居特质、不发退休资源、不再起地方五年期。关闭结果后走一天，复核原任命回调及身份清理。

再测“试守”须先重新准备无资格状态，不要把上轮已转正的人当试守。无合适署名官员时仍应转正；考官不是名义举主，不应增加恩师／门生关系。

### 3. 一年三轮考试

选本朝有效试守的中央任職者，须不符合地方五年资格。可自然等一年后走原考试，或直接准备考官和39分结果：

```text
effect { WJ_set_up_temp_official_examiner_effect = yes set_variable = { name = wj_official_assessment_score value = 39 } trigger_event = wj_temp_official.1005 }
```

39分关闭后续守、原官职保留，下轮仍一年。改40分应通过，原按最高非士族官职授资格规则不变，署名按真正获得的孝廉／茂才选。不要对地方五年角色用此命令。
