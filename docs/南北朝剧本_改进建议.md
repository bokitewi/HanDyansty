# 南北朝剧本组改进建议（346「戡定岷峨」、404「京口起兵」）

日期：2026-10-13。这份文件只提建议，没有改任何 mod 文件。以后真要做其中哪一条，按项目规则先写计划交复核再动手。

所有建议都以《南北朝剧本_整合计划》里你已经定下的决定为前提，没有推翻：工坊系统只搬谥号；北方胡族用天朝制；侨州法理全部启用；327、440 两个书签不做；长生人物保留；郡及以下的法理不动。确实想重新讨论的只有一处，单独列在第 6 节。

## 0. 先说结论

1. **现在两个开局里有几处会直接出错，最该先修**：
   - 404 年刘裕、沮渠蒙逊、社仑、广开土王会被"历史入侵"系统再起一次兵，广开土王还会出现两个；
   - 各政权都没有设国号，晋帝的帝国头衔显示成"关中"；
   - 朝官全部空着，随机补位又被关掉了；
   - 两场开局战争只有主攻方一个人参战；
   - 404 年桓玄和北方各国都没有年号。
   详见第 1 节。
2. **历史事件太少**：现在只有桓温伐蜀、京口起兵两场开局战争和一个谯纵兵变，开局几年后就和史实脱钩了。工坊原 mod 也只有这一个事件，没有现成的可搬。建议照 218 剧本的写法（`zz_hd_218_history_effects.txt`，"只由史实本人发动，条件不合就跳过"）给每个开局各写一条 10 到 15 个节点的主线。详见第 2 节。
3. **玩法上收益最大的是把衣冠南渡的后半段重新打开**。本 mod 已经写好北伐、立侨州、土断、北府这些事件（`events/zz_hd_yiguan_south_events.txt` 1101–1303），但南北朝开局为了不重演南渡，把整个局势挡掉了，这些事件也一起没了。详见第 3 节。
4. **职位和头衔目前完全是汉制**：三公九卿、州牧。东晋的录尚书事、中书监令、都督中外诸军事，北方的天王、大单于、行台都没有。建议先只改显示名，不新增职位。详见第 4 节。

## 2. 历史事件

- 新建 `zz_hd_nbc_history_on_actions.txt`，每年检查一次，所有条目带 `game_start_date` 闸门。
- 和已有系统的分工：建国、起兵类节点优先用历史入侵 hd_hi，例如 346 的慕容儁、404 的赫连勃勃已经有了，只补缺的；朝廷废立用权臣与天子 hd_court；民变用农民义军。

## 3. 玩法设计

### 3.1 衣冠南渡后半段（推荐最先做）
现在南北朝开局设了 `hd_yiguan_started`（`zz_hd_nbc_startup_effects.txt`:9），整个局势不会启动。建议改成"以后期阶段直接开局"：不重放难民、渡江事件（1001–1003），只放这些事件：
- 1101–1103 流民帅：祖逖型、郗鉴型、苏峻型；
- 1201–1203 立侨州、侨郡安户、侨姓吴姓之争；
- 1210 土断；
- 1301–1303 北府。

404 年北府已经成型，可以跳过 1301。局势的阶段变量 `hd_yiguan_phase` 已有分阶段的写法（`zz_hd_yiguan_effects.txt`:52-60），开局直接设到对应阶段即可。北方的胡族汉化决议（`zz_hd_yiguan_decisions.txt`:87-90）也依赖这个局势，会一起恢复。

### 3.2 北伐
现在只有通用的统一宣战理由，没有北伐。建议做一个南方天子或其方镇可用的"北伐"决议加宣战理由：
- 目标限于侨州对应的北方故土；
- 胜利后侨州"还治"本土，与侨州法理联动；
- 失败扣声望，并给权臣（桓温型）加威望或减威望；
- 北府、流民帅随从加成。

用来承接殷浩、桓温、刘裕的几次北伐。

### 3.3 荆扬之争（上游方镇）
东晋政治的主线是荆州（上游重镇）对扬州（朝廷）：王敦、庾亮、桓温、桓玄都是这条线上的人。346 开局桓温一人就持荆、湘、郢三州。建议：
- 荆州刺史兵多、好感度低时，自动进入 hd_court 的"权臣"候选；
- 扬州刺史作为朝廷制衡，可以选"以殷浩制桓温"这类事件。

这样不用新系统，只是把现有权臣系统的触发条件扩到"上游方镇"。

### 3.4 门阀
王、谢、庾、桓、郗等高门可以接现有的天朝制家族集团（`project-celestial-house-blocs`）和氏族团结度：开局把这些家族设成高门集团，给"门阀""寒门"（北府、刘裕）一组对立的好感修正。清议、月旦评本来就通用，可以直接复用作"九品中正"的表现。

### 3.5 北方胡族政权
- **时代套件**：现在 adv/con/exp/ten 四套都要求持有 h_china（`hd_dc_kit_*_triggers.txt`:4-6），北魏、后赵用不了汉化决议（`hd_dc_kit_con_decisions.txt`:131）。建议对"持有帝国头衔、天朝制、非天子"的统治者放开其中的汉化、改制类决议。
- **胡汉分治**：后赵、前秦、北魏都设过大单于与天王两套班子。可以做一个决议：设"单于台"，胡族封臣好感上升、汉人士族好感下降；后期可以选择"罢单于台、汉化"。
- **鲜卑各部文化**：拓跋、慕容、乞伏、秃发、宇文目前都是同一个 xianbei，柔然、丁零（高车）没有文化。只做中文的话工作量不大，但文化数量要考虑性能，所以列为可选。

### 3.6 天子只有一个
天朝循环只认 h_china 的持有者，也就是晋或楚。北方称帝的石虎、慕容儁、苻坚在系统里都只是地方势力。这是最大的结构问题，有两种办法：
- 保持只有一个天子，北方帝号只做显示（国号、天王、皇帝称谓）。改动小，推荐。
- 做"正统之争"：北方帝国也能挑战天子地位，例如淝水之战的胜者夺取 h_china。改动大，会碰到天朝循环的核心，建议以后单独立项。

### 3.7 平衡
- 404 刘裕：见 1.4、2.2，用覆舟山事件，不靠堆兵。
- 346 后赵：史实上 349 年自乱，有 2.3 的石虎死亡节点就够了，开局不用削弱。
- 桓温一人持荆、湘、郢三州，AI 可能早早叛晋。可以考虑把湘州、郢州给他的部将或子弟，让他通过封臣持有。

## 4. 职位与头衔

### 4.1 官名（推荐只改显示名）
现在议政和部门席位都显示为汉制：司徒、大司农、大将军、尚书令、廷尉、太仆、太尉、太傅、宗正、丞相、光禄勋。晋代三公和尚书令仍在，但实权在下面几个职位：

| 现有席位 | 东晋建议显示 | 北朝建议显示 |
|---|---|---|
| councillor_chancellor（司徒） | 录尚书事 | 录尚书事 / 司徒 |
| minister_personnel（尚书令） | 尚书令（不改） | 尚书令 |
| councillor_marshal（大将军） | 都督中外诸军事 | 大将军 / 都督中外诸军事 |
| councillor_steward（大司农） | 度支尚书 | 度支尚书 |
| councillor_spymaster（司空） | 中书监 / 中书令 | 中书监 |
| minister_justice（廷尉） | 廷尉（不改） | 廷尉 |

做法：开局设一个全局变量，例如 `hd_era_nbc`，在 customizable_localization 里按这个变量切换显示名。本 mod 已有按政体旗标切换 `_hanjin`/`_tang` 的先例（`WJ_ministry_positions.txt`:77-96）。不新增职位，也就不碰百官界面（工坊的 window_council.gui 会和百官冲突，你已定不搬）。

### 4.2 称谓
- 北方君主"天王"：石虎 346 年称"大赵天王"，苻健、苻坚都称天王。建议按国号或变量给持帝国头衔、未称帝的胡族君主显示"天王"。工坊的 `flavorization/beichao_meritocratic_title_holders.txt` 有现成的称谓表（天王、行台、镇将、仇池公），可以只借称谓、不借尚书体系。这一条碰到你"北朝尚书体系不搬"的决定边缘，单独列在第 6 节。
- 州长官：东晋刺史多带"都督某某诸军事"，而本 mod 州头衔持有者显示为州牧或刺史。建议在南北朝开局里统一显示"刺史"。

### 4.3 爵位
