## 2. 流程

```
决议"隐居养望"
  └─ WJ_yangwang.0001（保留）：玩家选雅号 / AI 随机雅号
       └─ 确认 → WJ_yinshi_enter_effect
            ├─ 辞官（交还头衔、离职、卸任骑士将领、set_knight_status = forbid）
            ├─ 加特质；设 150 年拒任期（已有外部拒任期则沿用旧的接力机制）
            └─ create_story = story_WJ_yinshi
故事（effect_group 每 120–240 天）
  └─ WJ_yinshi_pick_event_effect：10% 邀请 → 否则四类各 25% → 类内随机未冷却事件
出山（决议 / 接受邀请 / 接受授官）
  └─ WJ_yinshi_exit_effect：移除特质、清自有拒任期、恢复骑士资格、结束故事、加 15 年冷却标记
死亡 → 故事结束
```

## 5. 找人规则（避免全图搜索）

- 朋友类：先 `random_relation = { type = friend }`；没有则从直属上级宫廷里挑好感 ≥20 或近亲；再没有就改抽别的类。
- 当地人类：大多是无名乡人（无肖像），部分事件用所在县的持有者或所在地宫廷人物；县修正挂在 `location.county`。
- 邀请类：入幕只找玩家府主（沿用旧条件）；孝廉/茂才沿用旧发邀者条件。每次最多一次全图搜索，只在 10% 的邀请分支里发生。
