1. **`events/hd_party_events.txt` · hd_party_chain.32.b"赐以钱粮"**（生成器 `SPEC[('wuxun', 2)]`）

### 2.2 只影响显示的脚本改动（游戏结果不变）
4. **`common/scripted_effects/hd_party_effects.txt` · `hd_party_loyalty_resolve_effect`**（生成器约第 870 行）
   - 原写法：`random { save_scope_value_as }` 后接 `if exists scope / else`。预览时该 scope 尚不存在，要求效忠的每个选项都只显示失败一支（"此党拒不奉命"）。
   - 现写法：`random_list` 两支，权重分别为 `hd_party_loyalty_chance_$G$_value` 与 100 减该值，各带 `desc`，原版 harm_events 也是这种写法。选项提示因此同时显示成败两种结果及几率。
   - 实际结算放进 `hidden_effect` 的 if/else，以 `local_variable` 判定成败，并用 toast 告知结果。
   - 结算完毕即 `remove_local_variable`，因为 AI 在一次 `hd_party_ai_ruler_effect` 中可能连续对多党要求效忠，不清掉会把前一党的成功带到后一党。原写法 `save_scope_value_as` 也有同样的串用隐患，此处顺带消除。
   - 成功率、各分支效果均不变。AI 走同一 effect。
5. **事件链 15 个事件的所有选项**：满意度和势力变量的变化在界面上看不见，故按 §1B.3 各加一句叙事提示，共 49 处 `custom_tooltip`，新键 `hd_party_tt_*`：

   - "稍感宽慰"（折中）
   - "怏怏不平"（拒绝，或他党受损：12.a 武勋、22.a 武勋、41.a 寒门、52.a 宦官）
   - "声势大张，权倾朝野"加"其余诸党侧目而视"（第三段接受）
6. **hd_party.0101.a**（解除党锢）：加叙事提示"被禁锢的士人得以还归故里，寒门之中人心稍安"。
7. **立场之辩**：辩论进度是看不见的变量，在下列选项加叙事提示，共 17 处：
   - 0010.a、0021、0022.a、0023.b、0024、0032、0033.a、0040.a/b
   - 0025、0031 的随机两支各一句
   - 0050.a/b：裁断的胜算一句，加相关朋党不满一句
8. **`tgp_dynastic_cycle_decisions.txt` · favor_movement_decision 的 effect**

## 6. 自拟项与不确定处（需用户拍板的标 ★）
- ★ **42.b"略加约束"去掉付金后，此选项不再有花费**，仅推进事件链。若希望保留代价，可改回付金，并把文案改为"稍加禁约，厚赐以安其心"。
- ★ **31.a 原为"拜将封侯"**，实际效果只给前将军军号；已有军号者改为 +300 威望，不涉及封侯。已把选项改为"拜为将军"，正文改为"请你拜之为将、厚加封赏"，标题"拜将封侯"作为成语保留，脚本未改。若希望真正"封侯"，可仿 21.a 赐一县。
- ★ **0024 基础 −2**（见 2.1 第 3 条）。数值按 0021 对称取定。
- **守旧派对应"追名逐利"封臣立场**，语义略怪。这是 `00_vassal_stances.txt` 的映射（不属本单元），文本只是照实写出。
- **只报告、未修的脚本问题**：
  - hd_party.0020：选项 c（威望 300，仅限无影响力政体）与 d（威望 1000）成功率相同。无影响力政体两个选项会同时出现，d 严格劣于 c。建议给 d 加 `government_has_flag = government_has_influence`。
  - hd_party_debate.0010.a（50 金）与 hd_party_chain.51.a（100 金）没有 `gold >=` 条件，可能扣成负数。0022.a、0040.a 则有该条件。
- 事件链 52.b"听之而已"的效果是你 −100 威望、清议领袖 +150 威望，可解读为容忍清议、声名受损而彼得名。12.b 与 22.b 的"赐以名号/荣名"同理，即以你的威望成全对方。三者均未改。
- `hd_party_loyalty_resolve_effect` 里有一层 `hidden_effect` 的缩进不规整，这是有意为之：保持原有的 `set_variable = { name = hd_party_$G$_… }` 行逐字不变。否则校验器会把含 `$G$` 的 `name =` 误报为"新引用的本地化键不存在"。语义上无影响。
