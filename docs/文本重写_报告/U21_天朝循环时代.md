## 2. 效果改动清单
本单元没有改动任何玩法数值或效果，只改了效果的展示方式。

1. **`events/hd_collapse_crisis_events.txt` · `hd_collapse.1001` 选项 b（"乱臣贼子，安敢要挟朝廷！"）**
   - 改前：`hd_collapse_refuse_independence_effect = yes` 直接列出。提示里只会显示创建派系、设旗标、邀请封臣等内部步骤。
   - 改后：`custom_tooltip = hd_collapse.1001.b.tt` + `hidden_effect = { hd_collapse_refuse_independence_effect = yes }`。
   - 理由：结果是延迟结算（次日聚众两人以上才开战），按 §1B.3 用一句叙事说明。
2. **`events/hd_dc_era_events.txt` · `hd_dc_era.0001` 选项 a**
   - 删去 `custom_tooltip = hd_dc_era_rules_tt`，只保留一句叙事提示 `hd_dc_era_no_sovereignty_change_tt`。
   - 理由：这是规则清单，原样保留在群雄逐鹿的时代说明（`chaos_desc` 用 `$hd_dc_era_rules_tt$` 引用）里，事件中只留叙事。
3. **`tgp_dynastic_cycle_decisions.txt` · `situation_dynastic_cycle_claim_mandate_decision` 的 effect**
   - 改前：天命之赏在 `hd_claim_mandate_from_chaos_effect`（`zz_hd_dynastic_cycle_effects.txt`）中放在 `hidden_effect` 里，包括国库（≥1000）、影响力 ×4、正统拉满。玩家看不到这些赏赐，决议末尾却总挂一句"……原版天命进程判定"。
   - 改后：在交接之前加 `if = { limit = { hd_dc_can_receive_mandate_reward_trigger = yes } show_as_tooltip = { add_treasury / change_influence / add_legitimacy（与原隐藏效果同值） } } else = { custom_tooltip = hd_dc_mandate_observation_tt }`。删去原来无条件显示的 `custom_tooltip = hd_dc_mandate_observation_tt`。
   - 理由：§1B.3。判定放在交接之前，因为交接后会记下"已领赏"。实际执行不变。
   - 政体：非天朝政体的宣称者（游牧、外族）会在 `hd_transfer_mandate_to_claimant_effect` 里先 `change_government = celestial_government`，有了国库和影响力之后才领赏。所以展示的赏赐对所有宣称者都成立，无需再按政体区分。原版同类赏赐也藏在 `hidden_effect` 里，原版没有说明为什么隐藏。

4. **`$harmonious$` / `$antagonistic$` / `$activity_debate$`**：引用原版键（和谐／对抗／辩论），保证与家族团结阶段、活动的显示名一致。
