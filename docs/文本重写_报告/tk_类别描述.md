# tk 特殊建筑 · 类别描述对照表（U01 定稿，2026-10-09）

用途：`building_type_TK_*_desc` 一律按该建筑的类别名（即同名 `building_type_TK_*` 的值）取下表中的描述句；同一类别共用同一句。
`building_type_TK_*`（不带 `_desc`）是类别名，属于名称，**不改**。

- 共 30 类，覆盖 `tk_buildings_l_simp_chinese.yml`（U01，20 类）与 `tk_buildings_2_l_simp_chinese.yml`（后半，10 类：各矿 + 地貌景观）。
- 句中无英文双引号、无 ASCII 数字、无 `$ # [ @`，可直接写入。

## 给后半文件执行者的提醒（U01 的做法）

- 建筑描述 `building_TK_*_desc` 以汉末时人视角写：去现代行政区、公元纪年、"距今"、后世朝代沿革、"世界最大/海拔"之类科考口吻、金庸/影视/景区等现代语。
- 地名尽量用汉时郡县名（如蓟、番禺、临湘、秣陵、钱唐、江夏、叶榆、交趾）；年代用"孝武皇帝时""光武中兴""王莽时"等，不写"西汉/东汉/三国"。
- 矿山类可借《论衡》《史记·货殖列传》《汉书·地理志》等汉代已有的典籍或传说（如原文已引的"黄帝采首山铜"）；查不到可靠的汉代出处时，只写山川形势与开采景象，不要自造典故。
