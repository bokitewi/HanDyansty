## 6. 自拟项与不确定处（需用户拍板）

1. **后世朝代出处与"未来"出处是否保留**：年号寓意后的"（唐太宗使用）""（宋徽宗使用）"等注文是后人视角。目前全部保留，只修正了错误。如果要坚持汉末视角，可以统一删除汉末以后的出处，或改成"后世亦有用之者"之类的说法。WJ_names 的 `_tt` 副本也要一并处理。
   - 同一问题也出在游戏时间线之内：184 年开局时，初平、兴平、建安、延康（汉献帝）、章武、建兴、黄龙、嘉禾、赤乌、青龙、太和等年号尚未出现，注文等于提前透露了未来。建议与后世出处一并决定。
2. **长字年号中有几个残句名称**，是由一句长语截成两半得来的：
   - 012.z 政通人和百废
   - 012.al 日月合璧五星、012.am 连珠共贯增辉
   - 012.ar 天不爱道地不、012.as 藏宝圣人临御

   年号属于名称，本次未改。如果要改，需要同步改 `WJ_names` 中的 `SG_nianhao_*` 名称键（变量名不必改）。
3. **未能核实的出处**：003.ab 景瑞（大理段思廉使用）、003.ac 嘉瑞（大理段正严使用），据记忆两人的年号中似乎都没有这两个，但不能确定，所以没有改。
4. **自拟的修正**：
   - 太平改注为"吴会稽王孙亮"，即吴废帝，256–258 年用此年号。
   - 麟嘉改注为"汉刘聪"（汉赵），后凉吕光也用过此年号，取了较早的一例。
   - 凤翔改注为"夏赫连勃勃"。
   - 万安、永丰、安宁、建业、兴国、明堂没有查到可靠的出处，直接删去出处，只保留寓意。
