### 1.1 兵种描述（25 个 `_flavor` 键）

本 mod 的兵种描述键是 `<兵种>_flavor`，与原版 `regiment_l_simp_chinese.yml` 的写法相同，没有 `_desc` 键。原文多是「以突击撕开敌阵」「这身装具自有用处，却不能替持兵者抵挡所有锋刃」这类空泛的战术说明。现在全部改成原版式的一两句：这支兵从哪里招募、怎样作战、为何闻名。内容取材于史志，例如：
- 六郡良家子：出自《汉书·地理志》，汉家羽林、期门多从六郡选拔。
- 板楯蛮：高祖用之还定三秦，羌乱时号为神兵。
- 山越：山中出铜铁，自铸甲兵。
- 丹阳：民多果劲，好武习战。
- 湟中义从胡、五溪蛮与马援、涪陵山民射猎。

每条描述都与该兵种的地形加成大致对应，例如藤甲兵写了「受不得北地的严寒」，与其严冬惩罚一致。文中没有任何数值或克制关系。

- **17 种地域兵**开局即可组建，所以只写地域与风俗，不提 184 年以后才出现的人物或事件。例如青州兵不提曹操收编，白马义从不提公孙瓒。
- **8 种勋号精锐**本身以后世人物命名，所以写明其出处。详见 §5。

兵种名称与军队名（`hd_*_army`、`hd_gongsun_baima_event_army`）都没有改。

### 1.2 兵源通知事件 hd_maa_source.0001–0034（改写 98 键）

原文用第一人称「我」，主体是书吏、文书、军额、募额之类的办公场景，并反复说明「招募与扩编须待兵源恢复」。改动如下：
- 正文改为第二人称「你」。
- 写出兵源断绝的原因，与 `hd_valid_*_source_trigger` 的三项条件对应：直辖县已不在手、控制力不足、当地文化不合。叙事写作「郡县或已易手，或是乱后人心未定 / 诸部离心」，并点出具体郡名。例如乌桓写上谷、渔阳至辽东，五溪写武陵，藤甲写永昌。
- 「现有部伍仍可调遣、无法新募」这条信息保留，写成一句叙事。
- 恢复事件写出当地子弟重来应募的场景，并点明新兵仍须花钱招募。
- 标题改成有画面感的短语，例如「白马不复北来」「六郡子弟复来」「山越不复出山」。
- 选项改为文言短句。其中 0013.a、0025.a、0026.a、0028.a 原文已合用，保留未动。

## 2. 效果改动清单

1. **`events/hd_maa_training_events.txt`，全部 24 个投入选项**（1000/1100/…/1700 的 a/b/c）。只改提示，实际效果不变。
   - 改前：选项里直接写 `hd_resolve_*_training_effect = { INVESTMENT = N … }`。该效果内的 `if/else_if` 按变量 `hd_training_score` 分档并 `spawn_army`，按脚本推断，选项提示中可能显示「你获得一支人数为 N 的军队」。可是提示生成时本次分数还没算出，这个变量要么不存在，要么是上一次操练留下的旧值，所以显示的兵数可能与实际结果无关。以上未在游戏内验证。
   - 改后：调用外包一层 `hidden_effect`，前面加一行 `custom_tooltip = hd_maa_training_invest_0/10/20_tt`。这是按投入档位写的一句 `#EMP` 提示，说明新军在首府成军，以及投入厚薄的影响。
   - 理由：结果是随机的，规范 §1B.4 要求这类结果用原版式提示，不写确定数值。扣金、扣威望仍由引擎显示；成军、结果事件和兵力分档都照旧。
2. **`events/hd_maa_source_events.txt`，0005 / 0006（乌桓骑从）**：两个事件的 trigger 各加 `NOT = { culture = culture:wuhuan }`。
   - 理由：`hd_wuhuan_qicong` 的 `can_recruit` 是「`culture = culture:wuhuan`」或者兵源有效，二者满足其一即可。乌桓文化的统治者失去兵源县以后照样能招募，此时弹出「乌桓诸部离散，无从征发」与事实不符。加了这个条件后，这类统治者不再收到断绝与恢复通知。
3. **同文件 0029 / 0030（羌骑）**：trigger 各加 `NOT = { culture = { has_cultural_pillar = heritage_qiang } }`。理由同上，`hd_qiang_qi` 的 `can_recruit` 对羌系文化同样放行。

## 6. 自拟项与不确定处

1. **威望花费的解释**：选项扣威望，原叙事没有交代。现在每篇投入正文用一句话解释：你须以自己的名望招揽好手、许以前程。没有改动数值。
2. **成军结果事件新用了 `[hd_maa_trainer.GetTitledFirstName]` / `[hd_maa_trainer.GetSheHe]`**，原文这几个事件不用 scope。依据：结果事件 1001/1101/…/1701 的 `left_portrait = scope:hd_maa_trainer` 和 `trigger = { exists = scope:hd_maa_trainer }` 都已引用该 scope，它由投入事件经 `trigger_event` 带入。走调试决议时训练者就是玩家本人，个别句子会略显别扭，只影响调试。
3. **兵源断绝的原因**写作「或已易手 / 人心未定 / 诸部离心」，覆盖了直辖县丢失和控制力不足，没有单独点明「当地文化改变」这一情形。
4. **乌桓、羌骑通知的 culture 条件**：统治者若在游戏中途改换文化，切换前后可能漏掉一次通知。兵源旗标的逻辑没变，招募不受影响。
5. **成军结果正文**：删去兵数以后，四档只靠语气区分，兵力多寡由地图上的军队显示。
