主要处理：
- **人称**：主人事件（0001–0002、1001–1012、9001）、宾客事件（0001 宾客版、0003、2001–2012、9002）和月旦评事件（3001–3501）的正文一律改为第二人称“你”，3501 是 `character_event`，也一并改了。人物引语照旧用“吾/我”，比如 0002 的开席致辞。主人事件里原先用“主人”指称玩家本人的地方，改成“你这个主人”或“你”，涉及 1001、1005、1006、1012、0002.desc.learning 和 0001。
  - 自检脚本扫过两个文件：`.desc` 键中引号以外的“我”为 0。新文本也不再出现“他/她”。原 1010.b 的“让他自己想通”改成了“使其自悟”。剩下的“言他”“他日”是成语，不算。
- **选项**：全部改为文言短句，例如“正色驳之。”“一笑而转其锋。”“乘兴臧否人物。”“以吾声名为之作保。”。原本就是文言的选项保留，只补了句号，例如“以玄理作答：有之以为利，无之以为用。”“客人未免失礼。”。
- **月旦评得票提示**（隐藏变量 `wj_yd_bonus`，引擎无法显示）：
  - 原文写成“得票 #P +1#!/+2/+3/-1”，现在改为分档的叙事句，不写数字：
    - +1：“席间有人因此更愿推举……”
    - +2：“席间不少人因此转而推举……”
    - +3：“满座为之动容，多有转而推举……者”
    - -1：“有人因此不再看好此人”或“反倒有人因此不愿推举……了”
  - 颜色码 #P/#N 保留，玩家仍能分辨方向和大小。
- **投票说明**：
  - `3101.vote_tt` 原文是“本轮投给此人一票，随后可以为其拉票”，改成叙事：“你将此人之名写上竹简，此后或许还能为其奔走一番。”
  - `3101.abstain_tt` 原文是“按我平素的好恶与交情自动投票，不再拉票”，改成：“你不再多想，到时凭平日的好恶与交情写下一个名字。”
  - `3102.desc` 删去“计票还要等到本轮议论结束”这类流程说明，改为场景叙述。
- **评主本人可当选的处理**：
  - `WJ_qingyi_yuedan_candidate_trigger` 写明评主本人可以入选。3401 的两段正文原来都写“主人起身宣布”，评主自己当选时会读成第三人称在说自己，所以改为“竹简点算完毕，众人公推……”，不再提评主。
  - 9001.desc.yuedan 原文是“评主是我，这个名字也会和我的名字一起被人提起”，评主自己当选时说不通，改为“你这个评主的名字也会随之被人提起”。
- **名单人数**：脚本里提名的上限是 8 人，候选人不足时会少于 8 人。因此 3001 和 3201 不再写死“八个名字”，改为“拟好的名单”或“名单上的那些名字”。3301 改为“名单上只剩下四人”。保留“四人进入终评”的说法，这与 `KEEP = 4` 一致。
- **酒、茶两版**：1006 的正文有酒、茶两个版本，标题却只有“酒至微醺”。为免茶席也叫“微醺”，标题改为两版通用的“兴酣之际”。选项和相关活动记录也改为通用说法：“守礼节饮”改“守礼自持”，“借着酒兴品评”改“乘兴臧否人物”，“酒后失言”改“乘兴失言”，2006 的“醉后失仪”改“放浪失仪”。没有为此新增键，也没有改脚本。
- **特质**：`trait_hd_yuedan_mingshi_desc` 改为原版式“该角色曾在月旦评中被诸贤公推为第一……”。当选者另会获得 `WJ_mingshi_trait`，它的中文名是“宦海沉浮”，两者不重名，无需再作区分。
- 品评评语（18 句）、类别名、名单行、各事件的成败短语、绝大多数活动记录原本就是沉浸式文本，没有改动。

## 6. 自拟项与不确定处

1. **1007.b“以家藏书卷相赠”**：已按“效果以文案为准”改为只扣你的钱，见 §2。
2. **2007.b**：原文“以财物相赠”，效果同样是转钱给对方，文义相符，脚本不改。选项改为“赠以财帛。”。
   - 3102.a 原文是“以我的声望为其作保”，此项花的是威望（prestige）。文言化时用了“声名”而不用“清望”，改为“以吾声名为之作保。”，因为本 mod 里“清望/贤望”指 merit，容易混淆。
3. **1011.a“激浊扬清，正当其时”**：脚本注释写着“却也树敌”，但没有任何负面效果，选项文字也没说会树敌。按“文案没有承诺”处理，不改。
4. **1008.a“受其馈赠”（非月旦评版）**：对方请托又送礼，你收下后对方好感不变。文案没有写对方因此感激，所以不改。如果希望“收礼即应允请托”，可以给对方加 +10 好感（pleased_opinion）。
5. **9001.c“择其可用之才，荐之于朝”**：只给你贤望，被荐之人没有任何效果。这里理解为举荐有功，所以不改。
6. **选项文言化**中带典故或改动较大的几条：
   - 1002.b“一笑而转其锋。”
   - 1008.c“虚与委蛇，留此人情。”（效果是取得对方的人情把柄）
   - 2008.c“守口如瓶，须有所酬。”（索要封口钱）
   - 3102.b“奔走权门，为之游说。”（花费影响力）
   - 9002.c“飘然而去。”
7. **可能的脚本 bug（只报告，未修）**：
   - **2011 缺少评议对象**：月旦评进行中、但抽不到有效候选人（例如候选人都已出局或就是本人），而主人又没有附庸时，事件仍可能触发，`scope:wj_qingyi_subject` 不存在。此时选项里的效果和正文中的名字都会失效。immediate 里虽已有“抽不到候选人就改从主人附庸中取”的后备，但 trigger 只检查“月旦评进行中 或 主人有附庸”，这一后备未必有人可取。建议 trigger 改为：主人有附庸，或本轮存在除自己以外的有效候选人。
   - **0002.desc.learning**：判定用的是主人的 `qingyi_guest_learning_intent`。主人的可选意图里确实有“求学”，逻辑没有问题，记录在此仅供知悉。
