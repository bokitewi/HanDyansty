## 2. mod 现状（2026-10-25 摸底）

- 1.20 的宗教是「信仰 + 礼仪」两层。佛教的信仰是 `mahayana_faith`，下面有七个礼仪：`mahayana` 大乘、`dhyana` 禅、`sukhavati` 净土、`pundarika` 天台、`avatamsaka` 华严、`vinaya` 律、`yogacara` 唯识。县和人物身上记的都是礼仪。
- 佛教县只在西域（龟兹、于阗、疏勒、楼兰、焉耆、鄯善等，约 199 县），见 `history/provinces/zz_uuii_generated_county_capitals.txt`。
- 22/89 开局，`common/scripted_effects/zz_hd_early_han_religion_effects.txt` §B 把其中 47 县撤成马兹达或腾格里；还会把开局在世的佛教人物改成本地礼仪，长生人物和宗教人物不改。
- `history/faiths/00_buddhism.txt` 在 1.1.1 就开放了全部七宗，所以 190 年就能改信禅、天台、华严，是时代错乱。
- **白马寺** `TK_20_20_BaiMaSi`、**法门寺** `TK_20_20_FaMenSi` 已定义，文案也写好了（`common/buildings/tk_special_buildings.txt:942/1046`），但地图上没有放置。
- 原版已放置的佛教建筑位：云冈石窟（平城）、少林寺、麦积山、南华寺、灵隐寺，还有六和塔、乐山大佛（唐宋）。悬空寺 `TK_20_20_XuanKongSi` 已定义，未放置。
- 人物：笮融 `ze_rong` 已经是 `mahayana`，190 开局是下邳、彭城的军阀；楚王英 `liu_ying` 是经学（27–71）。玄奘在 OE 人物里（602–664）。**其余高僧人物库里一个都没有。**

## 3. 史实依据要点

- **汉魏禁汉人出家**：《高僧传·佛图澄传》记王度的奏疏，说汉明以来"唯听西域人得立寺都邑"，汉人不出家，魏承汉制。所以东汉魏晋的信徒是侨民（安息、月氏、康居商人和僧人）、少数宗室和天子（楚王英、桓帝），以及个别豪强（笮融），时人把浮屠当作黄老方术的一支。严佛调、朱士行是例外。
- **后赵解禁**：335 年，石虎回应王度，说"佛是戎神，正所应奉"，准许赵人出家。→ 对应已拍板第 6 项：从这里开始可以改个别县。
- **两条传入路线**：陆路是西域 → 敦煌 → 河西 → 长安、洛阳（安世高、支谶、竺法护、罗什）；海路是交趾 → 番禺 → 建业（康僧会、牟子、真谛、达摩）。

## 9. 技术备忘（实施前核对）

- 宗派开放用信仰史书的分日期 `rites = { X = { enabled = yes/no } }` 做开局校正，事件里用 `set_can_convert_to_rite` 打开。**不用 `create = no`**：光 `dhyana` 就被约 2,165 个人物引用，礼仪没创建时，`rite:key` 会报错。
- 高僧出场后才生成，要照现有出场脚本的规矩：标记只在人物真实存在之后才打。
- 22/89 开局的宗教校正，只改开局在世的人物；事件生成的高僧不会被它改掉。
- 原版的 `rite_growth` 只做同一信仰内的分化，本设计不用它。
- **史实主角不能按拼音 ID 找**：东汉同名人物很多。例如 `shi_hu` 是 195 年生的东汉石虎，`huan_xuan` 是 117 年生的桓玄，`yang_guang` 是 110 年生的杨广，`zhang_fu` 是张富，`xi_zao_chi` 是 225 年生。后期主角（石勒、石虎、苻坚、姚兴、吕光、沮渠蒙逊、桓玄、胡太后、杨广、张辅等）实施时按生卒逐个核对真实 ID，找不到就按 R1 退到地点持有者。`shi_xie`（士燮，137 年生）、`sun_deng`（孙登，209 年生）可以直接用。
- **第 44 项"写进历史死因"的实现**：本 mod 里未来日期的 history 死亡不会执行，事件生成的人物也没有 history 条目。所以做成"到史实年份的事件 + 自定义死因文本（death_reason 本地化）"，见 E54、E55。
- **R3 会动到原版建筑**：云冈、少林、麦积山要加"事件发生前不能建"的条件，就得整键覆盖这三个原版建筑，写法参照现有的 `zz_hd_maijishan_buddhist_override.txt`。
