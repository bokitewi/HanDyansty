### 0.1 跨开局总规则（表中「跨开局」列只写差异）

1. 史实日期早于 404.3.24 的新节点，404 开局由自保护前标；晚于 404.3.24 的，四个开局都走心跳。
2. 304/346/370 局跑到 395 年后，局面常常偏离（某国未立、某人未出场）。一律按 A1 §7.3：称号继统类、人事类放宽执行；战争类等双方存在且接壤；立国类只靠入侵，入侵没起就到期跳过，不硬造政权。
3. 非 j16 开局（190、218 等一路玩到 4 世纪，或史实事件规则关闭）：心跳不跑，入侵完全照旧（年度抽签、无闸门、无短路）；唯一的新增是 murongde 条目，它在非 j16 开局按年度抽签起兵（窗口 397–405，A6-F2）。
4. 当事人优先按位置解析（某县的 `top_liege` + 王朝判定），确需某人时才按 ID 用 `hd_j16_resolve_effect = { ID = … AS = … }`。卒年行的死者、凶手参数也要能被生成器认出（§8.1）。
5. 玩家规则照 A1 §7.3：当事人是玩家时一律给事件选项（史实项 / 拒绝项）；被篡者、被换主者是玩家时照 A3-F13 给「逊位 / 拒之」两项；K 类卒年当事人是玩家时照 A1-F6 弹「大限」。
