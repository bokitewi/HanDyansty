## 4. 卒年表生成方案（D12）

### 4.1 筛选口径

只要满足下面任意一条，就是「要角」：在 304.11.20 到 421.1.1 之间死亡，而且在四个开局中至少一个里原生在场或会由 hbirth 出场。

| 类 | 口径 | 自动取数来源 |
|---|---|---|
| R1 君主 | 在 304–421 年间持有过王国级或以上头衔的人，包括十六国各主、东晋皇帝、代王，以及仇池、吐谷浑、高句丽、百济这些外藩王（外藩是否收录见分歧 G5） | `history/titles` 中 `k_`、`e_`、`h_` 的 holder 记录；四个开局的标题历史；节点表里的「X 主」 |
| R2 储君 | 曾被立为太子或世子 | 节点表；history 里的 `designated_heir` 注释（不全，以人工补充为主） |
| R3 权臣、宰辅 | 任录尚书事、丞相、大司马、大将军、太宰、太傅，或在 A2 中被装为权臣 | A2 §1 权臣名单；`hd_court` 相关脚本；人工 |
| R4 名将 | A2–A4 节点中领兵的人，以及开局战的统帅 | 节点表的「当事人」列 |
| R5 宗室重臣 | 诸王，以及开局时持有王国级或公国级头衔的宗室 | 标题历史 |
| R6 后妃 | 节点用到的皇后和太后（褚蒜子、可足浑、刘太后、苟太后等） | 节点表 |
| R7 节点当事人、凶手 | A2–A4 节点表、卒年 K 类凶手列、志向卡、书签中出现的全部 ID | 实施后 grep 脚本里的 `ID = …`、`character:…`、`KILLER = …` |

排除：
- 死亡由节点结局决定的人（X 类：什翼犍、慕容暐、苻坚；以及苻融、梁成这类淝水结局死者），保留现有的独立效果（D11）。
- 只在开局之前死亡的人。
- 卒年在 421 年及以后的人（姚兴以后的赫连勃勃、沮渠蒙逊、冯跋、杨盛等）。
- 自拟人物。

### 4.2 脚本思路（`tools/hd_j16/gen_deaths.py`，新建）【自拟】

1. **读人物**：解析 `history/characters/*.txt`（UTF-8、GBK 两种编码都试），取 ID、生卒、`death_reason`、`killer`、父母、王朝、注释。人物索引照 `eval2/r5/idx.py` 的写法复用。
2. **读头衔**：解析 `history/titles` 和四个开局的标题文件，得到「哪一天谁持有王国级以上头衔」，据此标出 R1、R5。
3. **读引用**：在 `common/scripted_effects`、`events` 中 grep 统一心跳和各节点的 ID 引用，标出 R4、R7；A0 现有的 61 条直接并入。
4. **算可见性**：照 `a5/gen_tables.py` 的写法，算出每人在四个开局里属于原生、hb 还是已死。只在某个开局原生或会 hb 出场、且卒于该开局之后的人，才算「需要进表」。
5. **定日期**：
   - ★先套用 §3 的修正（例如刘粲、刘胤、石宣、六修、安帝的库值都判为错误），以「改正后的库值」为准；
   - §3 没有列出、且库中是精确公历日期（不是 x.1.1）的，沿用库值；
   - 库值是 x.1.1 的，取史料：农历月份加 1 个月换算公历，日取 15，标「待核」；
   - A0 现有表值与库值不同的，以表值为准（R4 附录 B），并回写 history（§3 #10）。
6. **定类别**：
   - 史料是病卒、老卒的，为 N；
   - 被杀、处死、战死、被逼自杀的，为 K，并填凶手 ID（凶手要能解析到；解析不到属前提不成立，按 D15 顺延，满 10 年改 N。只有史实本无凶手的部众所杀、自缢、自尽、投水才留空 killer、换死因键，见 06 §0、§5；已被 D15 覆盖，见文首）；
   - 由节点控制的 K 条目填写「前置节点」（A3 §7 的写法）。
7. **自检**，有任何一项不过就拒绝输出：
   - 凶手 ID 必须存在，凶手死亡日期要晚于事件日期；
   - 日期要在本人生卒之间；
   - 同一个 ID 不能出现两次；
   - 被删除的重复 ID 不能出现（读 §2 合并表）；
   - 日期 ≥ 421.1.1 的报警。
8. **副产品**：
   - **早出场名单**（A1 F2）：16 岁前即位或被立储的人（司马聃、司马丕、司马奕、司马曜、司马德宗、慕容暐、张耀灵、张玄靓、石世等；10-27 加慕容熙、刘义符、刘义真，06 §8.1-2、A6-F15），交给 hbirth 生成器；
   - **UUII 晋人错年副本候选**（§2.1 末）；
   - **缺失要角清单**：节点里有引用、库里却找不到的 ID。
