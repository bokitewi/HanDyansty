### 3.2 桓温卒与 hd_court 权臣交接分支的处理（时序；hd_court 内部原称「D18」，非 boki 的 D18）

问题：A1 心跳里卒年在各时代节点之前跑（A1 §2.2）。`hd_court_repair_effect` 的 权臣交接分支（`common/scripted_effects/hd_court_regent_effects.txt:355-375`）会把权臣交给 `var:hd_court_regent_title` 的新持有者，也就是桓温主头衔的继承人。所以等"桓温卒"节点在杀人之后再跑，就来不及了。

★做法（分歧 G4 选 A 时）：
1. 卒年表里把桓温标成**特殊卒年**（类同袁真特例，`zz_hd_370_history_effects.txt:124-159`），在 `hd_j16_death_effect` 之前先跑前置钩子。
2. 前置钩子：只有桓温是 AI，并且他的主头衔继承人也是 AI 时才执行。在 `title:h_china` 上设 `hd_j16_handoff_block = 桓温`，然后发遗命风味（E4-J30 的 ①②）。
3. 杀人，用 `death_natural_causes`。
4. `hd_court_repair_effect` 的 权臣交接分支 limit 加一条：`NOT = { title:h_china.var:hd_j16_handoff_block ?= scope:hd_court_cur_regent }`。不满足就落进 `else = { hd_court_release_effect = yes }`，天子获释。
5. E4-J40 首跳删掉 `hd_j16_handoff_block`。
6. 其他锁会自动解开：
   - 终身辅政锁 `hd_dc_ten_qjc_regent` 在桓温死时由 `hd_dc_kit_ten_on_death`（`common/on_action/hd_dc_kit_ten_on_actions.txt:31-40`）自动清除。
   - 任期旗标 `hd_court_regent_tenure` 是人物旗标，随人消失。
7. 玩家例外：桓温或其继承人是玩家时不设阻断，权臣交接分支 照常运作，E4-J40 因"有桓氏权臣"而等待，到期跳过。

注意：
- `hd_court_regent_effects.txt` 和 `hd_court_on_actions.txt` 都是共享文件，改动时须独占（A1 §9.2）。
- `hd_court_regent_eligible_trigger`（`common/scripted_triggers/hd_court_triggers.txt:33-38`）要求有地、天朝政体。谢安在 370 开局只有世族头衔 `c_nf_chenjun_xie`，是否算 `is_landed` **未核**。这也是 G4 推荐"只授朝官、不装权臣"的原因之一。
