# 地名审查（重名 / 拼凑 / 错置）2026-11-02

只读审查，未改任何游戏文件。完整明细见同目录 `地名审查_2026-11-02.csv`（UTF-8 BOM，可直接用 Excel 打开）。

## 范围与方法

- 头衔：`common/landed_titles/` 全部文件（replace_path，不含原版），共 6973 个男爵。
- 名称：先读原版中文，再读 `localization/simp_chinese`，最后读 `localization/replace/simp_chinese`（后者覆盖前者）。
- 本表「本地化位置」列中 `M` = `localization/replace/simp_chinese/uuii_dm_barony_missing_l_simp_chinese.yml`；几乎所有问题名都出自这一个文件。
- 白名单：凡与本 mod 任一在用县名相同的名字，一律视为真地名不报（如 东平陵、南武阳、防东、东缗、下密、上邽）。
- 原版本地化的名字（蒙古、辽地等 `VANILLA`）只在“重名”类里报，不在“拼凑”类里报。不可通行男爵（b_impassable_*）不报。
- 规律：生成器遇到同郡重名时，给后来者加「东/西/左/右/县」等字去重，于是出现 东良乡、涿左、西临淄、铚左/铚右 这类假名；另一类是去重没做干净，直接重名。
