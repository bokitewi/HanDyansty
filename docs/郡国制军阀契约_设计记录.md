## 2. 实现要点

- 军阀身份记在**主头衔变量** `hd_warlord` 上（`hd_warlord_trigger`）。档位 is_valid、继承法、免税免兵都认这个变量，不认契约 flag：继承人还没拿到契约时引擎就会先校验档位。
- 只有经欢呼继承接位（`inheritance` / `appointment_succession`）才保留变量；其他方式易手（剥夺、改封、征服、篡夺等）即删除（`hd_warlord_on_title_gain`）。
- 独立或改政体后身份作废；升迁换了主头衔时变量挪到新主头衔；契约或继承法被引擎重置时补回（`hd_warlord_reconcile_effect`，on_title_gain 与季度脉冲）。
- 锁契约：`celestial_provinces` 加 `can_be_changed`（军阀且有变量时不可改），第 0、3、5 档 is_valid 排除军阀；第 1、2、4 档本来就对郡国制无效。收回时先删变量再写档位。
- 免税免兵：`celestial_obligations` 的 tax/levies 对军阀取 0，第 6 档另有 `tax_factor = -1`、`levies_factor = -1` 兜底。
- 停发俸禄：`celestial_salary_rank` 各档排除军阀，落回 none 档（该档无俸禄、无军费修正）。

## 4. 自拟项（待确认）

1. 国库折算：每季度把 `月收入 × 0.8 × 3`（0.8 = 契约税率 0.75 + 政体附加 0.05）从金钱扣出转入国库，按全额、不打普通封臣的七五折；金钱不足时有多少转多少。结果约为金钱 20%、国库 80%（普通封臣约金钱 20%、国库 60% + 俸禄）。
2. 主君好感 -40，十年内衰减（`hd_warlord_declared_opinion`）。
3. 常备军规模用的是 `men_at_arms_limit`（第二轮起共 +3）。另外俸禄档落回 none 后，郡/州级军阀原有的「头衔常备军上限 -1」也随之消失。
4. 欢呼继承制的好感修正照抄天朝将领继任制（尚武派 +5、朝堂派 -10、玩家继承人 +20、其他子女 -5）。
5. AI 拥兵自重：每 120 个月评估，兵力 ≥ 主君 +25、≥ 一半 +10，对主君好感 ≤0 +10、≤-25 再 +15，野心 +10，傲慢/贪婪/暴怒 +5，知足 -10，谦逊/怯懦 -5；忠诚、兵力不足主君 1/4、忠顺于主君则不发起。
6. AI 军阀接受收回：好感 ×0.5，兵力 ≥ 主君 -100、≥ 一半 -50、< 1/4 +50；忠诚 +50、怯懦 +25、知足 +20、谦逊 +15、轻信 +10，野心 -30、傲慢/固执 -20、勇敢/多疑 -10。
7. AI 主君收回：每 60 个月评估，自身兵力须达军阀 2 倍（达 3 倍再加分）；AI 宣讨不臣须达 1.5 倍。
8. 讨不臣：免费；白和与战败停战五年，宣战理由随之作废；军阀死亡由继承人接战。
9. 决议须成年可行动、未与主君交战；主头衔须是县级以上、非世家头衔。
10. 都督区首领强设武官：临时变量 `hd_warlord_force_military` 让第 3 档的名额和领主类型检查放行，写入后即删。名额检查对已是军制管理者本就放行，所以之后仍有效；但若该首领的直属领主不是最高领主且不是武官，删变量后档位可能被引擎判无效（极少见，未处理）。
11. 「指定继承人」互动是 UUII 旧副本，影响力门槛挂在「持有世家头衔」上（原版挂在政体有影响力上）。郡国制有影响力，家主军阀照样能花威望 + 影响力指定继承人，不改。
12. 拒绝调兵：影响力在发出派遣时已扣；军阀拒绝后不退。AI 主君派遣没有冷却，可能反复挑中同一个会拒绝的军阀白花影响力（三倍代价本身是抑制）。
13. 应召后的通知：朝廷派遣时给召唤者一条提示；都督区派遣沿用原有的 WJ_district.201/202 通知。

## 6. 2026-10-25 「拥兵自重」决议门槛（用户拍板）

- 直属主君的集权法不是第 4 级「天命在我」（`celestial_bureaucracy_3`）；直属主君本身是封臣（没有集权法）时视为满足。
- 须为武官：军制管理或司隶（不变）。
- 主头衔至少郡级（公爵级）。决议对县级官员仍显示，但灰掉并提示原因。
- 威望至少「崭露头角」（`prestige_level >= 1`）。
- 强力封臣至少半数支持：忠顺、朋友或至交、对其好感 ≥ 70，或对其「畏惧」（威慑 2 级；「惧怕」不算）。没有强力封臣时视为满足。实现为 `hd_warlord_powerful_vassal_balance`（支持者 +1、不支持者 -1，≥ 0 通过）。
- 花费 300 威望。

测试：
- [ ] 主君为「天命在我」时决议灰掉；直属主君是州牧等封臣时不受此限
- [ ] 县级官员看得到决议但不能点；威望不足「崭露头角」或不足 300 时不能点
- [ ] 有强力封臣时，提示里能看出支持条件；全部不支持时不能点
