## CK3 关键技术要点（已验证，可复用给其他人物的 DNA 导入）

1. **ruler designer 导出不能直接塞进 `common/dna_data`。** 导出里的 `override={ portrait_modifier_overrides={...} }` 必须改写并在**人物条目**里写成 `portrait_override`（见 `game/history/_characters.info:31-38` 官方 schema）。注意命名差异：bookmark_portraits 里叫 `override`，history/characters 里叫 `portrait_override`。

2. **`common/dna_data` 标准形态**（核对 vanilla `game/common/dna_data/00_dna.txt`）：
   ```
   <名字> = { portrait_info = { genes = { ... } } }
   ```
   vanilla 的 dna_data **完全没有** `entity=` / `random_seed=`，这两个是存档快照产物，要丢弃。`type=male` / `id=0` 也不需要（性别由人物条目是否带 `female=yes` 决定）。

3. **模组已有现成范例**：`east_asian_jingzhou_180_200.txt:1499-1505`（刘辩）就是 `dna = hand_xxx_dna` + `portrait_override` 的标准写法。`custom_hair=m_hair_tgp_chinese_02` + `custom_beards=male_empty` 组合已被 3 处人物使用，验证可用。

4. **模组文件编码**：UTF-8 **带 BOM** + **LF 换行**。改写工具必须保留，否则游戏读取异常。

5. **CK3 游戏安装位置**：`D:\SteamLibrary\steamapps\common\Crusader Kings III`（不在 C 盘 Program Files）。查原版格式/schema 去这里找。

6. **`common/bookmark_portraits/` 是独立 DNA 快照副本**，改 DNA 不会影响它们。当前只有 cao_cao / liu_bei / sun_jian / yuan_shao / zhang_jiao 五个，**没有吕布**，所以本次无需处理。以后若改那五个人物的 DNA，需同步更新对应 bookmark 立绘。
