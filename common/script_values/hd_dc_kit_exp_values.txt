# Scope：开边 CB（scope:attacker / scope:defender）。AI 加分：对方每个与天子疆域接壤的县 +60；对方强于天子则大减
hd_dc_exp_frontier_ai_score_value = {
	value = 50
	scope:defender = {
		every_sub_realm_county = {
			limit = {
				any_neighboring_county = { holder.top_liege ?= scope:attacker }
			}
			add = 60
		}
	}
	if = {
		limit = {
			scope:defender = { max_military_strength > scope:attacker.max_military_strength }
		}
		multiply = 0.1
	}
}
