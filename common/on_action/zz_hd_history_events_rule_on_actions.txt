# 终结乱世锁、起义军标记原来只在心跳里解除，规则关闭后按原兜底日期在这里解除
hd_hevrule_yearly_locks = {
	trigger = {
		has_game_rule = hd_history_events_off
	}
	effect = {
		if = {
			limit = {
				game_start_date = 22.11.13
				current_date >= 26.1.1
				NOT = { exists = global_var:hd_22_locks_cleared }
			}
			hd_22_clear_locks_effect = yes
			debug_log = "HD_HEVRULE LOCK_RELEASED 22"
		}
		else_if = {
			limit = {
				game_start_date = 304.11.20
				exists = global_var:hd_304_mandate_lock
			}
			hd_304_lock_check_effect = yes
			if = {
				limit = { NOT = { exists = global_var:hd_304_mandate_lock } }
				debug_log = "HD_HEVRULE LOCK_RELEASED 304"
			}
		}
		else_if = {
			limit = {
				game_start_date = 531.7.1
				exists = global_var:hd_531_mandate_lock
			}
			hd_531_lock_check_effect = yes
			if = {
				limit = { NOT = { exists = global_var:hd_531_mandate_lock } }
				debug_log = "HD_HEVRULE LOCK_RELEASED 531"
			}
		}
		else_if = {
			limit = { game_start_date = 617.6.23 }
			if = {
				limit = {
					current_date >= 619.1.1
					NOT = { exists = global_var:hd_617_rebel_cleared }
				}
				hd_617_clear_rebel_effect = yes
				debug_log = "HD_HEVRULE LOCK_RELEASED 617_REBEL"
			}
			if = {
				limit = {
					current_date >= 620.1.1
					exists = global_var:hd_617_mandate_lock
				}
				remove_global_variable = hd_617_mandate_lock
				debug_log = "HD_HEVRULE LOCK_RELEASED 617"
			}
		}
	}
}
