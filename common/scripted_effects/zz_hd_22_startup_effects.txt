# OE 副本：在世子女先改挂到本 mod 那份（只有王莽之女王捷 22 年在世），再静默除去。都只在 22 开局生效
hd_22_oe_dup_one_effect = {
	character:$OE$ ?= {
		if = {
			limit = {
				is_alive = yes
				is_landed = no
				character:$KEEP$ ?= { is_alive = yes }
			}
			every_child = {
				limit = { is_alive = yes }
				if = {
					limit = { NOT = { father ?= character:$KEEP$ } }
					set_father = character:$KEEP$
				}
			}
			death = { death_reason = death_vanished }
			debug_log = "HD_22 OE_DUP_REMOVED $OE$"
		}
	}
}

# 天朝循环：局势紧张开局、新朝土德、进度清零（照 saas_game_start.txt 的 184 分支）。
# 不用斗争开局；新朝之亡由 S4 天下响应推动，阶段由 hd_dc_evaluate_era_effect 即时检测
hd_22_dynastic_cycle_effect = {
	if = {
		limit = {
			has_tgp_dlc_trigger = yes
			exists = title:h_china.holder
			NOT = { exists = situation:dynastic_cycle }
		}
		start_situation = {
			type = dynastic_cycle
			start_phase = situation_dynastic_cycle_phase_instability
		}
	}
	if = {
		limit = {
			has_tgp_dlc_trigger = yes
			exists = situation:dynastic_cycle
			NOT = { exists = global_var:saas_dynastic_cycle_initialized }
		}
		situation:dynastic_cycle = {
			title:h_china = {
				set_variable = { name = years_since_imperial_examination value = 0 }
			}
			title:h_china.holder ?= {
				if = {
					limit = { legitimacy < legitimacy_level_6 }
					add_legitimacy = {
						value = legitimacy_level_6
						subtract = legitimacy
					}
				}
			}
			tgp_set_wuking_element_effect = { ELEMENT = earth }
			every_situation_participant = {
				recalculate_participant_group = situation:dynastic_cycle
			}
			hd_dc_zero_start_progress_effect = yes
			trigger_event = { on_action = hd_22_dc_zero_progress days = 2 }
		}
		set_global_variable = {
			name = saas_dynastic_cycle_initialized
			value = yes
		}
		debug_log = "HD_22 DYNASTIC_CYCLE INSTABILITY EARTH"
	}
}

	character:$WHO$ ?= {
		if = {
			limit = {

			character:wang_mang = {
				add_truce_both_ways = {
					character = character:$WHO$
					days = 176
					name = hd_22_truce
				}
			}
		}
	}
}

# S1 光武中兴：刘縯以边境战争打南阳郡持有者甄阜（照 218 汉中之战），王莽不当守方；新市、平林入攻方。
# 宛（c_uuii_p_1733）归汉军即胜，胜负由心跳按宛城归属判定（zz_hd_22_history_effects.txt）
hd_22_nanyang_war_effect = {
	if = {
		limit = {
			character:liu_yan ?= { is_alive = yes is_independent_ruler = yes }
			character:zhen_fu ?= { is_alive = yes is_landed = yes }
			title:d_nanyang.holder ?= character:zhen_fu
		}
		# 守方最高宗主没有边境战争法时补上，宗主满 1095 天才能加入封臣战争
		character:zhen_fu.top_liege = {
			if = {
				limit = {
					NOT = { this = character:zhen_fu }
					NOT = { has_realm_law = top_liege_not_redirected_to_border_wars_law }
				}
				add_realm_law_skip_effects = top_liege_not_redirected_to_border_wars_law
				debug_log = "HD_22 S1 BORDER_LAW_ADDED"
			}
		}
		hd_nbc_start_war_effect = { ATTACKER = character:liu_yan DEFENDER = character:zhen_fu TARGET = title:d_nanyang KIND = hd22nanyang }
		if = {
			limit = { exists = scope:hd_nbc_war_hd22nanyang }
			set_global_variable = hd_22_nanyang_started
			scope:hd_nbc_war_hd22nanyang = {
				hd_nbc_add_attacker_effect = { WHO = hd_22_wang_kuang }
				hd_nbc_add_attacker_effect = { WHO = hd_22_chen_mu }
			}
			character:liu_yan = { hd_nbc_spawn_army_effect = { SIZE = 7000 WHERE = title:c_uuii_p_1800 NAME = hd_22_chunling_army_name } }
			character:hd_22_wang_kuang ?= {
				if = {
					limit = { is_alive = yes is_landed = yes }
					hd_nbc_spawn_army_effect = { SIZE = 3000 WHERE = title:c_uuii_p_1859 NAME = hd_22_xinshi_army_name }
				}
			}
			character:hd_22_chen_mu ?= {
				if = {
					limit = { is_alive = yes is_landed = yes }
					hd_nbc_spawn_army_effect = { SIZE = 1500 WHERE = title:c_uuii_p_1844 NAME = hd_22_pinglin_army_name }
				}
			}
			character:zhen_fu = { hd_nbc_spawn_army_effect = { SIZE = 8000 WHERE = title:c_uuii_p_1733 NAME = hd_22_qiandui_army_name } }
		}
		else = {
			set_global_variable = hd_22_nanyang_done
			debug_log = "HD_22 S1 NANYANG WAR_START_FAILED"
		}
	}
	else = {
		set_global_variable = hd_22_nanyang_done
		debug_log = "HD_22 S1 NANYANG SKIPPED"
	}
}
