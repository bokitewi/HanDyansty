# 授郡（D16）：把 $DUCHY$ 郡头衔与郡内 $FROM$ 直辖的县授给 $TO$（granted，不加宣称）。只在 $FROM$ 是 AI、$TO$ 在世且不是 $FROM$ 时执行；
# 郡头衔由 $FROM$ 持有或无人持有才转。授后 $TO$ 的直接上级不是 $LIEGE$ 时改投 $LIEGE$（封臣化要求 $LIEGE$ 头衔等级更高，不满足时引擎拒绝，记日志）。
# $TAG$：日志用的节点号。Scope：任意
hd_j16_n370_grant_duchy_effect = {
	if = {
		limit = {
			$FROM$ = {
				is_alive = yes
				OR = {
					is_ai = yes
					has_global_variable = hd_j16_n370_grant_player_ok
				}
			}
			$TO$ = { is_alive = yes }
			NOT = { $FROM$ = { this = $TO$ } }
		}
		create_title_and_vassal_change = { type = granted save_scope_as = hd_j16_n370_gd_change add_claim_on_loss = no }
		$DUCHY$ = {
			every_de_jure_county = {
				limit = { holder ?= $FROM$ }
				change_title_holder = {
					holder = $TO$
					change = scope:hd_j16_n370_gd_change
					take_baronies = yes
				}
			}
		}
		if = {
			limit = {
				OR = {
					$DUCHY$.holder ?= $FROM$
					NOT = { exists = $DUCHY$.holder }
				}
			}
			$DUCHY$ = {
				change_title_holder = {
					holder = $TO$
					change = scope:hd_j16_n370_gd_change
				}
			}
		}
		resolve_title_and_vassal_change = scope:hd_j16_n370_gd_change
		$TO$ = {
			if = {
				limit = {
					is_landed = yes
					NOT = { this = $LIEGE$ }
					NOT = { liege ?= $LIEGE$ }
				}
				hd_nbc_swear_fealty_effect = { LIEGE = $LIEGE$ }
			}
			if = {
				limit = { has_title = $DUCHY$ }
				debug_log = "HD_J16 $TAG$ FIRE grant_duchy"
			}
			else = { debug_log = "HD_J16 $TAG$ WAIT grant_duchy_failed" }
		}
	}
	else = { debug_log = "HD_J16 $TAG$ SKIP grant_duchy_not_ai" }
}

# 事件兵：在 $QIN$ 一系、与郡 $DUCHY$ 相邻的县生成 $SIZE$ 兵，归 $WHO$；找不到这样的县就放在 $WHO$ 的都城县。Scope：任意
hd_j16_n370_front_army_effect = {
	if = {
		limit = { exists = scope:hd_j16_n370_fa_place }
		clear_saved_scope = hd_j16_n370_fa_place
	}
	$DUCHY$ = {
		random_de_jure_county = {
			limit = {
				NOT = { holder ?= { target_is_same_character_or_above = $QIN$ } }
				any_neighboring_county = { holder ?= { target_is_same_character_or_above = $QIN$ } }
			}
			random_neighboring_county = {
				limit = { holder ?= { target_is_same_character_or_above = $QIN$ } }
				save_scope_as = hd_j16_n370_fa_place
			}
		}
	}
	if = {
		limit = { NOT = { exists = scope:hd_j16_n370_fa_place } }
		$WHO$.capital_county ?= { save_scope_as = hd_j16_n370_fa_place }
	}
	$WHO$ = {
		if = {
			limit = {
				is_alive = yes
				is_landed = yes
				exists = scope:hd_j16_n370_fa_place
			}
			hd_nbc_spawn_army_effect = { SIZE = $SIZE$ WHERE = scope:hd_j16_n370_fa_place NAME = $NAME$ }
		}
	}
}

	if = {
		limit = { NOT = { has_global_variable = hd_j16_jindao_after_done } }

			limit = { global_var:hd_j16_start_year >= 404 }
			set_global_variable = hd_j16_jindao_after_done
			debug_log = "HD_J16 e4_m05 SKIP prestart"
		}
		else_if = {
			limit = { current_date >= 370.2.14 }
			if = {
				limit = { current_date >= 371.1.2 }
				set_global_variable = hd_j16_jindao_after_done
				set_global_variable = hd_j16_jindao_after_skip
				debug_log = "HD_J16 e4_m05 SKIP window_closed"
			}
			else_if = {
				limit = { hd_j16_dead_trigger = { ID = changli_murong_038 } }
				set_global_variable = hd_j16_jindao_after_done
				set_global_variable = hd_j16_jindao_after_skip
				debug_log = "HD_J16 e4_m05 SKIP actor_dead"
			}
			else_if = {
				limit = {
					global_var:hd_j16_start_year < 370
					OR = {
						has_global_variable = hd_j16_jindao_declined
						AND = {
							has_global_variable = hd_j16_jindao_skip
							NOT = { hd_j16_dead_trigger = { ID = changli_murong_039 } }
						}
					}
				}
				set_global_variable = hd_j16_jindao_after_done
				set_global_variable = hd_j16_jindao_after_skip
				debug_log = "HD_J16 e4_m05 SKIP deviated"
			}
			else = {
				hd_j16_get_qin_ruler_effect = { AS = hd_j16_m05_qin }
				if = {
					limit = { exists = scope:hd_j16_m05_chui }
					clear_saved_scope = hd_j16_m05_chui
				}
				hd_j16_resolve_effect = { ID = changli_murong_038 AS = hd_j16_m05_chui }
				if = {
					limit = {
						OR = {
							global_var:hd_j16_start_year >= 370
							has_global_variable = hd_j16_jindao_settled
							AND = {
								hd_j16_dead_trigger = { ID = changli_murong_039 }
								NOT = { has_global_variable = hd_j16_jindao_result }
							}
						}
						scope:hd_j16_m05_qin ?= { is_independent_ruler = yes }
						scope:hd_j16_m05_chui ?= {
							NOT = { this = scope:hd_j16_m05_qin }
							hd_j16_n370_in_realm_trigger = { QIN = scope:hd_j16_m05_qin }
						}
					}
					set_global_variable = hd_j16_jindao_after_done
					scope:hd_j16_m05_chui = {
						if = {
							limit = { is_ai = yes }
							hd_j16_jindao_after_a_effect = yes
						}
						else = {
							trigger_event = hd_j16.4010
							debug_log = "HD_J16 e4_m05 WAIT player_asked"
						}
					}
				}
				else_if = {
					limit = { NOT = { has_global_variable = hd_j16_jindao_after_wlog } }
					set_global_variable = hd_j16_jindao_after_wlog
					debug_log = "HD_J16 e4_m05 WAIT not_ready"
				}
			}
		}
	}

	}
