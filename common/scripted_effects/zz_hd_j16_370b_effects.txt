# 授郡（D16 / A1 §7.1）：把 $DUCHY$ 郡头衔及原持有者在该郡直辖的县一并授给 $TO$（granted，不加宣称）。
# 调用方先判 hd_j16_370b_grantable_trigger（或自行确认持有者是同政权的 AI）。授完若受郡者的主君不是原持有者的主君（原持有者独立时即其本人），改投之。
hd_j16_370b_grant_duchy_effect = {
	if = {
		limit = { exists = scope:hd_j16_kgd_from }
		clear_saved_scope = hd_j16_kgd_from
	}
	if = {
		limit = { exists = scope:hd_j16_kgd_lg }
		clear_saved_scope = hd_j16_kgd_lg
	}
	if = {
		limit = { exists = scope:hd_j16_kgd_to }
		clear_saved_scope = hd_j16_kgd_to
	}
	$TO$ = { save_scope_as = hd_j16_kgd_to }
	$DUCHY$.holder ?= {
		save_scope_as = hd_j16_kgd_from
		if = {
			limit = { exists = liege }
			liege = { save_scope_as = hd_j16_kgd_lg }
		}
		else = { save_scope_as = hd_j16_kgd_lg }
	}
	if = {
		limit = {
			exists = scope:hd_j16_kgd_from
			exists = scope:hd_j16_kgd_to
		}
		create_title_and_vassal_change = {
			type = granted
			save_scope_as = hd_j16_kgd_change
			add_claim_on_loss = no
		}
		$DUCHY$ = {
			every_de_jure_county = {
				limit = { holder ?= scope:hd_j16_kgd_from }
				change_title_holder = {
					holder = scope:hd_j16_kgd_to
					change = scope:hd_j16_kgd_change
					take_baronies = yes
				}
			}
			change_title_holder = {
				holder = scope:hd_j16_kgd_to
				change = scope:hd_j16_kgd_change
			}
		}
		resolve_title_and_vassal_change = scope:hd_j16_kgd_change
		scope:hd_j16_kgd_to = {
			if = {
				limit = {
					is_landed = yes
					NOT = { this = scope:hd_j16_kgd_lg }
					NOT = { liege ?= scope:hd_j16_kgd_lg }
				}
				hd_nbc_swear_fealty_effect = { LIEGE = scope:hd_j16_kgd_lg }
			}
		}
		debug_log = "HD_J16 $LOG$ FIRE grant_duchy"
	}
}

# 授朝官 $TITLE$（$POS$ 为原版席位键）给 $WHO$（人物 scope），天子为授官者。
# 有地者走 granted（appointment 会让有地者辞去实土：10-16 讨董修复同因），并补朝官继承法与议会席位；无地者照 hd_nbc_minister_effect 走原版 got_minister_position_effect。
hd_j16_370b_office_effect = {
	if = {
		limit = { exists = scope:hd_j16_kof_who }
		clear_saved_scope = hd_j16_kof_who
	}
	$WHO$ ?= { save_scope_as = hd_j16_kof_who }
	if = {
		limit = {
			exists = title:h_china.holder
			scope:hd_j16_kof_who ?= {
				is_alive = yes
				is_imprisoned = no
				NOT = { has_title = title:$TITLE$ }
				NOT = { this = title:h_china.holder }
			}
		}
		if = {
			limit = { scope:hd_j16_kof_who = { is_landed = yes } }
			create_title_and_vassal_change = {
				type = granted
				save_scope_as = hd_j16_kof_change
				add_claim_on_loss = no
			}
			title:$TITLE$ = {
				change_title_holder = {
					holder = scope:hd_j16_kof_who
					change = scope:hd_j16_kof_change
				}
			}
			resolve_title_and_vassal_change = scope:hd_j16_kof_change
			# granted 不加继承法：照 WJ got_minister_position_effect（WJ_ministry_override_effects.txt 第 110–137 行）补上，免朝官头衔按普通继承传给继承人
			if = {
				limit = {
					title:$TITLE$ = title:e_minister_grand_marshal
					NOT = { title:$TITLE$ = { has_title_law = celestial_grand_marshal_appointment_succession_law } }
				}
				title:$TITLE$ = { add_title_law = celestial_grand_marshal_appointment_succession_law }
			}
			else_if = {
				limit = {
					NOR = {
						title:$TITLE$ = title:e_minister_grand_marshal
						title:$TITLE$ = { has_title_law = celestial_ministry_appointment_succession_law }
					}
				}
				title:$TITLE$ = { add_title_law = celestial_ministry_appointment_succession_law }
			}
			# 补议会席位（不调 got_minister_position_effect：它第 153–179 行会把无 WJ_rf 实封者的封臣全转给天子）。
			# 只在他是天子的直属封臣或廷臣时占席；否则只持头衔（实测项）
			if = {
				limit = {
					scope:hd_j16_kof_who = {
						NOT = { has_council_position = $POS$ }
						OR = {
							liege ?= title:h_china.holder
							employer ?= title:h_china.holder
						}
					}
				}
				title:h_china.holder = {
					assign_councillor_type = {
						type = $POS$
						target = scope:hd_j16_kof_who
						remove_existing_councillor = yes
					}
				}
			}
		}
		else = {
			title:h_china.holder = { save_scope_as = councillor_liege }
			scope:hd_j16_kof_who = {
				if = {
					limit = {
						NOT = { employer ?= scope:councillor_liege }
						is_councillor = no
					}
					scope:councillor_liege = { add_courtier = scope:hd_j16_kof_who }
				}
				got_minister_position_effect = { MINISTER_TITLE = $TITLE$ MINISTER_POSITION = $POS$ }
			}
		}
		debug_log = "HD_J16 $LOG$ FIRE office"
	}
}
