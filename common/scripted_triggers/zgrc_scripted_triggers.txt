# 蛮夷判定：① 自身非华夏礼乐 ② 最高领主亦非 ③ 非（通汉语 且 信公羊学）
zgrc_is_manyi_character_trigger = {
	culture = {
		NOT = { has_cultural_tradition = tradition_zgrc_hua_xia_li_yue }
	}
	NOT = {
		top_liege = {
			culture = { has_cultural_tradition = tradition_zgrc_hua_xia_li_yue }
		}
	}
	NOT = {
		AND = {
			knows_language = language_chinese
			rite = { rite_has_tenet = tenet_zgrc_zunwangrangyi }
		}
	}
}

# 归化目标文化合法性（Culture 作用域）
# 条件：尚未汉化；其文化领袖是执行者（汉家天子）自己的封臣
# 无文化领袖者不满足——无族长则无从推行汉化
zgrc_guihua_target_culture_trigger = {
	NOT = { has_cultural_tradition = tradition_zgrc_hua_xia_li_yue }
	NOT = { has_cultural_tradition = tradition_zgrc_yong_xia_bian_yi }

	# ?= 在 scope 不存在时判定为真，此处须显式 exists，否则无族长 / 独立之族亦入选
	exists = culture_head
	culture_head = {
		exists = top_liege
		# 文化领袖的最高领主须是执行者自己（即其封臣），不跨势力
		top_liege = root
	}
}

# 生于斯土：规则「仅 AI 家族」时，玩家（父母 / 家主）家族的后代不随出生地改风俗
# 上游写作 father ?= { is_ai = no } 等，?= 在父母 / 家主不存在时为真，会把无父无家者也挡掉；此处改为显式 exists
zgrc_sheng_yu_si_tu_allowed_trigger = {
	OR = {
		NOT = { has_game_rule = zgrc_sheng_yu_si_tu_ai_only }
		NOR = {
			AND = {
				exists = father
				father = { is_ai = no }
			}
			AND = {
				exists = mother
				mother = { is_ai = no }
			}
			AND = {
				exists = house
				house = {
					exists = house_head
					house_head = { is_ai = no }
				}
			}
		}
	}
}
