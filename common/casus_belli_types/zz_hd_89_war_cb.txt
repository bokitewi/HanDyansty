# 89 年剧本「燕然勒石」史实战争（S1 燕然、S2 金微山、S5 焉耆）。计划见 /mnt/project-files/89窦宪北伐剧本_计划.md 第 10、13 节。
# 写法照 hd_nbc_war_cb，只能由脚本宣战；胜利时不转移头衔：汉朝北伐不吞并漠北，各场次的结算在 zz_hd_89_history_effects.txt 里做。
# 结局设全局标记 hd_89_<场次>_won / _lost / _white / _invalid（以攻方论胜负，场次见战争变量 hd_89_war_kind）。
hd_89_war_cb = {
	icon = conquest
	group = conquest
	combine_into_one = no
	should_show_war_goal_subview = yes
	mutually_exclusive_titles = { always = yes }
	allow_hostages = no
	allowed_for_character = {}
	allowed_against_character = {}
	target_titles = all
	target_title_tier = all
	target_de_jure_regions_above = yes
	target_top_liege_if_outside_realm = no
	ignore_effect = change_title_holder
	should_check_for_interface_availability = no
	valid_to_start = { always = no }
	cost = {}

	should_invalidate = {
		NOT = {
			any_in_list = {
				list = target_titles
				any_in_de_jure_hierarchy = {
					tier = tier_county
					holder = { OR = { this = scope:defender target_is_liege_or_above = scope:defender } }
				}
			}
		}
	}

	on_invalidated_desc = msg_religious_war_invalidation_region_message
	on_invalidated = {
		# HD peace: the old payload belongs only to an authorized scripted war.
		if = {
			limit = { exists = root.war root.war = { hd_peace_is_scripted_war_trigger = yes } }

		hd_89_war_result_effect = { RESULT = invalid }
	
		}
		else = { hd_peace_cb_invalidated_effect = yes }
	}
	on_declaration = { on_declared_war = yes }

	on_victory_desc = { desc = hd_89_war_victory_desc }
	on_victory = {
		# HD peace: the old payload belongs only to an authorized scripted war.
		if = {
			limit = { exists = root.war root.war = { hd_peace_is_scripted_war_trigger = yes } }

		add_truce_attacker_victory_effect = yes
		hd_89_war_result_effect = { RESULT = won }
	
		}
		else = { hd_peace_cb_result_effect = yes }
	}

	on_white_peace_desc = { desc = hd_89_war_white_peace_desc }
	on_white_peace = {
		# HD peace: the old payload belongs only to an authorized scripted war.
		if = {
			limit = { exists = root.war root.war = { hd_peace_is_scripted_war_trigger = yes } }

		add_truce_white_peace_effect = yes
		hd_89_war_result_effect = { RESULT = white }
	
		}
		else = { hd_peace_cb_result_effect = yes }
	}
	on_defeat_desc = { desc = hd_89_war_defeat_desc }
	on_defeat = {
		# HD peace: the old payload belongs only to an authorized scripted war.
		if = {
			limit = { exists = root.war root.war = { hd_peace_is_scripted_war_trigger = yes } }

		add_truce_attacker_defeat_effect = yes
		hd_89_war_result_effect = { RESULT = lost }
	
		}
		else = { hd_peace_cb_result_effect = yes }
	}

	on_primary_attacker_death = inherit
	on_primary_defender_death = inherit
	transfer_behavior = transfer
	attacker_allies_inherit = no
	defender_allies_inherit = yes
	war_name = "HD_89_WAR_NAME"
	interface_priority = 80
	use_de_jure_wargoal_only = yes
	attacker_wargoal_percentage = 0.8
	landless_attacker_needs_armies = no
	full_occupation_by_attacker_gives_victory = no
	full_occupation_by_defender_gives_victory = no
	max_attacker_score_from_battles = 100
	max_defender_score_from_battles = 50
	max_defender_score_from_occupation = 150
	max_attacker_score_from_occupation = 150
	max_ai_diplo_distance_to_title = 500
}
