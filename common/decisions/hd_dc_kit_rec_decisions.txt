# 招抚流民：花 300 金，选一州（王国级法理区域），州内属天子之国的各县发展增长速率 +20%、征兵 +10%，10 年；冷却 10 年
############################################################
hd_dc_rec_resettle_refugees_decision = {
	picture = {
		reference = "gfx/interface/illustrations/decisions/decision_recruitment.dds"
	}
	decision_group_type = dynastic_cycle
	title = hd_dc_rec_resettle_refugees_decision
	desc = hd_dc_rec_resettle_refugees_decision_desc
	selection_tooltip = hd_dc_rec_resettle_refugees_decision_tooltip
	confirm_text = hd_dc_rec_resettle_refugees_decision_confirm
	sort_order = 63

	ai_check_interval = 24

	is_shown = {
		has_title = title:h_china
		hd_dc_phase_is_trigger = { PHASE = hd_recovery }
	}

	is_valid_showing_failures_only = {
		is_imprisoned = no
		custom_tooltip = {
			text = hd_dc_rec_resettle_refugees_pick_tt
			scope:selected_item ?= {
				tier = tier_kingdom
				any_de_jure_county = { holder.top_liege ?= root }
			}
		}
	}

	cooldown = { years = 10 }

	cost = {
		treasury_or_gold = 300
	}

	widget = {
		gui = "decision_view_widget_select_realm_county"
		controller = select_scope_object

		setup_items = {
			scope:actor = {
				every_sub_realm_county = {
					kingdom ?= {
						if = {
							limit = { NOT = { is_in_list = item_list } }
							add_to_list = item_list
						}
					}
				}
			}
		}

		default_item = {
			scope:actor.capital_county.kingdom ?= {
				save_scope_as = selected_item
			}
		}

		is_item_valid = {
			tier = tier_kingdom
		}

		ai_item_will_do = {
			value = 1
			every_de_jure_county = {
				limit = { holder.top_liege ?= scope:actor }
				add = 1
			}
		}
	}

	effect = {
		hd_dc_rec_resettle_refugees_effect = yes
	}

	ai_potential = {
		treasury_or_gold >= 500
	}

	ai_will_do = {
		base = 15
		modifier = {
			add = 15
			has_trait = diligent
		}
		modifier = {
			add = 10
			has_trait = compassionate
		}
	}
}
