# 中兴改革：花一级正统 + 500 金，每帝一次，10 年事件链；党锢：择一朋党，事件中选禁锢或一网打尽

hd_dc_kit_ten_restoration_decision = {
	decision_group_type = dynastic_cycle
	picture = {
		reference = "gfx/interface/illustrations/decisions/decision_golden_age.dds"
	}
	desc = hd_dc_kit_ten_restoration_decision_desc
	selection_tooltip = hd_dc_kit_ten_restoration_decision_tooltip
	sort_order = 82

	is_shown = {
		hd_dc_kit_ten_emperor_trigger = yes
	}
	is_valid = {
		custom_tooltip = {
			text = hd_dc_kit_ten_restoration_once_tt
			NOT = { has_variable = hd_dc_ten_restoration_done }
		}
		custom_tooltip = {
			text = hd_dc_kit_ten_restoration_legitimacy_tt
			legitimacy_level >= 1
		}
	}
	is_valid_showing_failures_only = {
		is_available_adult = yes
	}

	cost = {
		gold = hd_dc_ten_restoration_gold
	}

	effect = {
		show_as_tooltip = { hd_dc_kit_ten_drop_legitimacy_level_effect = yes }
		custom_tooltip = hd_dc_kit_ten_restoration_decision_effect_tt
		custom_tooltip = hd_dc_kit_ten_if_success_tt
		show_as_tooltip = {
			add_prestige = major_prestige_gain
			add_legitimacy = medium_legitimacy_gain
			add_character_modifier = {
				modifier = hd_dc_kit_ten_restoration_success_modifier
				years = hd_dc_ten_restoration_success_years
			}
		}
		custom_tooltip = hd_dc_kit_ten_if_failure_tt
		show_as_tooltip = {
			add_prestige = medium_prestige_loss
			add_character_modifier = {
				modifier = hd_dc_kit_ten_restoration_failed_modifier
				years = 10
			}
		}
		hidden_effect = {
			hd_dc_kit_ten_restoration_start_effect = yes
			trigger_event = hd_dc_ten.0001
		}
	}

	ai_check_interval = 60
	ai_potential = {
		is_ai = yes
	}
	ai_will_do = {
		base = 0
		modifier = {
			add = 20
			legitimacy_level >= 2
			gold >= 800
		}
		modifier = {
			add = 20
			hd_dc_kit_ten_restoration_chance_value >= 50
		}
		modifier = {
			add = 10
			OR = {
				has_trait = ambitious
				has_trait = diligent
				has_trait = brave
			}
		}
		modifier = {
			add = -30
			OR = {
				has_trait = content
				has_trait = lazy
				has_trait = craven
			}
		}
	}
}
