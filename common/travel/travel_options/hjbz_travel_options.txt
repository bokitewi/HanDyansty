# 【写法核实（2026-10-07，原版取证）】
#   · 字段清单唯一权威：common/travel/travel_options/_travel_options.info
#     is_shown / is_valid / cost / travel_modifier / owner_modifier /
#     on_applied_effect / on_travel_end_effect / ai_will_do / travel_entourage_selection
#   · **没有 icon 字段** —— 图标由 TravelOption.GetIcon 按 key 自动解析：

#   · 开放/禁用靠 is_shown / is_valid（scope = 旅行发起者），无专门的开关机制
#
# 【本选项的「解锁 / 禁用」如何实现】
#   不加任何额外标记，直接以角色修正为条件：
#     is_shown = { has_character_modifier = hjbz_yulin_guard_modifier }
#   → 事件一施加该修正 = 自动开放
#   → 事件三移除该修正 = 自动禁用
#   与「重建 / 裁撤」共用同一个状态源，不会出现不同步。
